---
name: pleos-check
description: 변경 사항이나 문서가 Pleos 공식 규칙을 지키는지 점검할 때 사용한다.
---

1. 변경 대상과 `docs/principles/compliance-matrix.md`를 읽습니다.
2. 관련 규칙 문서에서 MUST 항목을 먼저 확인합니다.
3. 주행 규제, 오디오 포커스, 지원 여부 확인, 백그라운드 동작, 개인정보, 알림의 광고성 여부를 점검합니다.
4. 결과를 `규칙 ID / 판정 / 근거 파일 / 조치`로 보고합니다. 판단할 수 없으면 `미확정`으로 적습니다.
5. 사용자가 요청하면 매트릭스 상태를 갱신합니다.
