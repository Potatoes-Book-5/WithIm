---
name: implement
description: 승인된 계획이나 명세에 따라 앱 코드를 구현할 때 사용한다.
---

1. 계획, 명세, `docs/ARCHITECTURE.md`를 읽습니다.
2. 계획 범위 안에서만 변경합니다. 범위 밖 문제는 `tasks.md`에 `debt`로 등록을 제안합니다.
3. `domain` 로직은 테스트와 함께 작성합니다.
4. SDK 사용 전에 `docs/platform/sdk-usage-map.md`를 갱신하고, 지원 여부 확인과 미지원 동작을 구현합니다.
5. 색상과 글꼴은 토큰만 사용합니다.
6. 계획 문서의 체크리스트와 진행 기록을 갱신합니다.
7. `verify` 스킬로 검증합니다.
