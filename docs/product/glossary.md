# 용어집

| 용어 | 정의 | 상태 |
|---|---|---|
| 임장 | 부동산을 직접 둘러보러 가는 일 | 확정 |
| 임과 함께 | 이 앱의 이름. 임장을 누군가와 함께한다는 의미 | 확정 |
| 시세 | 단지의 최근 매매 실거래가. 단지 대표값 산정 방식은 미정 | 초안 |
| 반경 | 차량 위치 기준 10km | 초안 |
| 순위 | 반경 안 단지를 시세 기준으로 정렬한 1~3위 | 초안 |
| 대장 아파트 | 반경 안 실거래가 1위 단지 | 초안 |
| 대장 교체 | 이동 중 대장 아파트가 다른 단지로 바뀌는 일 | 초안 |
| 관심 조건 | 동네, 가격대, 평수 등 사용자가 정한 조건 | 초안 |
| 관심 매물 | 관심 조건을 모두 만족하는 단지 | 초안 |
| 스크랩 | 나중에 다시 보려고 저장한 단지 | 초안 |
| 변동 | 스크랩 단지의 새 실거래 등록, 가격 변화, 순위 변화 | 초안 |
| 주행 세션 | Drive 전환부터 주차 후 일정 시간까지의 기록 단위 | 초안 |
| 주행 요약 | 주행 세션의 순위 기록과 관심 매물 정리 | 초안 |
| 주행 규제 상태 | `CarUxRestrictions` 기준 제한 활성 상태 | 초안 |

## Gleo 임장 추가 용어

| 용어 | 정의/소유 문서 | 상태 |
|---|---|---|
| 동네 평균 | 법정동·동일 면적대·기간의 공개 매매 거래 평균. [F-002](features/F-002-nearby-price-lookup.md) | 제안 |
| 관심 지역 | 법정동 경계 또는 역세권 중심+반경의 저장 객체. [F-011](features/F-011-interest-area-booking.md) | 초안 |
| 맞춤 추천 | 필수 조건을 통과한 후보의 선호 점수 정렬. 가격 순위·오각형과 별개. [F-004](features/F-004-interest-conditions.md) | 제안 |
| 왕관 | 가격 순위 1위의 정적 표식. [F-003](features/F-003-apartment-ranking.md) | 초안 |
| 새로 공개된 거래 | 처음 수집된 공개 거래. 당일 체결이라는 의미 아님. [F-013](features/F-013-area-daily-briefing.md) | 초안 |
| 지역 문맥 | 프로필·세션·대상 지역·시각을 묶은 요청 해석 정보. [F-010](features/F-010-gleo-app-control.md) | 초안 |

기존 표의 시세 대표값·순위 범위 관련 미결은 F-002/F-003의 검토 제안으로 구체화했으며 확정되었다는 뜻은 아니다.
