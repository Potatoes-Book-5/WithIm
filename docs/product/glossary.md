# 용어집

정의를 확정하면 기능 문서는 이 파일을 링크합니다.

| 용어 | 정의 | 상태 |
|---|---|---|
| 시세 | 실거래가, 호가, 추정가 중 무엇을 뜻하는지 작성 필요 | 미정 |
| 주변 | 차량 위치 기준 반경 또는 행정구역, 작성 필요 | 미정 |
| 순위 | 어떤 지표로 어떤 대상을 정렬하는지 작성 필요 | 미정 |
| 관심 부동산 | 사용자가 직접 지정한 단지 | 초안 |
| 관심 조건 | 지역, 가격대, 면적 등 사용자가 지정한 조건 | 초안 |
| 매물 | 시세 데이터의 단지와 실제 판매 물건 중 무엇인지 작성 필요 | 미정 |
| 알림 | 조건 일치 시 제공하는 TTS와 화면 표시 | 초안 |
| 주행 규제 상태 | `CarUxRestrictions` 기준 제한 활성 상태 | 초안 |
