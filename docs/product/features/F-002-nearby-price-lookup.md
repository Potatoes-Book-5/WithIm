# F-002 반경 10km 시세 조회

## 목적

차량 위치 반경 10km 이내 아파트 단지의 실거래가를 조회해 순위 경쟁과 관심 매물 판정에 제공한다.

## 사용자 가치

- 이동하는 지역의 아파트 시세를 따로 검색하지 않아도 알 수 있다.

## 비즈니스 규칙

1. 조회 반경은 차량 위치 기준 10km이다.
2. 가격 기준은 공개된 아파트 매매 실거래가이다. 대표값·동네 평균의 검토용 제안은 아래 R-PRICE에서 정의하며 채택은 미결이다.
3. 실거래가는 신고 이후 공개되므로 '실시간'은 위치 변화에 따른 실시간 갱신을 뜻한다.
4. 지역 단위로 데이터를 받아 기기에 캐시하고, 이동 중에는 캐시를 우선 사용한다.
5. 요청에는 재시도와 타임아웃을 적용한다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 현재 위치 | F-001 |
| 출력 | 단지 목록 | 단지명, 위치, 최근 실거래가, 거래일, 평형, 세대수 |
| 출력 | 데이터 기준일 | 화면에 표시 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 조회 후 홈에 표시 |
| Drive | 캐시 우선, 필요한 지역만 추가 조회 |
| 오프라인 | 마지막 캐시와 기준 시각 표시 |
| API 미지원 | 해당 없음 |
| 백그라운드 | 알림이 켜진 경우 캐시 범위만 갱신 |

## 예외

- 반경 안에 단지가 없으면 빈 상태를 표시한다.
- 응답이 늦으면 마지막 결과를 유지하고 갱신 중임을 표시한다(DG-005).

## 인수 조건

- [ ] 반경 10km 밖의 단지는 결과에 포함되지 않는다.
- [ ] 오프라인에서 마지막 결과와 기준 시각이 표시된다.
- [ ] 같은 지역·필터·원천 버전의 유효 캐시만 재사용하고 시각을 표시한다.

## R-PRICE — Gleo 임장 가격 제안

### 지표와 집계

이 명세의 가격은 매물 호가나 실시간 체결 가격이 아닌 최신 공개된 아파트 매매 실거래 데이터이다. 사용자에게는 조회 시점, 원천 자료 기준일, 거래일을 구분해 제공한다.

| 지표 | 제안 정의 |
|---|---|
| 동네 | 좌표가 속한 법정동. 역세권 관심 지역은 중심 좌표와 반경을 별도로 저장 |
| 동네 평균 | 해당 법정동, 동일 면적대, 최근 90일, 취소 제외 매매 거래금액의 산술평균 |
| 기본 면적대 | 전용면적 80㎡ 이상 90㎡ 미만. 사용자 면적 조건이 있으면 해당 조건 사용 |
| 최소 표본 | 3건. 미만이면 평균을 단정하지 않고 표본 부족으로 안내 |
| 최고 거래 단지 | 평균과 같은 필터 안의 거래 중 금액 최댓값의 단지 |
| 주변 가격 순위 | 차량 중심 직선거리 10km 이내 단지. 단지별 동일 필터의 가장 최근 거래금액을 내림차순 정렬 |
| 가격 동률 | [F-003](F-003-apartment-ranking.md)의 안정 정렬을 따름 |
| 왕관 | [F-003](F-003-apartment-ranking.md)의 가격 순위 1위 표식. 최고 거래/맞춤 추천과 별도 |
| 맞춤 추천 | [F-004](F-004-interest-conditions.md)의 임장 추천 제안. 가격 순위와 별도 |
| 가격 변화 | 같은 단지·같은 면적대의 비교 가능한 대표값 차이. 원천 정정은 새로운 거래와 구분 |

90일·면적대·표본수·대표값·동률 처리는 모두 제품 제안값이다. 데이터 제공자의 보장이나 Pleos SDK의 규칙이 아니다. 학군은 출처 있는 배정/시설 사실을 요약하며, 확인되지 않은 우열 평가를 생성하지 않는다.

### 데이터 유효성

- 거래키로 중복 제거하고 취소·정정·지연 유입을 반영한다. 금액은 정수 원 단위로 보관하며 표시만 억 단위로 변환한다.
- 평균과 최고 거래의 지역·기간·면적 필터가 다르면 같은 문장으로 비교하지 않는다.
- 표본 없음/부족을 가격 0원으로 처리하지 않는다. 조건을 넓히려면 사용자 선택 또는 명시적인 안내가 필요하다.
- 캐시는 지역·거래종류·면적대·기간·원천 버전으로 구분한다. 24시간 이내 수집 캐시를 오프라인 요약에 쓸 수 있다는 값을 제안한다. 24시간을 초과하면 최신 요약은 제공하지 않고 과거 자료임을 표시한 주차 열람만 허용한다.
- 조회 도중 다른 지역으로 이동해도 시작 시점의 조회 대상은 유지한다. 결과에 대상 지역을 명시하고, 오래된 결과가 현재 지역 카드에 덮어쓰이지 않게 한다.
- 실거래·단지/경계·학교/교통·청약·뉴스의 공급자, 이용 권한, 갱신 주기, 출처 표시는 확정 전이다. 선정 전에는 합성 fixture만 사용한다.

### R-04 — 주차 심층 분석의 데이터 계약

- 동일 면적대의 기간별 거래를 사용한다. 거래 없는 월을 0원/추정값으로 채우지 않는다.
- 축·기간·단위·표본·원천 기준일·수집 시각을 구분하고 입지 출처/시점도 유지한다.
- 예산/면적을 통과한 맞춤 추천은 F-004에서 계산한다. 가격 순위는 F-003과 구분한다.
- 단지 선택을 빠르게 바꿔도 늦은 응답이 현재 선택 단지를 덮어쓰지 않게 한다.
- 부분 입지 오류 시 유효 가격 자료를 유지하고 정보 부족을 표시한다.
- PriceSummary는 지역/필터/기간·표본·평균·최고 거래·원천 기준일/버전·수집 시각을 갖는다.
- 상태 전환/가로·세로 표현은 [SCR-002](../../design/screens/SCR-002-apartment-detail.md), 지역 음성 조회는 [F-010](F-010-gleo-app-control.md)을 따른다.

검증: [S-011 테스트](../../testing/gleo-tour/README.md). 집계 예시는 합성 자료이며 공급자 선정/원천 가격 검증은 완료하지 않았다.
