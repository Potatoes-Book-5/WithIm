# F-002 반경 10km 시세 조회

## 목적

차량 위치 반경 10km 이내 아파트 단지의 실거래가를 조회해 순위 경쟁과 관심 매물 판정에 제공한다.

## 사용자 가치

- 이동하는 지역의 아파트 시세를 따로 검색하지 않아도 알 수 있다.

## 비즈니스 규칙

1. 조회 반경은 차량 위치 기준 10km이다.
2. T-027의 순위 가격은 최근 1개월 단지별 최고 매매 실거래 총액이다. 평형별 대표값 정책은 후속 결정이다.
3. 실거래가는 신고 이후 공개되므로 '실시간'은 위치 변화에 따른 실시간 갱신을 뜻한다.
4. 현재 위치의 10km 원을 감싼 경계 상자를 Vworld 시군구 경계 레이어(`LT_C_ADSIGG_INFO`)에 조회해 교차 시군구 코드를 얻는다. 각 코드에 대해 걸치는 계약 연월의 국토부 거래를 조회하고, 실제 거래 좌표가 10km 이내인지 다시 거른다. 같은 기간·코드의 월별 원본은 메모리에서 재사용한다.
5. 요청에는 재시도와 타임아웃을 적용한다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 현재 위치 | F-001 |
| 출력 | 단지 목록 | 단지명, Vworld 좌표, 실제 거래금액·거래일·전용면적 환산평. 세대수는 국토부 거래 응답에 없어 미제공 |
| 출력 | 데이터 조회 시각 | 거래일 범위·전달받은 차량 위치와 함께 화면에 표시 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 전달받은 차량 위치 기준 10km 조회 후 홈에 표시 |
| Drive | 위치 갱신마다 지도 중심을 바꾸고, 500m 이상 이동·10km 경계 통과 시 순위 재평가 |
| 오프라인 | 마지막 실제 결과가 있으면 조회 시각·오류와 함께 표시. 없으면 오류 상태 |
| API 미지원 | 해당 없음 |
| 백그라운드 | 알림이 켜진 경우 캐시 범위만 갱신 |

## 예외

- 반경 안에 단지가 없으면 빈 상태를 표시한다.
- 응답이 늦으면 마지막 결과를 유지하고 갱신 중임을 표시한다(DG-005).

## 인수 조건

- [ ] 반경 10km 밖의 단지는 결과에 포함되지 않는다.
- [ ] 오프라인에서 마지막 결과와 기준 시각이 표시된다.
- [ ] 같은 조회기간·지역의 월별 원본은 위치 갱신 시 재사용한다.
