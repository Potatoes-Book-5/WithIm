# F-002 현재 구 3km 시세 조회

## 목적

차량 위치 반경 3km 이내 아파트 단지의 실거래가를 조회해 순위 경쟁과 관심 매물 판정에 제공한다.

## 사용자 가치

- 이동하는 지역의 아파트 시세를 따로 검색하지 않아도 알 수 있다.

## 비즈니스 규칙

1. 조회 반경은 차량 위치 기준 3km이다.
2. T-038부터 순위 가격은 최근 3개월 단지별 최고 매매 실거래 총액이다. 평형별 대표값 정책은 후속 결정이다.
3. 실거래가는 신고 이후 공개되므로 '실시간'은 위치 변화에 따른 실시간 갱신을 뜻한다.
4. Vworld 시군구 경계 레이어(LT_C_ADSIGG_INFO)의 POINT 공간 필터로 현재 구를 판별한다. 확정된 구의 월별 거래를 조회하고 현재 위치 직선거리 3km 이내인지 거른다. 같은 기간·코드의 원본은 메모리에서 재사용한다.
5. 요청에는 재시도와 타임아웃을 적용한다.

T-036에서는 구·거래월별 응답을 실제 수신 완료 시각부터 5분 동안 메모리에서 재사용한다. 진행 중인 조회는 응답·오류·타임아웃까지 처리하고 밀린 재계산 요청은 최신 위치 한 개로 합친다(A 진행 중 B·C·D가 오면 A→D). 지역·출처가 바뀌어도 진행 중인 네트워크 호출은 유지하되 세대·라운드·위치 검증으로 이전 결과가 새 순위를 덮지 않게 한다. 위치가 무효해지면 새로운 경계 조회는 보내지 않는다. 앱 실행 스코프 종료·위치 동의 철회·권한 상실 시 작업은 취소한다. 지도와 이미 확인된 단지의 거리는 매 유효 위치에서 계산한다. 처음 방문한 지역·주소는 서버 조회가 필요하며 즉시 응답을 보장하지 않는다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 현재 위치 | F-001 |
| 출력 | 단지 목록 | 단지명, Vworld 좌표, 실제 거래금액·거래일·전용면적 환산평. 세대수는 국토부 거래 응답에 없어 미제공 |
| 출력 | 데이터 조회 시각 | 거래일 범위·전달받은 차량 위치와 함께 화면에 표시 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 전달받은 차량 위치 기준 3km 조회 후 홈에 표시 |
| Drive | 위치 갱신마다 지도 중심을 바꾸고, 500m 이상 이동·3km 경계 통과 시 순위 재평가 |
| 오프라인 | 마지막 실제 결과가 있으면 조회 시각·오류와 함께 표시. 없으면 오류 상태 |
| API 미지원 | 해당 없음 |
| 백그라운드 | 알림이 켜진 경우 캐시 범위만 갱신 |

## 예외

- 반경 안에 단지가 없으면 빈 상태를 표시한다.
- 응답이 늦으면 마지막 결과를 유지하고 갱신 중임을 표시한다(DG-005).

## 인수 조건

- [ ] 반경 3km 밖의 단지는 결과에 포함되지 않는다.
- [ ] 오프라인에서 마지막 결과와 기준 시각이 표시된다.
- [ ] 같은 조회기간·지역의 월별 원본은 위치 갱신 시 재사용한다.

- [ ] 평형별 대표값 산정 방식
- [ ] 캐시 유효 기간
- [ ] 반경 3km 판정 기준(직선 거리 여부)


## T-031 적용 기준

T-031은 기존 경계 상자 교차 조회를 현재 소재 시군구 판별로 대체한다. Vworld Data API의 POINT(경도 위도) 필터와 LT_C_ADSIGG_INFO로 공식 시군구 코드를 확인하고, 확정된 코드 한 개의 최근 3개월 거래를 조회한다. 해당 구 소속이며 현재 위치 직선거리 3km 안인 거래만 순위·지도·관심 매물 후보로 사용한다. 구가 없는 시·군에서는 같은 시군구 코드 단위를 쓴다.

처음 확인된 지역은 즉시 시작한다. 다른 지역으로 진입하면 유효 위치와 공식 지역 판별이 30초 동안 연속 확인돼야 전환한다. 확인 사이 간격이 15초를 넘거나 위치가 불확실해지면 대기 시간을 다시 센다. 경계 판별 API는 위치 입력과 별도로 최대 5초마다 요청하며, 지도는 매 유효 위치를 따라간다. 최근 거래가 없으면 빈 결과를 표시하고 기간·반경을 늘리지 않는다.
