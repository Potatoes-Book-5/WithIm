# F-006 알림과 TTS 안내

## 목적

추천 매물 발견(F-005/F-010)과 대장 교체(F-003)를 짧은 화면 알림과 TTS로 전달한다.

## 사용자 가치

- 운전 중 화면을 보지 않고도 소식을 듣는다.
- 동승한 배우자도 함께 듣고 이야기할 수 있다.

## 비즈니스 규칙

1. 알림 종류는 '추천 매물 발견'과 '대장 교체' 두 가지이다.
2. 추천 매물 TTS는 ‘{단지명}, 스크랩할까요?’로, 대장 발견·교체 TTS는 ‘새로운 대장 아파트를 발견했어요. {단지명}입니다.’로 안내한다(2026-11-15 사용자 후속 요청). 초기화 포함 10초 안에 끝내고 대기열은 만들지 않는다. 위치 동의와 해당 종류의 알림 설정이 켜져 있고 배너가 보일 때만 재생한다.
3. 화면 알림은 자동으로 사라진다. 표시 시간은 대장 교체 10초(2026-11-14 사용자 결정), 추천 매물 발견 15초(T-041 후속, TTS 질문과 음성 명령 시간 확보)이다.
4. 내비게이션 안내 중에는 끼어들지 않고 오디오 포커스 정책을 따른다.
5. 추천 질문 중에는 같은 단지를 15초 동안 유지한다. 다른 추천·대장 알림이 끼어들지 않으며 발견 기록은 주행 요약에 남긴다. 화면을 나가면 즉시 닫고 음성을 중단한다.
6. 광고로 보이는 표현을 쓰지 않는다(DG-010).
7. 사용자는 알림 종류별로 켜고 끌 수 있다(F-007).

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 알림 이벤트 | F-003, F-005, F-010 |
| 출력 | TTS 재생 | TextToSpeech SDK |
| 출력 | 화면 알림 | SCR-005 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 화면 알림만 표시, TTS 선택 |
| Drive | TTS와 간소 알림, 주행 중 허용 범위는 T-001 답변 후 확정 |
| 오프라인 | 캐시 기반 이벤트만 알림 |
| API 미지원 | TTS는 전체 호환(CP-003) |
| 백그라운드 | 허용 여부 미확정(T-001) |

## 예외

- 오디오 포커스를 얻지 못하면 TTS를 건너뛰고 화면 알림만 표시한다.
- 재생 중 포커스를 잃으면 즉시 중단하고 다시 읽지 않는다(제안값).

## 인수 조건

- [ ] 두 알림 종류의 문구가 정해진 길이를 넘지 않는다.
- [ ] 내비 안내 재생 중에는 TTS가 끼어들지 않는다.
- [ ] 꺼 둔 알림 종류는 재생되지 않는다.
