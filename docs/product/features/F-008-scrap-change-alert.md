# F-008 스크랩과 변동 알림

## 목적

관심 있는 단지를 스크랩해 두고, 앱을 다시 열었을 때 그 단지 정보에 변동이 있으면 알려 준다.

## 사용자 가치

- 임장 중 눈여겨본 단지를 나중에 다시 확인한다.
- 스크랩한 단지의 새 거래 소식을 놓치지 않는다.

## 비즈니스 규칙

1. 스크랩은 홈, 상세, 주행 요약, 알림에서 할 수 있다.
2. 주행 중 스크랩은 한 번의 탭 또는 음성으로만 가능하며 허용 여부는 T-001 답변 후 확정한다.
3. 변동은 '새 실거래 등록', '가격 변화', '순위 변화'로 정의한다.
4. 앱 실행 시 스크랩 단지의 변동을 확인하고 홈에 변동 건수를 표시한다.
5. 확인한 변동은 '읽음'으로 표시해 다시 강조하지 않는다.
6. 스크랩 목록은 기기에 저장한다(제안값).

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 스크랩 요청 | 단지 ID |
| 입력 | 최신 시세 | F-002 |
| 출력 | 스크랩 목록 | 단지, 스크랩 시각, 마지막 확인 값 |
| 출력 | 변동 목록 | 단지, 변동 종류, 이전 값, 현재 값 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 스크랩, 목록 확인, 변동 확인 |
| Drive | 스크랩만 가능(미확정), 목록 진입 불가 |
| 오프라인 | 목록 표시, 변동 확인은 연결 후 |
| API 미지원 | 해당 없음 |
| 백그라운드 | 변동 확인하지 않음(제안값) |

## 예외

- 스크랩 단지 데이터가 사라지면 '정보 없음'으로 표시하고 목록에서 지우지 않는다.

## 인수 조건

- [ ] 스크랩한 단지가 앱 재실행 후에도 유지된다.
- [ ] 새 실거래가 등록되면 다음 실행 시 변동으로 표시된다.
- [ ] 확인한 변동은 다시 강조되지 않는다.
