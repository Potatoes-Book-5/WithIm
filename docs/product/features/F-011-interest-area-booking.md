# F-011 관심 지역 저장과 진입 알림

## 목적

법정동/역세권을 관심 지역으로 저장하고 진입 이벤트를 만든다. 단지 스크랩(F-008), 단지 근접 판정(F-005)과 별도 기능이다.

## 사용자 가치

- 마음에 든 동네를 이동 중 기억하고 다음 방문/브리핑에 연결한다.

## 비즈니스 규칙

### R-02 — 지역 저장

- 트리거: ‘이 동네 관심 지역으로 저장해 줘’ 또는 허용된 저장 버튼 1회 탭.
- 저장 전 확정된 AreaContext를 사용하여 실행 중 차량 이동으로 다른 지역이 저장되지 않게 한다.
- 저장 위치는 활성 프로필이다. 부부 공유 계정/가족 동기화는 별도 결정 전까지 제공하지 않는다.
- 동일 지역 재요청은 추가 행을 만들지 않고 ‘이미 저장한 지역’으로 응답한다. 저장 실패는 success를 반환하지 않는다.
- 오프라인 로컬 저장을 지원한다. 권한이나 프로필이 바뀌면 완료 전 다시 검사하고 이전 프로필 결과를 숨긴다.
- 주행 중 단일 탭/음성 저장은 승인 조건부다. 주차 후 목록·삭제·설정을 제공한다.
- 인수 조건: 성공 후 재시작해도 저장 항목이 남고, 응답에 실제 저장 지역이 명시된다. 분석 자료가 없을 때 ‘상세 리포트 완성’을 약속하지 않는다.

### R-03 — 영역 진입

- 트리거: 활성 프로필에 등록된 관심 영역의 outside→inside 전이.
- 법정동 저장은 경계 기반, 역세권 저장은 중심+반경 기반이다. 제안 초기 역세권 반경은 500m이다. 동 경계를 원형 진입 API에 그대로 전달하지 않는다. 지원 API의 공간 표현과 경계 계산 위치는 구현 시 확정한다.
- 원형 영역은 정확한 경계 거리 `d <= 500m`에서 내부, `d >= 600m`에서 외부로 재무장하는 히스테리시스를 제안한다. 첫 기동 시 이미 내부라면 진입 알림을 발생시키지 않는다.
- 동일 프로필·동일 지역의 알림은 10분에 최대 1회. 같은 주행에서 이탈/재진입해도 최소 간격을 적용한다. 진입 감지와 오디오 실제 재생을 별도로 기록한다.
- Gleo 자동 발화는 미확인이다. 앱 자체 TTS 대안도 주행·오디오·백그라운드 허용 검증 후에만 사용한다. 검증 전에는 주차 후 앱 내 진입 기록으로 확인한다.
- 오프라인은 유효한 위치·캐시로 계산한다. 위치 SDK 미지원/권한 철회 시 진입 감지를 중단한다. 프로세스 종료 중 이벤트 전달/재등록은 실제 SDK·플랫폼 검증 항목이다.
- 인수 조건: GPS 경계 흔들림으로 알림이 반복되지 않으며, 비활성 프로필 이벤트나 만료된 위치로 발화하지 않는다.

가격 왕관과 맞춤 후보는 F-003/F-004, 화면은 SCR-004/SCR-005에서 정의한다. 수치 제안 원본은 [기본값](../gleo-tour-defaults.md)이다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 확정 AreaContext | F-010의 명시 지역/대화 문맥/현재 위치 |
| 저장 | InterestArea | profileId, stableAreaId, 명칭, 경계 또는 중심+반경, 저장 시각, 알림 설정 |
| 출력 | 저장 결과·진입 이벤트 | 영속 저장 결과, 진입/발화 시각 분리 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 지역 저장·목록·삭제. 진입 기록 확인 |
| Drive / 신호 대기 | 음성/단일 탭 저장과 진입 알림은 허용 확인 전 비활성 |
| 오프라인 | 유효 문맥으로 로컬 저장. 유효 위치/캐시만 진입 판정 |
| API 미지원 | 현재 위치/진입 비활성, 주차 후 명시 지역 선택 |
| 백그라운드 | 이벤트 전달·재등록·FGS 조건 검증 전 비활성 |

## 예외

- 저장 실패 시 완료 응답 금지. 중복 요청은 `(profileId, stableAreaId)` 유일 제약으로 1건만 유지한다.
- 삭제/프로필 전환/권한 철회 후 지연 이벤트는 폐기한다.
- 첫 시작부터 영역 안이면 진입 알림을 발생시키지 않는다.

## 인수 조건

- [ ] 저장 성공 후 프로세스 재시작에도 동일 지역이 남는다.
- [ ] GPS 흔들림/재진입이 알림 최소 간격을 우회하지 않는다.
- [ ] 유효한 직전 문맥과 명시적 현재 위치 요청을 구분한다.
- [ ] 자동 발화 미지원에서는 기록만 제공하고 발화를 가장하지 않는다.
