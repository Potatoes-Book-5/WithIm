# F-005 관심 매물 근접 판정

## 목적

차량 주변에서 관심 조건 적합도가 높은 추천 단지가 가까워지면 알림 후보를 만든다.

## 사용자 가치

- 지나가는 길에 우리 조건에 맞는 단지를 놓치지 않는다.

## 비즈니스 규칙

1. 추천 후보 상위 3개(F-010) 중 실제 차량에서 가까운 단지를 판정한다. 추천 후보 검색 범위는 10km이다.
2. 알림 거리는 제안값 2km이다.
3. 같은 단지는 한 번 알린 뒤 일정 기간 다시 알리지 않는다. 기간은 제안값 24시간이다.
4. 스크랩한 단지는 근접 알림 대신 변동 알림(F-008)으로 다룬다.
5. 판정은 위치 갱신 이벤트에서만 수행하고 폴링하지 않는다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 현재 위치, 추천 후보 상위 3개, 관심 조건 | F-001, F-002, F-004, F-010 |
| 출력 | 알림 후보 | 단지, 거리, 일치 조건 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 판정하지 않음 |
| Drive | 위치 갱신 시 판정 |
| 오프라인 | 캐시 범위 안에서만 판정 |
| API 미지원 | 위치 미지원 시 비활성 |
| 백그라운드 | 알림이 켜진 경우에만 판정 |

## 예외

- 관심 조건이 없으면 판정하지 않는다.

## 인수 조건

- [ ] 추천 상위 3개 중 알림 거리 안에 든 단지만 후보가 된다.
- [ ] 재알림 억제 기간 안에는 같은 단지가 후보가 되지 않는다.
- [ ] 판정 로직은 JVM 단위 테스트로 검증된다.

## 관련 문서

- 규칙: SM-007, SM-008, PF-002
