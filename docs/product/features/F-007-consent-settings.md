# F-007 동의와 설정

## 목적

첫 실행 시 위치 사용과 알림에 동의를 받고, 알림 종류와 데이터 삭제를 설정한다.

## 사용자 가치

- 무엇을 왜 수집하는지 알고 시작한다.

## 비즈니스 규칙

1. 첫 실행 시 위치 사용 이유를 한 화면에 설명하고 동의를 받는다(SP-003).
2. 알림 설정은 관심 매물 발견, 대장 교체, TTS 사용 여부로 나눈다.
3. 저장된 조건, 스크랩, 주행 기록과 기기 내 추천 반응 집계를 한 번에 삭제할 수 있다(SP-001, SP-004).
4. 설정 변경은 주차 중에만 가능하다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 동의 여부, 알림 설정 | 사용자 선택 |
| 출력 | 설정값 | 기기 저장 |
| 삭제 | 추천 반응 집계 | 추천 상세 열기 횟수와 추천 속성 스냅샷. 기기 내 저장이며 사용자 데이터 삭제 시 함께 삭제 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 설정 가능 |
| Drive | 진입 불가. 앱이 DO를 선언해 앱이 직접 막는다. 온보딩 전 첫 동의 화면이면 주차 안내만 보여 준다(T-035) |
| 오프라인 | 설정 가능 |
| API 미지원 | 해당 없음 |
| 백그라운드 | 해당 없음 |

## 예외

- 동의를 거부하면 위치 기반 기능 없이 스크랩 목록만 사용할 수 있다.

## 인수 조건

- [ ] 동의 전에는 위치를 요청하지 않는다.
- [x] 데이터 삭제 후 조건, 스크랩, 기록이 모두 비어 있다(T-019, 단위·기기 테스트).
- [x] 데이터 삭제 후 추천 반응 집계도 비어 있다(T-047).
