# F-007 동의와 설정

## 목적

첫 실행 시 위치 사용과 알림에 동의를 받고, 알림 종류와 데이터 삭제를 설정한다.

## 사용자 가치

- 무엇을 왜 수집하는지 알고 시작한다.

## 비즈니스 규칙

1. 첫 실행 시 위치 사용 이유를 한 화면에 설명하고 동의를 받는다(SP-003).
2. 알림 설정은 관심 매물 발견, 대장 교체, TTS 사용 여부로 나눈다.
3. 저장된 조건, 스크랩, 주행 기록을 한 번에 삭제할 수 있다(SP-001).
4. 설정 변경은 주차 중에만 가능하다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 동의 여부, 알림 설정 | 사용자 선택 |
| 출력 | 설정값 | 기기 저장 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 설정 가능 |
| Drive | 진입 불가 |
| 오프라인 | 설정 가능 |
| API 미지원 | 해당 없음 |
| 백그라운드 | 해당 없음 |

## 예외

- 동의를 거부하면 위치 기반 기능 없이 스크랩 목록만 사용할 수 있다.

## 인수 조건

- [ ] 동의 전에는 위치를 요청하지 않는다.
- [x] 데이터 삭제 후 조건, 스크랩, 기록이 모두 비어 있다(T-019, 단위·기기 테스트).

## R-PRIVACY — S-011 검토용 확장

위치 기반 조회, 위치/관심 지역 저장, 선택적 자동 알림의 동의를 구분한다. MVP는 로컬 프로필을 사용한다는 제안이며 저장/보관/삭제 정책은 사람 검토 후 확정한다. 원시 주행 경로·음성 녹음은 MVP에서 저장하지 않는다. 로그에는 좌표·선호 예산·관심 지역명·개인 식별값을 기본 기록하지 않는다. 삭제 시 관심 지역·관련 문맥·예약 알림·브리핑 열람 이력을 삭제하며 공급자의 공용 가격 자료와 개인 자료를 구분한다. 프로필 전환 시 이전 프로필의 화면·진행 요청·알림을 무효화한다.

위 문단은 개인정보 처리 방식의 승인된 결정이 아닌 제품 검토 초안이다. 기존 단지 스크랩/조건 설정과 관심 지역 저장(F-011)을 구분하고, 자동 진입 알림과 자동 브리핑(F-013)은 별도 opt-in 후보로 표시한다. 실제 보관기간·공유·계정 정책 확정 전 기능을 활성화하지 않는다.

- [ ] 프로필 전환 중 늦은 저장/브리핑/진입 결과를 새 프로필에 노출하지 않는다.
- [ ] 삭제 후 관련 문맥·예약 알림·열람 이력이 남아 발화되지 않는다.
- [ ] 원시 좌표 경로·음성/카메라 기록을 MVP에서 생성하지 않는다.
