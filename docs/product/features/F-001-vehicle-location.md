# F-001 차량 위치 획득

## 목적

차량의 현재 위치와 이동 여부를 얻어 시세 조회, 순위 경쟁, 관심 매물 판정의 기준점으로 제공한다.

## 사용자 가치

- 별도 입력 없이 지금 있는 곳 기준으로 정보를 받는다.

## 비즈니스 규칙

1. T-027는 GPS를 직접 획득하지 않는다. 친구가 Pleos SDK 위치 콜백을 `vehicle/`의 `VehicleLocationInput.updateLocation`으로 연결한다. 앱은 같은 `VehicleLocationProvider` 포트에서 전달받은 위치를 처리한다.
2. 위치 사용 동의(F-007)가 없으면 전달된 위치를 시세 계산에 사용하지 않는다. 위치 권한 획득·미지원 판정은 SDK 연결 측이 담당하고 상태를 입력 포트로 알린다.
3. 유효한 위치가 들어올 때마다 지도상의 현재 위치를 갱신한다. 시세 순위 재계산은 기준점에서 500m 이상 이동하거나 10km 포함 경계를 넘을 때 수행한다(T-027).
4. 현재 국토부·Vworld 요청에는 차량 위치 원좌표를 보내지 않는다. 지역 코드와 거래 주소로 조회하고 기기 안에서 거리를 계산한다.
5. 현재 단계에서 GPS 원좌표와 Vworld 변환 좌표는 영구 저장하지 않는다. 주행 요약(F-009)에 필요한 위치 이력 정책은 별도로 정한다.
6. 사용 가능한 차량 위치가 없으면 삼성전자 수원 본사(ADR-007)를 임시 조회 기준으로 사용한다. 화면에 임시 기준임을 표시하고 차량 위치로 표시하거나 근접·대장 교체 알림 및 주행 기록의 근거로 사용하지 않는다. 유효한 차량 위치가 들어오면 즉시 그 위치로 전환한다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 외부 차량 위치 콜백 | 위도, 경도, 정확도(m), 관측 시각, 출처. Pleos SDK 연결은 친구 담당 |
| 출력 | 현재 위치 상태 | domain `VehicleLocationState` (`AVAILABLE`, 동의 필요, 오래됨, 부정확 등) |
| 출력 | 이동 이벤트 | 기준 거리 이상 이동 시 발생 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 외부에서 전달한 유효 위치를 시세 기준점으로 사용 |
| Drive | 전달받은 유효 위치마다 지도 중심 갱신. 주행 상태 전환은 현재 개발용 수동 입력 |
| 오프라인 | 전달 위치와 시세 API 오류를 구분해 표시 |
| API 미지원 | 삼성전자 수원 본사 기준 실거래 순위만 표시하고 차량 위치 기반 알림은 끈다(S-006) |
| 백그라운드 | 위치 콜백의 수명주기와 백그라운드 알림은 SDK 담당자와 후속 결정 |

## 예외

- 위치 정확도가 100m를 초과하거나 관측 시각이 30초를 넘으면 실제 차량 위치 기준 순위 갱신과 근접 판정을 보류하고 삼성전자 임시 기준으로 조회한다.
- 권한이 철회되거나 SDK가 위치를 제공할 수 없으면 입력 포트에 해당 상태를 전달한다. 이때 실제 차량 위치 기반 결과와 근접 알림은 중단하고 삼성전자 임시 기준 순위를 표시한다.

## 인수 조건

- [ ] 차량 위치를 사용할 수 없는 환경에서 앱이 종료되지 않고 삼성전자 임시 기준과 차량 위치 대기 안내를 표시한다.
- [ ] 기준 거리 미만 이동에서는 갱신 이벤트가 발생하지 않는다.
- [ ] 동의 전에는 전달 위치를 시세 계산에 사용하지 않는다.

## 미결 사항

- [ ] 갱신 기준 거리 확정
- [x] Pleos 위치 API 지원 여부·권한 상태를 입력 포트 상태와 연결(T-029 `PleosFusedLocationBridge`)
- [ ] 주행 방향 정보 필요 여부. SDK `heading`은 단위가 문서에 없어 T-029는 진행 방향을 미확인(null)으로 넘긴다.
- [x] Pleos 위치 콜백을 `VehicleLocationInput.updateLocation`에 연결(T-029)
- [ ] 위치 정확도 기준(제안값 100m): SDK `confidence`의 단위가 문서에 없어 적용하지 못한다. T-029는 정확도를 미제공(null)으로 넘긴다.
- [ ] 이동 거리 기준 갱신(규칙 3): SDK에 갱신 주기·거리 설정 API가 문서에 없다. T-029는 받은 위치를 입력 포트로 넘기고, 시세 재계산 기준은 T-027이 맡는다.
