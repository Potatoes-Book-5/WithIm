# F-001 차량 위치 획득

## 목적

차량의 현재 위치와 이동 여부를 얻어 시세 조회, 순위 경쟁, 관심 매물 판정의 기준점으로 제공한다.

## 사용자 가치

- 별도 입력 없이 지금 있는 곳 기준으로 정보를 받는다.

## 비즈니스 규칙

1. 위치는 Pleos FusedLocation SDK로 얻고, 사용 전 `isSupported`로 지원 여부를 확인한다.
2. 위치 사용 동의(F-007)가 없으면 위치를 수집하지 않는다.
3. 일반 순위 재계산 이벤트는 이동 거리 기준으로 제한한다. 기준 거리는 제안값 500m이다. 이 억제값을 현재 위치 재획득이나 F-011의 진입 경계 감지에 적용하지 않는다. SDK 위치 갱신·진입 이벤트 전달 방식은 실제 지원을 검증한다.
4. 위치 좌표는 기기 밖으로 보낼 때 시세 조회에 필요한 정밀도로만 보낸다.
5. 원시 좌표 경로는 저장하지 않는 초안을 제안한다. 주행 요약(F-009)에 필요한 순위/관심 이벤트와 집계값만 유지하며 실제 보관 정책은 F-007에서 검토한다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | FusedLocation 위치 | 위도, 경도, 정확도, 시각 |
| 출력 | 현재 위치 | domain `VehicleLocation` |
| 출력 | 이동 이벤트 | 기준 거리 이상 이동 시 발생 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 앱 실행 시 1회 조회 |
| Drive | 이동 거리 기준으로 갱신 |
| 오프라인 | 위치는 계속 수집하고 조회는 F-002에서 대기 |
| API 미지원 | 위치 기반 기능을 끄고 안내 화면 표시(S-006) |
| 백그라운드 | 알림 기능이 켜진 경우에만 갱신, 그 외 중단 |

## 예외

- 일반 순위 갱신은 위치 오차 제안값 100m 초과에서 보류한다. 현재 법정동 확정/지역 진입은 더 엄격한 [Gleo 기본값](../gleo-tour-defaults.md)을 사용하며 마지막 위치를 새 위치로 오인하지 않는다.
- 신뢰도 필드의 단위와 정규화 경로를 실제 SDK에서 확인한다. SDK가 오차 반경(m)을 직접 제공한다고 가정하지 않는다.
- 권한이 철회되면 위치 기반 기능을 끄고 SCR-006으로 안내한다.

## 인수 조건

- [ ] 지원되지 않는 차량에서 앱이 종료되지 않고 미지원 안내를 표시한다.
- [ ] 일반 순위 재계산은 기준 거리 미만에서 억제되지만 현재 위치 요청과 지역 진입 감지를 막지 않는다.
- [ ] 동의 전에는 위치를 요청하지 않는다.

## 관련 문서

## 미결 사항

- [ ] 갱신 기준 거리 확정
- [ ] FusedLocation 미지원 차량의 대체 경로
- [ ] 주행 방향 정보 필요 여부

## Gleo 임장 연결

현재 지역 요청의 스냅샷·freshness·문맥은 [F-010](F-010-gleo-app-control.md), 저장/진입은 [F-011](F-011-interest-area-booking.md)을 따른다. 주행/백그라운드는 [상태 매트릭스](../feature-state-matrix.md)와 실제 SDK 허용이 전제다.
