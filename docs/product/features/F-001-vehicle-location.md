# F-001 차량 위치 획득

## 목적

차량의 현재 위치와 이동 여부를 얻어 시세 조회, 순위 경쟁, 관심 매물 판정의 기준점으로 제공한다.

## 사용자 가치

- 별도 입력 없이 지금 있는 곳 기준으로 정보를 받는다.

## 비즈니스 규칙

1. 위치는 Pleos FusedLocation SDK로 얻고, 사용 전 `isSupported`로 지원 여부를 확인한다.
2. 위치 사용 동의(F-007)가 없으면 위치를 수집하지 않는다.
3. 갱신은 시간 주기가 아니라 이동 거리 기준으로 요청한다. 기준 거리는 제안값 500m이다.
4. 위치 좌표는 기기 밖으로 보낼 때 시세 조회에 필요한 정밀도로만 보낸다.
5. 위치 이력은 주행 요약(F-009)에 필요한 범위만 기기에 저장한다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | FusedLocation 위치 | 위도, 경도, 정확도, 시각 |
| 출력 | 현재 위치 | domain `VehicleLocation` |
| 출력 | 이동 이벤트 | 기준 거리 이상 이동 시 발생 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 앱 실행 시 1회 조회 |
| Drive | 이동 거리 기준으로 갱신 |
| 오프라인 | 위치는 계속 수집하고 조회는 F-002에서 대기 |
| API 미지원 | 위치 기반 기능을 끄고 안내 화면 표시(S-006) |
| 백그라운드 | 알림 기능이 켜진 경우에만 갱신, 그 외 중단 |

## 예외

- 위치 정확도가 낮으면(제안값 100m 초과) 순위 갱신과 근접 판정을 보류한다.
- 권한이 철회되면 위치 기반 기능을 끄고 SCR-006으로 안내한다.

## 인수 조건

- [ ] 지원되지 않는 차량에서 앱이 종료되지 않고 미지원 안내를 표시한다.
- [ ] 기준 거리 미만 이동에서는 갱신 이벤트가 발생하지 않는다.
- [ ] 동의 전에는 위치를 요청하지 않는다.
