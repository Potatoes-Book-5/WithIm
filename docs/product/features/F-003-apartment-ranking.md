# F-003 아파트 가격 순위 경쟁

## 목적

차량이 이동하는 동안 반경 3km 안의 아파트 가격 1~3위를 실시간으로 갱신하고 기록한다. 1위 단지를 '대장 아파트'로 부른다.

## 사용자 가치

- 이동하면서 지역별 대장 아파트가 어떻게 바뀌는지 게임처럼 확인한다.
- 주행이 끝나면 지나온 지역의 순위를 한눈에 돌아본다.

## 비즈니스 규칙

1. 순위 대상은 반경 3km 안의 아파트 단지이고, 기준은 F-002의 가격 기준이다.
2. 순위 탭·홈·기록은 1~3위를 다룬다. 지도 탭은 기존 순위 행과 실제 좌표 마커로 최대 5위까지 보여 준다(T-037, 사용자 결정). 조회 반경과 대장 판정은 같다.
3. 현재 단계에서는 외부에서 전달된 유효 위치를 매 갱신 반영하고, 순위는 500m 이상 이동 또는 반경 3km 경계 통과 시 다시 계산한다(T-027).
4. 1위 단지가 바뀌면 '대장 교체' 이벤트를 만들어 F-006으로 알린다.
5. 대장 교체 알림은 짧은 시간 안에 반복되지 않게 제한한다. 최소 간격은 제안값 5분이다.
6. 주행 세션 동안의 순위 변화와 대장 교체 이력을 F-009에 기록한다.
7. 동률이면 거래일이 최근인 단지를 우선한다(제안값).
8. 주행 중에는 `순위`와 `지도` 두 보기를 전환할 수 있다. 지도 보기는 차량과 Top 3, 관심 매물의 상대 위치를 보여 준다(SCR-009).

### 현재 단계의 실거래 순위 (T-027)

세 달 전 날짜부터 오늘까지(양 끝 포함)의 실제 거래를 사용한다. 기간에 포함된 각 계약 연월의 응답을 합치고 거래일로 다시 거른다. 현재 위치가 속한 시군구를 Vworld POINT 공간 필터로 확인하고 30초 안정화로 확정된 구의 국토부 거래를 조회한다. 외부에서 전달받은 현재 차량 위치에서 직선거리 3km 이내인 거래만 최종 포함한다. 해제된 거래는 제외한다. 단지별 최고 거래 총액(만원)을 기준으로 Top 3를 정하며 동률이면 거래일 최신순이다. 홈 카드·주행 카드·네이버 지도 단지 마커·오른쪽 실거래 표·상세는 이 실제 거래 흐름을 공유한다. 유효 위치가 바뀌면 지도 중심을 갱신하고, 기준점에서 500m 이상 이동하거나 반경 3km 경계를 넘으면 순위를 다시 평가한다. 진행 방향이 없으면 앞·뒤를 추정하지 않는다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 단지 목록 | F-002 |
| 출력 | Top 3 | 순위, 단지명, 가격, 직전 대비 변화 |
| 출력 | 대장 교체 이벤트 | 이전 대장, 새 대장, 시각, 위치 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 홈에 현재 Top 3 표시 |

| 오프라인 | 캐시 기준으로 계산하고 기준 시각 표시 |

## 예외

- 반경 안 단지가 3개 미만이면 있는 만큼만 표시한다.
- 최근 거래가 없는 지역에서는 순위를 비우고 '거래 없음'을 표시한다. 이전 지역 결과를 현재 지역 순위로 표시하지 않는다.

## 인수 조건

- [ ] 위치 이동 후 Top 3가 다시 계산된다.
- [ ] 1위가 바뀌면 대장 교체 이벤트가 한 번 생성된다.
- [ ] 최소 간격 안의 반복 교체는 알림 없이 기록만 된다.
- [ ] 주행 종료 시 세션 기록이 F-009에 전달된다.

## T-031 지역 라운드

- 순위는 확정된 현재 시군구 안의 직선거리 3km 후보로 제한한다. 다른 구의 단지는 가까워도 포함하지 않는다.
- 구 경계 전환은 F-002의 30초 안정화 규칙을 따른다. 같은 구를 다시 방문해도 별도 라운드다.
- 새 라운드에서 첫 유효 1위가 나오면 '새 지역 대장 발견', 같은 라운드에서 1위가 바뀌면 '대장 교체'다. 지역 발견은 이전 구와 가격으로 겨루는 사건이 아니다.
- 지역 전환 시 교체 알림의 이전 대장과 5분 억제를 초기화한다. 같은 지역 내 교체의 5분 억제는 유지한다.
- 지도 축척은 근거리 배율(최소 줌 18.5)로 고정한다. 3km 순위의 단지를 모두 담으려고 자동 축소하지 않는다.
- 지역별 최고가 기록과 주행 전체 최고가는 F-009에 보존한다. 실제 차량 위치가 없는 임시 기준 결과는 주행 기록·대장 알림에서 제외한다.
