# F-003 아파트 가격 순위 경쟁

## 목적

차량이 이동하는 동안 반경 10km 안의 아파트 가격 1~3위를 실시간으로 갱신하고 기록한다. 1위 단지를 '대장 아파트'로 부른다.

## 사용자 가치

- 이동하면서 지역별 대장 아파트가 어떻게 바뀌는지 게임처럼 확인한다.
- 주행이 끝나면 지나온 지역의 순위를 한눈에 돌아본다.

## 비즈니스 규칙

1. 순위 대상은 반경 10km 안의 아파트 단지이고, 기준은 F-002의 가격 기준이다.
2. 화면과 기록은 1~3위만 다룬다.
3. 위치 갱신 이벤트(F-001)마다 순위를 다시 계산한다.
4. 1위 단지가 바뀌면 '대장 교체' 이벤트를 만들어 F-006으로 알린다.
5. 대장 교체 알림은 짧은 시간 안에 반복되지 않게 제한한다. 최소 간격은 제안값 5분이다.
6. 주행 세션 동안의 순위 변화와 대장 교체 이력을 F-009에 기록한다.
7. 대표값 동률이면 거래일이 최근인 단지, 그래도 같으면 단지 ID 오름차순으로 정렬하고 동률 사실을 유지한다(제안값).
8. 주행 중 `순위`와 `지도` 전환은 미확정이다. 지도 보기는 차량과 Top 3, 관심 매물의 상대 위치를 보여 주는 초안이며 실제 허용 전 비활성이다(SCR-009).

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 단지 목록 | F-002 |
| 출력 | Top 3 | 순위, 단지명, 가격, 직전 대비 변화 |
| 출력 | 대장 교체 이벤트 | 이전 대장, 새 대장, 시각, 위치 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 홈에 현재 Top 3 표시 |
| Drive | 간소 화면에 Top 3만 크게 표시, 교체 시 알림 |
| 오프라인 | 캐시 기준으로 계산하고 기준 시각 표시 |
| API 미지원 | 위치 미지원 시 순위 경쟁 비활성 |
| 백그라운드 | 알림이 켜진 경우 계산 유지, 화면 갱신 중단 |

## 예외

- 반경 안 단지가 3개 미만이면 있는 만큼만 표시한다.
- 데이터가 없는 지역에서는 현재 왕관/순위를 비우고 데이터 없음을 표시한다. 이전 순위를 남기면 과거 지역/기준임을 분리하고 현재 순위로 표시하지 않는다.

## 인수 조건

- [ ] 위치 이동 후 Top 3가 다시 계산된다.
- [ ] 1위가 바뀌면 대장 교체 이벤트가 한 번 생성된다.
- [ ] 최소 간격 안의 반복 교체는 알림 없이 기록만 된다.
- [ ] 주행 종료 시 세션 기록이 F-009에 전달된다.

## S-011 가격 왕관과 추천의 구분

- 대표값·대상 반경·필터는 [F-002의 R-PRICE](F-002-nearby-price-lookup.md)를 따른다.
- 왕관은 현재 가격 순위 1위의 정적 아이콘이다. 최고 단일 거래 단지나 맞춤 추천 1위와 같다고 가정하지 않는다.
- 위치 이동으로 후보가 바뀌어 왕관이 교체되어도 집값 상승으로 읽지 않는다. 주목을 유도하는 애니메이션/강제 화면 전환은 하지 않는다.
- RankingSnapshot은 중심/반경, 대표값 정의, Top 3, 왕관 단지, 데이터 버전을 갖는다.
- 대장 교체 최소 간격은 이 문서의 제안이며, F-011의 지역 진입 알림 간격과 별개다.
- 주행/백그라운드 사용은 [상태 매트릭스](../feature-state-matrix.md)를 따른다. 검증: [S-011 테스트](../../testing/gleo-tour/README.md).
