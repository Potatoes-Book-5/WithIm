# F-004 관심 조건 설정

## 목적

앱 첫 실행 시 관심 있는 부동산 조건(동네, 가격대, 평수)을 설정하고 이후 수정할 수 있게 한다.

## 사용자 가치

- 부부가 함께 원하는 조건을 한 번 정해 두면 이동 중 알아서 알려 준다.

## 비즈니스 규칙

1. 첫 실행 시 동의(F-007) 다음에 조건 설정 화면을 보여 준다. 건너뛸 수 있다.
2. 조건 항목은 동네, 가격대, 평수이며 최소 1개 이상 선택해야 저장된다.
3. 동네는 현재 위치 주변 추천, 최근 지나간 동네, 음성 검색으로 고른다. 키보드 입력은 보조 수단이다.
4. 가격대와 평수는 미리 정한 구간 칩으로 고른다.
5. 조건 수정은 주차 중에만 가능하다.
6. 조건은 기기에 저장하고 서버로 보내지 않는다(제안값).

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 동네 | 행정동 또는 법정동, 여러 개 |
| 입력 | 가격대 | 구간 선택, 여러 개 |
| 입력 | 평수 | 구간 선택, 여러 개 |
| 출력 | 관심 조건 | domain `InterestCondition` |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 설정과 수정 가능 |
| Drive | 수정 불가, 저장된 조건만 사용 |
| 오프라인 | 동네 추천은 캐시 기반, 저장 가능 |
| API 미지원 | 위치 미지원 시 주변 추천 대신 음성 검색 안내 |
| 백그라운드 | 해당 없음 |

## 예외

- 조건 없이 건너뛰면 관심 매물 알림(F-005)은 꺼진 상태로 시작한다.

## 인수 조건

- [ ] 첫 실행 흐름에서 조건 화면이 표시되고 건너뛸 수 있다.
- [ ] 주행 중에는 조건 수정 진입이 막힌다.
- [ ] 앱을 다시 실행해도 저장한 조건이 유지된다.

- [ ] 세대수, 준공연도 추가 조건(마이 페이지 오각형 축, SCR-010)
