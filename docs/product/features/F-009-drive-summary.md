# F-009 주행 요약

## 목적

주행이 끝나면 이번 주행에서 기록된 순위, 대장 교체 이력, 지나친 관심 매물을 정리해 보여 준다.

## 사용자 가치

- 임장을 마친 뒤 함께 결과를 돌아보고 관심 단지를 스크랩한다.

## 비즈니스 규칙

1. 주행 세션은 Drive 전환으로 시작하고, Parking 전환 즉시 종료한다(T-034, 사용자 결정. 이전 제안값 3분). Drive와 Parking은 차량 기어(AAOS `GEAR_SELECTION`)로 정한다. P면 Parking(주행 완료), 그 밖의 기어면 Drive다. 기어를 읽지 못하면 Parking으로 남는다(T-034).
2. 요약에는 주행 거리, 시간, 최종 Top 3, 대장 교체 이력, 지나친 관심 매물과 F-010 추천 후보 최대 3개를 담는다. 실제 노출한 F-010 추천 알림 단지는 지나친 관심 매물에도 기록하며 화면에서는 중복을 제거한다.
3. 요약은 주행 종료 후 앱을 열거나 앱이 화면에 있을 때 표시한다.
4. 요약에서 단지를 바로 스크랩할 수 있다.
5. 요약 기록은 최근 제안값 10건까지 기기에 저장한다.
6. 종료 시각은 주차한 시각이다(T-018). 주차 후 다시 Drive가 되면 새 세션을 시작한다. 짧게 멈췄다 출발해도 세션과 요약이 나뉜다(T-034).
7. 대장 교체는 알림 간격(F-003, 5분)과 알림 동의와 관계없이 모두 기록한다.
8. 지나친 관심 매물은 조건 일치 또는 추천 알림으로 실제 노출된 단지를 모으고 가장 가까웠던 거리를 남긴다.
9. 주행 거리는 위치 SDK가 연결될 때까지 기록하지 않고 화면에서 뺀다. 공식 값이 없어 추정하지 않는다.

저장은 Room `drive_sessions`, `drive_ranks`, `drive_leader_changes`, `drive_passed_interests` 테이블 및 지역 라운드 테이블(v4)에 한다. 자세한 설계는 [T-018 계획](../../plans/active/T-018-drive-summary.md)에 있다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 세션 기록 | F-003, F-005, F-001 |
| 출력 | 주행 요약 | SCR-008 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 요약 표시 |
| Drive | 기록만 수행 |
| 오프라인 | 기록과 표시 가능 |
| API 미지원 | 위치 미지원 시 요약 없음 |
| 백그라운드 | 기록 유지 |

## 예외

- 기록된 순위와 추천 후보가 모두 없으면 요약을 만들지 않는다.
- 주행 중 앱이 종료되면 저장된 지점까지 요약한다(SM-009).

## 인수 조건

- [ ] 주차 전환 즉시 요약이 생성된다.
- [ ] 요약의 대장 교체 횟수가 세션 기록과 일치한다.
- [ ] 요약에서 스크랩한 단지가 스크랩 목록에 나타난다.

## T-031 지역별 기록과 전체 최고가

확정된 각 지역 방문을 drive_region_rounds에 저장하고, 해당 방문 동안 만난 최고가 Top 3를 drive_region_ranks에 남긴다. 지역을 떠나도 이전 기록은 삭제하지 않는다. 원좌표와 변환 좌표는 저장하지 않고 지역 코드·이름·시각·단지와 가격만 기록한다.

drive_leader_changes는 발견(DISCOVERED)과 같은 지역 교체(REPLACED)를 구분하고 지역 이름을 함께 남긴다. 주행 요약의 기존 순위 카드 영역에는 각 라운드를 통틀어 만난 최고가 Top 3를 표시한다. 기존 최종 순위 필드와 이전 기록은 유지한다. 지역 기록이 없는 이전 버전의 요약은 종전 최종 순위를 표시한다.

Room v3→v4 자동 마이그레이션은 두 테이블과 기본값이 있는 사건 종류·지역명 열만 추가하며 기존 스크랩·주행 기록을 삭제하지 않는다. 데이터가 없는 지역으로 끝나더라도 앞선 지역 기록은 보존한다.
