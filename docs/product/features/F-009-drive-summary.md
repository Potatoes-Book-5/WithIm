# F-009 주행 요약

## 목적

주행이 끝나면 이번 주행에서 기록된 순위, 대장 교체 이력, 지나친 관심 매물을 정리해 보여 준다.

## 사용자 가치

- 임장을 마친 뒤 함께 결과를 돌아보고 관심 단지를 스크랩한다.

## 비즈니스 규칙

1. 주행 세션은 Drive 전환으로 시작하고, Parking 전환 후 일정 시간이 지나면 종료한다. 시간은 제안값 3분이다.
2. 요약에는 주행 거리, 시간, 최종 Top 3, 대장 교체 이력, 지나친 관심 매물을 담는다.
3. 요약은 주행 종료 후 앱을 열거나 앱이 화면에 있을 때 표시한다.
4. 요약에서 단지를 바로 스크랩할 수 있다.
5. 요약 기록은 최근 제안값 10건까지 기기에 저장한다.
6. 주차 후 3분 안에 다시 Drive가 되면 같은 세션을 이어 간다. 종료 시각은 주차한 시각이다(T-018).
7. 대장 교체는 알림 간격(F-003, 5분)과 알림 동의와 관계없이 모두 기록한다.
8. 지나친 관심 매물은 세션 동안 본 단지를 모으고 가장 가까웠던 거리를 남긴다.
9. 주행 거리는 위치 SDK가 연결될 때까지 기록하지 않고 화면에서 뺀다. 공식 값이 없어 추정하지 않는다.

저장은 Room `drive_sessions`, `drive_ranks`, `drive_leader_changes`, `drive_passed_interests` 테이블(v3)에 한다. 자세한 설계는 [T-018 계획](../../plans/active/T-018-drive-summary.md)에 있다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 세션 기록 | F-003, F-005, F-001 |
| 출력 | 주행 요약 | SCR-008 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | 요약 표시 |
| Drive | 기록만 수행 |
| 오프라인 | 기록과 표시 가능 |
| API 미지원 | 위치 미지원 시 요약 없음 |
| 백그라운드 | 기록 유지 |

## 예외

- 기록된 순위가 없으면 요약을 만들지 않는다.
- 주행 중 앱이 종료되면 저장된 지점까지 요약한다(SM-009).

## 인수 조건

- [ ] 주차 전환 후 기준 시간이 지나면 요약이 생성된다.
- [ ] 요약의 대장 교체 횟수가 세션 기록과 일치한다.
- [ ] 요약에서 스크랩한 단지가 스크랩 목록에 나타난다.
