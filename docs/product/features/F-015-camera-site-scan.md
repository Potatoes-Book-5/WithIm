# F-015 차량 카메라 현장 스캔

## 목적

선택 단지 주변의 차량 카메라 확인·기록 요구를 추적하는 확장 연구 명세다. 구현·지원·녹화 승인은 없으며 MVP에서 비활성이다.

## 사용자 가치

- 차 밖 환경을 돌아보려는 원 시나리오의 요구를 지원 검증 대상으로 보존한다.

## 비즈니스 규칙

- 원 시나리오의 자동 활성화·스트리밍·녹화를 요구사항으로 보존하되 지원 미확인 상태로 관리한다. MVP에서는 카메라를 열거나 녹화하지 않는다.
- 진입 반경은 선택 단지 중심 500m를 요구값으로 보존한다. 이 반경은 내비 도착 판정과 다르다.
- 구현 전 확인: 표준 카메라 API, 외부 앱 권한/승인, 차량별 지원 확인, 영상 표시 제한, 시스템 후방/서라운드 화면 우선순위, 저장·보관·삭제 정책.
- 확장하더라도 주행 중 일반 앱 화면에서 영상을 자동 재생하지 않는다. 플랫폼에서 별도로 허용한 경로가 입증되어야 원 시나리오의 주행 영상 부분을 재검토한다.
- 녹화·업로드는 별도 동의와 명시적 기록 상태가 있어야 한다. 초기 제안은 자동 녹화/업로드 꺼짐이며 보관 기한은 미결이다. 미결인 상태에서는 녹화를 활성화하지 않는다.
- 카메라가 없어도 목적지 안내와 관심 지역 기록은 독립적으로 동작한다. 지도·입지 데이터 요약은 ‘카메라 스캔 결과’로 표시하지 않는다.
- 도로 상태·녹지 비율·상권 분위기의 자동 추론 알고리즘/정확도는 이번 범위 밖이며 영상 기록과 구분한다.

## 입출력 데이터

| 구분 | 항목 | 설명 |
|---|---|---|
| 입력 | 단지·거리·플랫폼 지원/권한·UX·녹화 동의 | 모두 검증 필요 |
| 출력 | MVP 없음 | 위치/지도 요약을 카메라 결과로 가장하지 않음 |

## 상태별 동작

| 상태 | 동작 |
|---|---|
| Parking | MVP 비활성. 확장 Gate 통과 시만 별도 설계 |
| Drive / 신호 대기 | 일반 앱 영상 자동 재생/녹화 없음 |
| 오프라인 | 비활성 유지 |
| API 미지원 | 비활성, 내비 안내와 독립 |
| 백그라운드 | 캡처/녹화/업로드 시작 금지 |

## 예외

- 권한 거부·보관정책 미결이면 녹화·업로드 금지.
- 시스템 후방/서라운드 화면 우선순위를 침해하지 않는다.

## 인수 조건

- [ ] MVP에서 대상 500m 진입만으로 카메라/파일/업로드가 시작되지 않는다.
- [ ] 확장 활성화 전에 표준 API·권한·실제 장치 지원·UX·보관/삭제 증거를 확보한다.
- [ ] 카메라 실패가 내비 안내/관심 지역 저장을 막지 않는다.
