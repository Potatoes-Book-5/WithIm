# S-005 주행 시작 전환

| 항목 | 내용 |
|---|---|
| 행위자 | 운전자 |
| 차량 상태 | Parking → Drive |
| 트리거 | 기어가 P에서 다른 기어(R, N, D, 수동 단수)로 바뀜(T-034) |

## 사전 조건

- 앱이 화면에 표시 중

## 주 흐름

1. 차량 기어(AAOS `GEAR_SELECTION`) 변경을 받는다(T-034). 주행 중 기능 제한은 주행 규제 상태(DI-001)를 따른다.
2. 현재 화면을 주행 화면(SCR-004)으로 전환한다. 앱은 DO를 선언해 주행 중에도 주행 화면이 보인다(T-035). 플랫폼 규제(DI-001)가 켜져도 같은 화면으로 전환한다.
3. 주행 세션 기록을 시작한다(F-009).

## 대체 흐름

- 조건 설정이나 상세 화면에 있었다면 입력 상태를 저장한 뒤 전환한다.
- 온보딩(동의, 관심 조건)을 마치기 전이면 주행 화면 대신 `주차한 뒤 시작할 수 있어요` 안내를 보여 주고, 주차하면 온보딩으로 돌아간다(T-035).

## 예외 흐름

- 기어를 읽지 못하면(미지원, 서비스 없음, 권한 없음) 주행 화면으로 전환하지 않는다. 개발 빌드는 수동 전환 버튼을 쓴다.
- 기어를 읽은 뒤 오류가 오면 현재 상태를 유지한다.
- 주행 중 허용이 확정되지 않은 기능은 비활성 상태로 표시한다.

## 음성 문구

음성 안내 없음

## 사후 조건

- 주행 화면에 Top 3가 표시된다.

## 측정 기준

- 전환까지 제안값 1초 이내

## 관련 문서

- 기능: F-003, F-009
- 화면: SCR-001, SCR-004
- 규칙: DD-001, DD-002, DI-002
