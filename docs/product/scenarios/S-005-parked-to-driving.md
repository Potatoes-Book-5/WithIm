# S-005 주행 시작 전환

| 항목 | 내용 |
|---|---|
| 행위자 | 운전자 |
| 차량 상태 | Parking → Drive |
| 트리거 | 주행 규제 상태 활성화 |

## 사전 조건

- 앱이 화면에 표시 중

## 주 흐름

1. 주행 규제 상태 변경을 받는다(DI-001).
2. 현재 화면을 주행 화면(SCR-004)으로 전환한다.
3. 주행 세션 기록을 시작한다(F-009).

## 대체 흐름

- 조건 설정이나 상세 화면에 있었다면 입력 상태를 저장한 뒤 전환한다.

## 예외 흐름

- 주행 중 허용이 확정되지 않은 기능은 비활성 상태로 표시한다.

## 음성 문구

음성 안내 없음

## 사후 조건

- 주행 화면에 Top 3가 표시된다.

## 측정 기준

- 전환까지 제안값 1초 이내

## 관련 문서

- 기능: F-003, F-009
- 화면: SCR-001, SCR-004
- 규칙: DD-001, DD-002, DI-002
