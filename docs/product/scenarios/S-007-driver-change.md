# S-007 운전자 변경과 데이터 삭제

| 항목 | 내용 |
|---|---|
| 행위자 | 새 운전자 또는 차량 소유자 |
| 차량 상태 | Parking |
| 트리거 | 데이터 삭제 요청 |

## 사전 조건

- 앱에 조건, 스크랩, 주행 기록 저장

## 주 흐름

1. 설정(SCR-006)에서 데이터 삭제를 선택한다.
2. 삭제 대상과 되돌릴 수 없음을 확인한다.
3. 조건, 스크랩, 주행 기록을 모두 지운다.
4. 첫 실행 흐름(S-002)으로 돌아간다.
