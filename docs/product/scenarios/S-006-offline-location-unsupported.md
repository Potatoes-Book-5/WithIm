# S-006 오프라인·위치 미지원

| 항목 | 내용 |
|---|---|
| 행위자 | 부부 |
| 차량 상태 | Parking / Drive |
| 트리거 | 네트워크 단절 또는 위치 API 미지원 |

## 사전 조건

- 앱 실행 중

## 주 흐름

1. 오프라인이면 마지막 캐시 순위를 기준 시각과 함께 표시한다.
2. 연결이 복구되면 자동으로 갱신한다.

## 대체 흐름

- 위치를 사용할 수 없으면 삼성전자 수원 본사 기준 10km 실거래 순위를 임시로 표시한다. 이를 차량 위치로 표시하지 않고 근접 알림과 주행 중 대장 교체 알림은 끈다. 유효한 차량 위치가 들어오면 자동 전환한다.

## 예외 흐름

- 캐시도 없으면 빈 상태와 연결 안내를 표시한다.

## 음성 문구

음성 안내 없음

## 사후 조건

- 앱이 종료되지 않고 사용 가능한 기능을 안내한다.

## 측정 기준

- 오프라인 안내 표시까지 제안값 3초 이내

## 관련 문서

- 기능: F-001, F-002
- 화면: SCR-001
- 규칙: CP-004, HW-007
