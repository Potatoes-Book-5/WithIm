# S-008 앱 실행 시 스크랩 변동 확인

| 항목 | 내용 |
|---|---|
| 행위자 | 부부 |
| 차량 상태 | Parking |
| 트리거 | 앱 실행 |

## 사전 조건

- 스크랩한 단지 1개 이상
- 네트워크 연결

## 주 흐름

1. 앱 실행 시 스크랩 단지의 최신 정보를 확인한다.
2. 변동이 있으면 홈(SCR-001)에 '스크랩 변동 N건'을 표시한다.
3. 사용자가 누르면 스크랩 목록(SCR-007)이 '변동 있음' 필터로 열린다.
4. 단지를 누르면 상세(SCR-002)에서 변동 내용을 확인한다.
5. 확인한 변동은 읽음 처리된다.

## 대체 흐름

- 변동이 없으면 홈에 표시하지 않는다.

## 예외 흐름

- 오프라인이면 변동 확인을 연결 후로 미룬다.

## 음성 문구

음성 안내 없음

## 사후 조건

- 사용자가 변동을 확인했다.

## 측정 기준

- 실행 후 변동 표시까지 제안값 3초 이내

## 관련 문서

- 기능: F-008
- 화면: SCR-001, SCR-007, SCR-002
- 규칙: DD-008, HW-005
