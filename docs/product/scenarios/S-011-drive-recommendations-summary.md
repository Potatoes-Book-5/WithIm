# S-011 주행 중 추천 수집과 종료 요약

| 항목 | 내용 |
|---|---|
| 행위자 | 운전자, 동승자 |
| 차량 상태 | Drive → Parking |
| 트리거 | 주행 중 유효 위치/시장 결과 갱신, 이후 기어 P 전환 |

## 사전 조건

- 온보딩 또는 설정에서 비어 있지 않은 관심 조건 저장
- 위치 동의 및 유효한 차량 위치
- 실제 차량 위치 주변 시장 자료를 조회할 수 있음

## 주 흐름

1. Drive 세션 중 위치와 시장 스냅샷이 갱신된다.
2. F-010은 실제 차량 반경 10km 안의 검증된 단지를 세션 후보에 추가한다.
3. 기존 후보와 같은 단지는 안정 ID로 합치고 거리·평가 정보를 갱신한다.
4. 명시 조건 점수와 로컬 선호 프로필을 결합해 세션 추천 후보를 갱신한다. 프로필은 활성 스크랩과 추천 카드에서 상세를 연 단지의 집계만 사용한다.
5. 추천 상위 3개 중 실제 차량 2km 이내에 진입한 단지가 있으면 기존 F-006 상단 배너에 위치 갱신당 최대 1건을 표시하고, 알림으로 노출한 단지를 세션의 지나친 관심 매물에 기록한다.
6. 기어 P에서 세션이 닫힌다. 요약(SCR-008)은 적합도 상위 3개만 보여 준다. 관심 매물 모아보기(SCR-011)는 전체 추천 후보와 그 외 실제 지나친 관심 매물을 보여 주며, 알림으로 노출한 단지는 추천 점수 순위가 바뀌어도 누락하지 않는다.
7. 주차 중 사용자가 추천 카드에서 상세를 열면 해당 단지의 상세 열기 집계를 기기에 기록한다. 일반 검색이나 다른 화면의 상세 진입은 추천 반응으로 기록하지 않는다.
8. 다음 주행의 선호 프로필에 새 상세 열기 반응과 현재 스크랩이 반영된다. 추천에 노출되었으나 열지 않은 단지는 선호/비선호 신호가 되지 않는다.

## 대체 흐름

- 조건 설정을 건너뛴 경우 추천 계산 및 추천 알림을 생략하고 기존 요약을 제공한다.
- 주행 중 네트워크가 끊기면 새 후보는 추가하지 않고 저장된 세션 후보를 유지한다.
- 같은 단지가 여러 차례 관측되면 한 항목으로 합치고 최단 관측 거리와 최신 유효 평가 자료를 남긴다.
- 후보가 3개 미만이면 저장된 수만큼만 요약에 제공한다.
- 앱이 화면에 없을 때는 주행 기록처럼 세션 후보를 저장하고 다음 실행 후 요약에 포함한다.

## 예외 흐름

- 임시 기준 위치, 오래되거나 무효한 위치, 위치 미지원 결과는 후보 풀에 포함하지 않는다.
- 10km 범위에 유효한 단지가 없거나 필요한 적합도 속성이 없으면 해당 관측은 후보를 추가하지 않는다.
- 시장 API 실패 시 이미 누적한 후보와 요약은 삭제하지 않는다.
- 기어 P 전환으로 주행이 종료되면 저장된 추천 후보와 실제 노출한 알림 매물을 함께 요약에 반영한다.

## 알림

추천 상위 3개 중 실제 차량 2km 이내에 든 단지를 기존 F-006 관심 매물 배너로 표시한다. 단지별 24시간 억제와 위치 갱신당 최대 1건을 적용한다. 주행 중 화면/TTS 허용 범위는 미결이다(T-001).

## 사후 조건

- 주행 요약은 세션 후보에서 계산한 추천 최대 3개와 데이터 기준일을 제공한다.
- 기존 `drive_passed_interests` 및 순위·대장 기록은 유지된다.
- 추천 기록에는 원좌표나 이동 경로가 포함되지 않는다.
- 상세 열기 반응은 단지별 제한된 집계로 저장하며 서버 전송이나 원시 시각 기록은 하지 않는다. 설정에서 전체 데이터를 삭제하면 함께 삭제된다.

## 측정 기준

- 같은 위치·조건·시장 입력에서 추천 결과 순서가 결정적으로 동일하다.
- 같은 후보·조건·개인화 입력에서 추천 결과 순서가 결정적으로 동일하다.
- 반경 경계 밖, 임시 위치, 중복 관측을 포함한 후보 집계가 F-010 인수 조건을 만족한다.
- 앱 프로세스 재시작과 오프라인 전환 후 저장 후보가 유지된다.
