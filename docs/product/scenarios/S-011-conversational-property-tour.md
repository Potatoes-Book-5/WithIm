# S-011 신혼부부 대화형 모빌리티 임장

## 사용자와 목표

신규 주거지를 찾는 신혼부부가 주말 드라이브에서 마음에 드는 동네를 발견한다. 남편은 운전하며 음성으로 묻고, 동승한 아내와 함께 주차 후 대화면으로 후보를 비교한다. 다음 탑승 때 관심 지역의 새 소식을 이어서 확인한다.

발화자가 아닌 앱의 활성 프로필을 사용한다. 목소리만으로 부부를 식별하거나 계정을 전환하지 않는다. 동승자 존재만으로 공용 화면의 제한을 해제하지 않는다.

## 선행 조건

- 위치/저장/알림 동의와 실행 상태를 확인한다(F-007).
- 주행 음성·화면은 카테고리·DO·플랫폼 허용 확인 후에만 활성화한다(T-001).
- 원천 데이터 공급자·이용 조건은 미결이다(T-005). 예시 가격은 모두 합성 데이터다.
- 제품 숫자는 [제안 기본값](../gleo-tour-defaults.md), 플랫폼 근거는 [연동 확인](../../platform/gleo-integration.md)을 따른다.

## 상태와 대체 흐름

- 신호 대기는 주차 상세 모드가 아니다. [주행 상태 매트릭스](../feature-state-matrix.md)가 모든 화면/기능보다 우선한다.
- 오프라인·표본 부족·위치 오차·저장 실패는 담당 기능의 예외 흐름을 따른다. 없는 가격/단지/입지를 생성하지 않는다.
- 자동 Gleo 발화·시동 실행·백그라운드 geofence는 API/권한 검증 전 비활성이다. 자동형 대신 요청형 브리핑과 주차 후 진입 기록으로 여정을 연결한다.
- 카메라 미지원이어도 관심 지역 저장과 내비 안내는 독립 동작한다.
- 프로필 전환 시 이전 화면/문맥/요청/음성 결과를 무효화한다(F-007).

## 인수 조건

- [ ] STEP 1~6에서 대상 지역·필터·프로필이 일관되게 연결된다.
- [ ] 신호 대기/주행 전환에서 상세 화면과 입력이 제한된다.
- [ ] 가격 왕관과 맞춤 추천 1위를 혼동하지 않는다.
- [ ] 미지원 자동 발화/시동/카메라를 구현 완료로 표시하지 않는다.
- [ ] 다음 세션에 저장 지역이 남고 브리핑 중복·읽음 상태가 정확하다.
- [ ] Intent 주입 성공과 실제 Gleo 자연어 E2E 성공을 따로 기록한다.
