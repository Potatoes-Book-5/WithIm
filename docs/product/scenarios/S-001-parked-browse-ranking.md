# S-001 주차 중 주변 순위 확인

| 항목 | 내용 |
|---|---|
| 행위자 | 부부(운전자, 동승자) |
| 차량 상태 | Parking |
| 트리거 | 주차 중 앱 실행 |

## 사전 조건

- 위치 동의 완료
- 네트워크 연결

## 주 흐름

1. 홈(SCR-001)이 열리고 반경 10km Top 3와 대장 아파트가 표시된다.
2. 사용자가 순위 항목을 누른다.
3. 아파트 상세(SCR-002)가 열린다.
4. 사용자가 스크랩 버튼을 누르면 스크랩 목록에 추가된다.

## 대체 흐름

- 스크랩 변동이 있으면 홈 상단에 변동 건수가 함께 표시된다(S-008).

## 예외 흐름

- 오프라인이면 마지막 순위와 기준 시각을 표시한다(S-006).

## 음성 문구

음성 안내 없음

## 사후 조건

- 사용자가 주변 Top 3를 확인했다.

## 측정 기준

- 홈 진입 후 Top 3 표시까지 제안값 2초 이내
- Top 3를 1~2초 안에 파악(DG-004)

## 관련 문서

- 기능: F-002, F-003, F-008
- 화면: SCR-001, SCR-002
- 규칙: DD-008, DG-004
