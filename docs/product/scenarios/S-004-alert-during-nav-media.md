# S-004 내비·미디어 재생 중 알림

| 항목 | 내용 |
|---|---|
| 행위자 | 운전자, 동승자 |
| 차량 상태 | Drive |
| 트리거 | 다른 오디오 재생 중 알림 발생 |

## 사전 조건

- 내비게이션 안내 또는 음악 재생 중

## 주 흐름

1. F-006이 오디오 포커스를 요청한다.
2. 음악 재생 중이면 음악 볼륨이 줄어든 상태에서 TTS를 읽는다.
3. TTS가 끝나면 포커스를 반납한다.

## 대체 흐름

- 내비 안내가 나오는 중이면 TTS를 건너뛰고 화면 알림만 표시한다(제안값).

## 예외 흐름

- TTS 재생 중 포커스를 잃으면 즉시 중단한다.

## 음성 문구

음성 안내 없음

## 사후 조건

- 다른 앱의 오디오가 원래 상태로 돌아간다.

## 측정 기준

- 내비 안내와 겹친 TTS 0건

## 관련 문서

- 기능: F-006
- 화면: SCR-005
- 규칙: AF-001, AF-002, AF-003
