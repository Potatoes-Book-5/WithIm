# S-002 첫 실행과 관심 조건 설정

| 항목 | 내용 |
|---|---|
| 행위자 | 부부(주로 동승자 또는 주차 중 운전자) |
| 차량 상태 | Parking |
| 트리거 | 앱 첫 실행 |

## 사전 조건

- 앱 설치 직후

## 주 흐름

1. 동의 화면(SCR-006)에서 위치 사용 이유를 읽고 동의한다.
2. 관심 조건 화면(SCR-003)이 열린다.
3. 주변 추천 동네 칩에서 동네를 고른다.
4. 가격대와 평수 구간 칩을 고른다.
5. 저장하면 홈(SCR-001)으로 이동한다.

## 대체 흐름

- 건너뛰기를 누르면 조건 없이 홈으로 이동하고 관심 매물 알림은 꺼진다.
- 동네를 음성으로 검색한다(DD-012).

## 예외 흐름

- 동의를 거부하면 위치 기반 기능 없이 홈으로 이동하고 동의 방법을 안내한다.
- 주행이 시작되면 저장하지 않은 입력은 유지하고 SCR-004로 전환한다(S-005).

## 음성 문구

음성 안내 없음

## 사후 조건

- 관심 조건이 저장되었거나 건너뛰었다.

## 측정 기준

- 첫 실행부터 홈까지 탭 수 제안값 6회 이내

## 관련 문서

- 기능: F-004, F-007
- 화면: SCR-006, SCR-003, SCR-001
- 규칙: SP-003, DD-012, DD-009
