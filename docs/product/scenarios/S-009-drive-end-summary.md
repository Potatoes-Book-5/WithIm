# S-009 주행 종료 요약과 스크랩

| 항목 | 내용 |
|---|---|
| 행위자 | 부부 |
| 차량 상태 | Drive → Parking |
| 트리거 | 기어 P(주행 완료) 전환 즉시(T-034) |

## 사전 조건

- 주행 중 순위 기록 1건 이상

## 주 흐름

1. 주행 세션이 종료된다.
2. 주행 요약(SCR-008)이 표시된다.
3. 최종 Top 3, 대장 교체 이력, 지나친 관심 매물을 확인한다.
4. 관심 있는 단지의 스크랩 버튼을 누른다.
5. 닫으면 홈으로 이동한다.

## 대체 흐름

- 앱이 화면에 없었다면 다음 실행 시 요약을 먼저 보여 준다.

## 예외 흐름

- 요약을 본 뒤 다시 P 외의 기어로 바뀌면 새 주행 세션을 시작한다(F-009 규칙 6).
- 기록이 없으면 요약을 만들지 않는다.

## 음성 문구

음성 안내 없음

## 사후 조건

- 요약이 저장되고 선택한 단지가 스크랩되었다.

## 측정 기준

- 요약에서 스크랩까지 탭 1회

## 관련 문서

- 기능: F-009, F-008, F-003
- 화면: SCR-008, SCR-007
- 규칙: DR-001, SM-009
