# S-003 주행 중 관심 매물 알림

| 항목 | 내용 |
|---|---|
| 행위자 | 운전자, 동승자 |
| 차량 상태 | Drive |
| 트리거 | F-010 추천 상위 3개 단지에 제안값 2km 이내로 접근 |

## 사전 조건

- 관심 조건 저장
- 관심 매물 알림 켜짐
- 주행 중 알림 허용(T-001 확정 필요)

## 주 흐름

1. F-005가 F-010 추천 상위 3개에서 알림 후보를 만든다.
2. F-006이 오디오 포커스를 요청한다.
3. TTS로 ‘{단지명}, 스크랩할까요?’라고 읽는다.
4. 화면에 간소 알림(SCR-005)을 15초간 표시해 질문과 Gleo 명령 시간을 확보한다.
5. 알림이 자동으로 사라지고 주행 화면(SCR-004)으로 돌아간다.

## 대체 흐름

- 동승자가 '스크랩' 버튼을 한 번 눌러 스크랩한다(주행 중 허용 여부 미확정).
- Gleo에 '스크랩해 줘'라고 말하면 현재 보이는 알림의 스크랩 버튼과 같은 멱등 저장을 실행한다. 알림 만료·교체·화면 숨김 뒤에는 실행하지 않는다.

## 예외 흐름

- 내비 안내 중이면 S-004로 처리한다.
- 포커스를 얻지 못하면 화면 알림만 표시한다.

## 음성 문구

| 상황 | 문구 | 최대 길이 |
|---|---|---|
| 추천 매물 발견 | 한빛마을 1단지, 스크랩할까요? | 초기화 포함 최대 10초, 알림 만료 시 중단 |

## 사후 조건

- 알림 이력이 주행 요약에 남는다.

## 측정 기준

- TTS 질문 중에도 Gleo 호출 시 포커스를 즉시 반납하고 중단
- 같은 단지 재알림 0건(억제 기간 내)

## 관련 문서

- 기능: F-005, F-006, F-008, F-010
- 화면: SCR-004, SCR-005
- 규칙: DR-001, DG-010, AF-001
