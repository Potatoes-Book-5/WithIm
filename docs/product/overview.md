# 제품 개요: 임과 함께

## 한 줄 소개

**임과 함께**는 임장을 누군가와 함께 다닐 때 편하게 쓰는 Pleos Connect 차량 앱입니다. 차량이 이동하는 동안 주변 아파트의 시세 순위와 관심 매물을 알려 줍니다.

## 주요 사용자

부동산에 관심이 많은 부부입니다. 한 명은 운전하고 한 명은 동승하는 상황을 기본으로 합니다. 자세한 내용은 [personas-contexts.md](personas-contexts.md)를 봅니다.

## 핵심 기능

### 1. 부동산 추천

| ID | 기능 | 요약 |
|---|---|---|
| F-004 | 관심 조건 설정 | 첫 실행 시 동네, 가격대, 평수 설정 |
| F-005 | 관심 매물 근접 판정 | 주변에 조건과 일치하는 단지가 있는지 판정 |
| F-006 | 알림과 TTS 안내 | 화면 알림과 음성으로 전달 |
| F-008 | 스크랩과 변동 알림 | 스크랩한 단지의 변동을 앱 실행 시 안내 |

### 2. 아파트 가격 순위 경쟁

| ID | 기능 | 요약 |
|---|---|---|
| F-002 | 반경 10km 시세 조회 | 차량 주변 단지의 실거래가 조회 |
| F-003 | 아파트 가격 순위 경쟁 | Top 3 실시간 갱신, 대장 아파트 교체 알림 |
| F-009 | 주행 요약 | 주행 종료 후 순위와 관심 매물 정리 |

### 공통

| ID | 기능 |
|---|---|
| F-001 | 차량 위치 획득 |
| F-007 | 동의와 설정 |

## 비목표

- 매물 거래, 중개, 대출 연결
- 투자 자문이나 가격 예측
- 주행 중 상세 탐색과 텍스트 입력

## 성공 기준

작성 필요. 후보: 주행 1회당 확인한 단지 수, 스크랩 전환율, 주행 요약 열람률

## 주요 위험

| 위험 | 관련 | 대응 |
|---|---|---|
| 주행 중 TTS·순위 화면 허용 여부 미확정 | DR-001, T-001 | Pleos 답변 전까지 주행 기능을 미확정으로 관리 |
| 앱 카테고리 미확정 | ADR-001 | Pleos 문의 |
| 매물 알림이 광고로 해석될 가능성 | DG-010 | 문구에서 홍보 표현 배제 |
| 실거래가 공개 지연으로 '실시간' 오해 | F-002 | 데이터 기준일 표시 |
| 시세 데이터 이용 조건 미확정 | T-005 | 출처 검토 |

## 대화형 임장 확장 초안

시작점은 [S-011 신혼부부 6단계 임장](scenarios/S-011-conversational-property-tour.md)이다. 제품 규칙은 기능별 문서, 플랫폼 근거는 [gleo-integration](../platform/gleo-integration.md), 검증 절차는 [testing](../testing/gleo-tour/README.md)에서 각각 관리한다.

| ID | 새 범위 | 상태/범위 |
|---|---|---|
| F-010 | Gleo 가격 질의·지역 저장·브리핑 호출 | 3개 함수 초안, 실제 연동 미실행 |
| F-011 | 법정동/역세권 저장과 진입 이벤트 | 단지 스크랩/근접 판정과 별개, 자동형 조건부 |
| F-012 | 단지 출입구 내비 안내 | 주차 중 선택, SDK 지원 검증 필요 |
| F-013 | 관심 지역 실거래·청약·뉴스 브리핑 | 요청형 기본, 시동 자동형 비활성 |
| F-014 | 차량 카메라 현장 스캔 | 확장 연구, MVP 비활성 |

기존 F-002/F-003/F-004를 가격·왕관·추천의 원본으로 보강했다. 수치와 산식은 [검토용 기본값](gleo-tour-defaults.md)이며 개인정보/DO/카테고리 승인은 미결 상태를 유지한다. 주행 허용 여부의 단일 기준은 [feature-state-matrix](feature-state-matrix.md)다.
