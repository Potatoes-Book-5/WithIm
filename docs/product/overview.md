# 제품 개요: 임과 함께

## 한 줄 소개

**임과 함께**는 임장을 누군가와 함께 다닐 때 편하게 쓰는 Pleos Connect 차량 앱입니다. 차량이 이동하는 동안 주변 아파트의 시세 순위와 관심 매물을 알려 줍니다.

## 주요 사용자

부동산에 관심이 많은 부부입니다. 한 명은 운전하고 한 명은 동승하는 상황을 기본으로 합니다. 자세한 내용은 [personas-contexts.md](personas-contexts.md)를 봅니다.

## 핵심 기능

### 1. 부동산 추천

| ID | 기능 | 요약 |
|---|---|---|
| F-004 | 관심 조건 설정 | 첫 실행 시 동네, 가격대, 평수 설정 |
| F-005 | 관심 매물 근접 판정 | 추천 상위 3개 단지가 가까워지면 알림 후보를 만듦 |
| F-006 | 알림과 TTS 안내 | 추천 매물과 대장 교체를 화면 알림·음성으로 전달 |
| F-008 | 스크랩과 변동 알림 | 스크랩한 단지의 변동을 앱 실행 시 안내 |

### 2. 아파트 가격 순위 경쟁

| ID | 기능 | 요약 |
|---|---|---|
| F-002 | 반경 10km 시세 조회 | 차량 주변 단지의 실거래가 조회 |
| F-003 | 아파트 가격 순위 경쟁 | Top 3 실시간 갱신, 대장 아파트 교체 알림 |
| F-009 | 주행 요약 | 주행 종료 후 순위와 관심 매물 정리 |
| F-010 | 주행 관심 매물 추천 | 주행 중 반경 10km 후보를 누적·평가하고 종료 요약에 최대 3개 제공 |

### 공통

| ID | 기능 |
|---|---|
| F-001 | 차량 위치 획득 |
| F-007 | 동의와 설정 |

## 비목표

- 매물 거래, 중개, 대출 연결
- 투자 자문이나 가격 예측
- 주행 중 상세 탐색과 텍스트 입력

## 성공 기준

작성 필요. 후보: 주행 1회당 확인한 단지 수, 스크랩 전환율, 주행 요약 열람률

## 주요 위험

| 위험 | 관련 | 대응 |
|---|---|---|
| 주행 중 TTS·순위 화면 허용 여부 미확정 | DR-001, T-001 | Pleos 답변 전까지 주행 기능을 미확정으로 관리 |
| 앱 카테고리 미확정 | ADR-001 | Pleos 문의 |
| 매물 알림이 광고로 해석될 가능성 | DG-010 | 문구에서 홍보 표현 배제 |
| 실거래가 공개 지연으로 '실시간' 오해 | F-002 | 데이터 기준일 표시 |
| 시세 데이터 이용 조건 미확정 | T-005 | 출처 검토 |
