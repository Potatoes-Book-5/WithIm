# 제품 개요

## 목표

현대자동차 Pleos Connect 차량에서 차량 위치 주변 아파트의 시세를 조회해 순위로 보여 주고, 사용자의 관심 부동산·조건에 맞는 부동산이 주변에 있으면 TTS로 알립니다.

## 핵심 기능

| ID | 기능 |
|---|---|
| F-001 | 차량 위치 획득 |
| F-002 | 주변 아파트 시세 조회 |
| F-003 | 아파트 순위 산정 |
| F-004 | 관심 부동산·조건 관리 |
| F-005 | 근접 매물 판정 |
| F-006 | TTS 매물 알림 |
| F-007 | 동의와 설정 |

## 비목표

작성 필요. 후보: 매물 거래·중개, 주행 중 상세 탐색, 금융·투자 자문
