# 기능 × 주행 상태 매트릭스

주행 중 허용 범위의 단일 기준 문서입니다. 근거는 DR-001, DR-002, CAT-002입니다. `미확정`은 T-001 답변 후 확정합니다.

앱은 `MainActivity`에 DO를 선언했습니다(T-035, 사용자 결정). 아래 `Drive (DO 선언)` 열을 적용하며, 주행 중에는 주행 화면(SCR-004·SCR-009)만 보이고 나머지 화면은 앱이 막습니다. 온보딩 전에는 주차 안내만 보입니다.

| 기능 | Parking | Drive (DO 미선언) | Drive (DO 선언) |
|---|---|---|---|
| F-001 차량 위치 획득 | 사용 | 사용 불가 | 백그라운드 수집 |
| F-002 반경 10km 시세 조회 | 사용 | 사용 불가 | 캐시 우선 조회 |
| F-003 아파트 가격 순위 경쟁 | 홈에 표시 | 사용 불가 | Top 3 간소 화면, 지도 모드(T-035 표시, 심사 허용 여부 미확정) |
| F-004 관심 조건 설정 | 설정·수정 | 사용 불가 | 수정 차단 |
| F-005 관심 매물 근접 판정 | 판정 안 함 | 사용 불가 | 판정 |
| F-006 알림과 TTS 안내 | 화면 알림 | 사용 불가 | TTS와 간소 알림(미확정) |
| F-007 동의와 설정 | 사용 | 사용 불가 | 진입 차단 |
| F-008 스크랩과 변동 알림 | 사용 | 사용 불가 | 한 번 탭·음성 스크랩만(미확정) |
| F-009 주행 요약 | 요약 표시 | 사용 불가 | 기록만 |
| F-010 주행 관심 매물 추천 | 종료 요약 추천 표시 | 사용 불가 | 유효 위치 갱신 때 10km 후보 누적·평가, 알림은 F-006 허용 범위에 따름 |

북미·유럽·그 외 구분에서 한국의 적용 대상은 확인이 필요합니다(T-001).
