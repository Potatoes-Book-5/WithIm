# 사용자와 이용 맥락

## 사용자

| 사용자 | 목표 | 제약 |
|---|---|---|
| 운전자 | 이동 중 관심 지역 시세와 매물 정보 파악 | 시선과 손을 운전에 사용 |
| 동승자 | 주차 또는 이동 중 정보 탐색 | 동승자 전용 입력 경로 확인 필요 |

## 이용 맥락

| 맥락 | 차량 상태 | 가능한 행동 | 시나리오 |
|---|---|---|---|
| 주차 후 탐색 | Parking | 순위 조회, 조건 등록 | S-001, S-002 |
| 이동 중 알림 | Drive | 음성 청취 | S-003, S-004 |
| 주행 전환 | Parking → Drive | 간소 화면 전환 | S-005 |
| 연결 불량 | Parking / Drive | 캐시 확인 | S-006 |
| 운전자 변경 | Parking | 계정 전환 | S-007 |
