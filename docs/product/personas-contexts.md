# 사용자와 이용 맥락

## 주요 사용자: 부동산에 관심 많은 부부

| 역할 | 목표 | 제약 |
|---|---|---|
| 운전자 | 이동 중 주변 시세와 관심 매물 소식을 듣는다 | 시선과 손을 운전에 사용, 음성 위주 |
| 동승자 | 화면을 보며 함께 이야기하고 관심 단지를 표시한다 | 주행 중 터치 허용 범위 미확정 |
| 두 사람 함께 | 임장 후 결과를 돌아보고 다음 후보를 정한다 | 주차 후 화면 사용 |

## 이용 맥락

| 맥락 | 차량 상태 | 주로 하는 일 | 시나리오 |
|---|---|---|---|
| 첫 실행 | Parking | 동의, 관심 조건 설정 | S-002 |
| 출발 전 | Parking | 주변 순위와 스크랩 변동 확인 | S-001, S-008 |
| 주행 시작 | Parking → Drive | 주행 화면 전환 | S-005 |
| 임장 이동 중 | Drive | 순위 경쟁 보기, 알림 듣기 | S-003, S-004, S-010 |
| 도착 후 | Drive → Parking | 주행 요약, 스크랩 | S-009 |
| 연결 불량 | Parking / Drive | 캐시 확인 | S-006 |
| 운전자 변경 | Parking | 데이터 삭제 | S-007 |

## 미결 사항

- [ ] 동승자 전용 입력 허용 여부(주행 중 터치)
- [ ] 부부가 조건과 스크랩을 공유할지, 각자 가질지
