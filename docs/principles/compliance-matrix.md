## T-031 확인 범위

기존 지도·카드·알림 레이아웃을 유지하고 지도 축척만 근거리 배율(최소 줌 18.5)로 고정했다. 지역별 시군구 코드·단지·가격·시각은 기존 로컬 주행 요약 보존 정책에 따라 저장하며 GPS 원좌표는 기록하지 않는다. 지역 판별 API로 좌표가 Vworld에 전송되는 점을 F-001과 Vworld 문서에 명시했다. Pleos SDK, 주행 규제, TTS, 동의·권한 획득 정책은 변경하지 않는다. CPU·메모리·실차 주행 안전 검증은 이번 변경에서 완료로 표시하지 않는다.

## T-045 확인 범위

[임장 내부 API](../api/tour-intent-api.md)는 foreground·동의·주행 제한을 검사하고 개인 공개 호출을 차단한다. Room 변경은 실행 자격 재검증으로 취소 시 rollback하며 삭제 cascade와 버전별 읽음을 검사한다. 시군구 코드/장소 중심을 경계·차량 출입구로 추정하지 않는다. 실제 SDK·Gleo 자연어·실차 오디오·주행 심사·대화면 UX 완료를 이 단위 검증으로 대체하지 않는다. [검증 상세](../testing/gleo-tour/spec-actions.md).
