# 보안과 개인정보

> 확인일: 2026-11-08 · 상태: 초안. 페이지 요약을 바탕으로 작성했으며 T-006에서 원문과 대조합니다.
> 공식 문서를 복제하지 않고 요약합니다. 판단이 필요하면 원문을 우선합니다.

## 원문

- [보안 및 개인정보 보호를 고려한 설계](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/security-privacy)

## 요약

차량은 운전자가 바뀔 수 있으므로 계정 전환과 개인정보 최소 수집을 고려해야 합니다.

## 규칙

강도(MUST/SHOULD)는 원문 표현을 바탕으로 팀이 해석한 값입니다.

| ID | 강도 | 규칙 |
|---|---|---|
| SP-001 | MUST | 차량 소유자나 운전자가 바뀌면 쉽게 로그아웃하고 계정을 전환할 수 있어야 한다. |
| SP-002 | MUST | 계정 토큰은 Keystore 같은 안전한 저장소에 보관한다. |
| SP-003 | MUST | 위치 정보 등을 요구할 때 필요한 이유를 명확히 하고 동의 절차를 단순하게 한다. |
| SP-004 | MUST | 불필요한 개인정보를 저장하지 않는다. |
| SP-005 | MUST | 로그에 포함되는 개인정보는 마스킹한다. |
| SP-006 | MUST | 차량 밖으로 나가는 차량 ID와 사용자 ID의 익명화·가명화 정책을 세운다. |
| SP-007 | MUST | 운전 중 행동 데이터는 마케팅 목적으로 사용하지 않도록 구분한다. |

## 이 앱에 적용

- Pleos 키는 `local.properties`로만 관리하고 커밋하지 않습니다.
- 실제 위치 데이터는 테스트 자료와 로그에 넣지 않습니다.
- 관심 부동산과 이동 위치의 조합은 민감 정보로 취급합니다.

## 원문에 없는 항목

- 키와 시크릿 관리 기준(별도 앱 보안 가이드 확인 필요)
- 위치 정보 전용 항목
