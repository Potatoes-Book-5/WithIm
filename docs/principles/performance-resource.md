## 원문

- [성능 및 리소스 효율을 고려한 설계](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/performance-resource-mgmt)

## 요약

차량 리소스는 여러 앱이 나눠 쓰므로 시작 시간과 CPU, 메모리, 배터리 사용을 최소화해야 합니다.

## 규칙

강도(MUST/SHOULD)는 원문 표현을 바탕으로 팀이 해석한 값입니다.

| ID | 강도 | 규칙 |
|---|---|---|
| PF-001 | SHOULD | 콜드 스타트에는 필요한 최소한만 초기화하고 나머지는 지연 로딩한다. |
| PF-002 | MUST | 내비게이션 외 앱의 주행 중 CPU 사용률은 5% 미만이다. |
| PF-003 | MUST | 모든 앱의 정차 중 CPU 사용률은 25% 이하이다. |
| PF-004 | MUST | RAM 사용량은 400 MB 이하이다. |
| PF-005 | SHOULD | 이미지와 리스트에 재활용 구조와 캐시 전략을 적용한다. |
| PF-006 | MUST | 오디오 포커스 정책을 준수하고 획득·상실 대응을 구현한다. |
