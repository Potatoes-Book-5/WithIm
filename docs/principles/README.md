# 설계 원칙

Pleos Connect 앱 설계 가이드를 이 프로젝트의 규칙 ID로 정리한 폴더입니다.

| 문서 | 접두어 | 다루는 내용 |
|---|---|---|
| [driver-distraction.md](driver-distraction.md) | DD | 운전자 주의 분산 방지 |
| [driving-restriction.md](driving-restriction.md) | DR | 주행 상태·지역별 기능 허용 |
| [app-category.md](app-category.md) | CAT | 앱 카테고리와 주행 중 제약 |
| [app-structure-screen-model.md](app-structure-screen-model.md) | SM | 화면 구성, 멀티 윈도우, 생명주기 |
| [performance-resource.md](performance-resource.md) | PF | 시작 시간, CPU, 메모리, 오디오 |
| [security-privacy.md](security-privacy.md) | SP | 계정, 개인정보, 외부 전송 |
| [compliance-matrix.md](compliance-matrix.md) | - | 규칙별 적용 위치와 검증 방법 |

## 작성 규칙

- 규칙 하나에 ID 하나를 부여합니다. 삭제된 규칙의 ID는 재사용하지 않습니다.
- 수치는 원문 값을 그대로 적고, 원문에 없는 값을 추정해 넣지 않습니다.
- 원문이 바뀌면 확인일을 갱신하고 영향을 받는 기능·화면 문서를 함께 수정합니다.
