# 운전자 주의 분산 방지

> 확인일: 2026-11-08 · 상태: 초안. 페이지 요약을 바탕으로 작성했으며 T-006에서 원문과 대조합니다.
> 공식 문서를 복제하지 않고 요약합니다. 판단이 필요하면 원문을 우선합니다.

## 원문

- [주행 안전을 고려한 설계](https://document.pleos.ai/docs/pleos-only/vehicle-app-planning-guide/driver-distraction-guideline)
- [AAOS 운전자 주의 분산 가이드라인](https://source.android.com/docs/automotive/driver_distraction/guidelines?hl=ko)

## 요약

주행 중 사용 가능 범위는 주행 상태, 지역, 앱 카테고리에 따라 달라집니다. 앱은 주행 상황을 고려해 시선과 조작 부담을 최소화해야 합니다.

## 규칙

강도(MUST/SHOULD)는 원문 표현을 바탕으로 팀이 해석한 값입니다.

| ID | 강도 | 규칙 |
|---|---|---|
| DD-001 | MUST | `CarUxRestrictions`를 기준으로 현재 주행 제한 상태를 판단한다. |
| DD-002 | MUST | 제한 대상 기능은 UI와 동작을 축소하거나 비활성화한다. |
| DD-003 | MUST | 주행 규제 상태에서는 영상 재생을 시작하거나 재개하지 않는다. |
| DD-004 | SHOULD | 운전에 필요한 정보는 짧은 시간에 이해할 수 있게 간결하게 표시한다. |
| DD-005 | SHOULD | 주행 중 동영상, 애니메이션, 움직이는 이미지를 최소화하거나 제한한다. |
| DD-006 | SHOULD | 이미지는 정보 전달에 필요한 범위로 제한하고 장식적·반복적 움직임을 피한다. |
| DD-007 | SHOULD | 중요한 정보와 기능에 우선순위를 두고 잘 보이는 위치에 배치한다. |
| DD-008 | SHOULD | 자주 쓰는 기능은 첫 화면 상단에 둔다. |
| DD-009 | SHOULD | 드롭다운과 다단계 메뉴를 남용하지 않는다. |
| DD-010 | SHOULD | UI Design Guide에 따라 큰 터치 영역, 높은 대비, 최소한의 텍스트를 적용한다. |
| DD-011 | SHOULD | 터치 조작을 줄이고 음성 명령, 물리 버튼 등 차량 입력과 연계한다. |
| DD-012 | SHOULD | 검색과 로그인에서도 키보드보다 프리셋, 최근 항목, 음성을 우선한다. |
| DD-013 | MUST | AAOS 운전자 주의 분산 가이드라인을 준수한다. |

## 이 앱에 적용

- 주행 전환 시 처리는 S-005, 주행 중 화면은 SCR-004에서 구체화합니다.
- 관심 조건 입력은 프리셋 선택을 기본으로 합니다(F-004).
- 음성 안내는 오디오 포커스 정책을 따릅니다([audio-focus-impl.md](../platform/audio-focus-impl.md)).

## 원문에 없는 항목

- 시간, 글자 수, 터치 횟수 같은 수치 기준
- TTS 전용 규칙
