# 공동주택 세대수 조회

T-033에서 상세 화면의 기존 세대수 필드에 국토교통부 K-APT 정보를 연결한다. UI·DB·차량 SDK 변경은 없다.

## 공식 출처

2026-11-14 확인:

- [공동주택 단지 목록제공 서비스](https://www.data.go.kr/data/15057332/openapi.do): `AptListService4/getSigunguAptList4`, `sigunguCode`, `pageNo`, `numOfRows`. JSON `response.body.items[]`의 `kaptCode`, `kaptName`, `bjdCode`, `as3` 사용.
- [공동주택 기본 정보제공 서비스](https://www.data.go.kr/data/15058453/openapi.do): `AptBasisInfoServiceV5/getAphusBassInfoV5`, `kaptCode`. JSON `response.body.item`의 세대수는 **`kaptdaCnt`**다. `hoCnt` 등 다른 항목으로 대체하지 않는다.
- 두 서비스 모두 `serviceKey`가 필요하다. 같은 키라도 두 서비스 각각 활용신청해야 한다. `KAPT_API_KEY`를 저장소 밖 설정으로 전달하며, 인코딩·디코딩 키를 모두 받는다.

## 연결 기준과 실패 처리

1. 실거래의 시군구 코드로 목록 전체를 페이지 조회한다.
2. 같은 법정동과 공백·말미의 `아파트` 표기를 제외한 동일 단지명 후보가 하나인 경우에만 기본정보를 조회한다. 예: 실거래 `힐스테이트영통`과 K-APT `힐스테이트 영통아파트`. 동·차수·숫자는 제거하지 않는다. K-APT와 실거래 단지번호는 별개다.
3. 기본정보의 시군구·단지명 및 지번 또는 도로명 건물번호가 일치해야 양의 정수 세대수를 사용한다. 동명이거나 식별이 애매하면 `정보 없음`을 유지한다.
4. 검증된 `시군구 코드 + 실거래 단지 ID → kaptCode` 매핑을 최대 256개 보관해 이후 조회는 단지명 검색 없이 ID로 접근한다. 주소는 재검증한다. 목록은 최대 8개 구, 기본정보는 최대 256개 단지만 프로세스 메모리에 보관한다. 앱 재시작 시 다시 확인하며 응답·인증키를 디스크 캐시나 로그에 남기지 않는다.
5. 상세의 부가 조회는 최대 8초로 제한한다. 권한 오류·네트워크 오류·미가입 단지·값 누락이 있어도 실거래 상세는 표시한다. 스크랩은 기존 상세 저장·보충 경로로 세대수를 받는다.

## 이번 범위 밖

주행 중 세대수 관심 필터는 기존처럼 미확인 단지를 제외한다. 모든 주변 단지의 메타데이터를 미리 조회하는 변경은 이번 최소 수정 범위에 포함하지 않는다.

## 원문에 없는 항목

- 실거래 단지번호와 K-APT 단지코드 간 공식 매핑은 제공된 명세에 없다.
- K-APT 가입 단지만 제공하므로 모든 실거래 단지에 세대수가 있다고 보장하지 않는다.
