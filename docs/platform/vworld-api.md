# 영통구 거래와 Vworld 주소 좌표 변환

T-021, [ADR-007](../decisions/ADR-007-geocoding-reference.md)의 구현 사용법이다.

`VWORLD_API_KEY`를 빌드 환경 변수 또는 사용자 Gradle 속성으로 전달한다. 키는 코드·문서·로그에 넣지 않는다. 앱의 `BuildConfig`에 포함된 키는 APK에서 추출 가능하므로 배포용 키 관리 방식은 별도 결정이 필요하다.

수원시 영통구 거래는 법정동 시군구 코드 `41117`로 국토부 API에서 조회한다. 거래의 도로명 주소를 우선 조합하고, 없으면 지번 주소를 사용해 Vworld `getcoord`로 좌표를 얻는다. EPSG:4326 결과에서 `x`는 경도, `y`는 위도다. 조회한 좌표를 영구 저장하지 않는다.

차량 좌표 대신 [삼성전자 수원 본사 주소](https://www.samsung.com/sec/ir/reports-disclosures/public-disclosure/4005/)를 임시 기준점으로 사용한다. 이 주소도 Vworld로 좌표를 얻으며, 거래 좌표와의 거리는 임시 기준점에서의 직선거리다. 실제 차량 거리나 내비게이션 주행거리로 표시하지 않는다.

기존 개발 브랜치에서 2026년 9월 영통구 실거래 522건의 실서버 응답과 선택 거래 주소의 좌표 변환을 확인했다. 이후 해당 개발 브랜치의 에뮬레이터 앱에서도 국토부 실제 거래 응답을 확인했다. 이번 PR 브랜치는 앱 빌드를 통과했으며 실제 API 호출을 다시 실행하지는 않았다. 홈의 샘플 순위는 실거래 기반 순위로 취급하지 않는다.
