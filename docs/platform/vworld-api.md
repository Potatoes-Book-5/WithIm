# 실거래 주소·지역 Vworld 조회

T-021, [ADR-007](../decisions/ADR-007-geocoding-reference.md)의 구현 사용법이다.

`VWORLD_API_KEY`를 git 제외 파일 `local.properties`에 넣는다. 없으면 사용자 Gradle 속성, 그다음 빌드 환경 변수(CI)에서 찾는다. 키는 코드·문서·로그에 넣지 않는다. 앱의 `BuildConfig`에 포함된 키는 APK에서 추출 가능하므로 배포용 키 관리 방식은 별도 결정이 필요하다.

T-021에서는 수원시 영통구 법정동 시군구 코드 `41117`을 고정 조회했다. T-027은 현재 위치 반경 10km의 경계 상자와 교차하는 시군구를 Vworld Data API 2.0의 `LT_C_ADSIGG_INFO`에서 조회해 국토부 요청 코드를 동적으로 정한다. 거래의 도로명 주소를 우선 조합하고, 없으면 지번 주소를 사용해 Vworld `getcoord`로 좌표를 얻는다. EPSG:4326 결과에서 `x`는 경도, `y`는 위도다. 최종 반경 판정은 거래 좌표와 현재 위치의 직선거리로 수행하며 변환 좌표를 영구 저장하지 않는다.

T-021에서는 [삼성전자 수원 본사 주소](https://www.samsung.com/sec/ir/reports-disclosures/public-disclosure/4005/)를 임시 기준점으로 사용했다. T-027 런타임은 외부 콜백에서 받은 현재 차량 위치를 기준으로 한다. Pleos 차량 위치 SDK 콜백 연결은 친구 담당이고, 앱은 GPS 센서를 직접 읽지 않는다. 거리는 내비게이션 주행거리가 아닌 직선거리다.

기존 개발 브랜치에서 2026년 9월 영통구 실거래 522건의 실서버 응답과 선택 거래 주소의 좌표 변환을 확인했다. 이후 해당 개발 브랜치의 에뮬레이터 앱에서도 국토부 실제 거래 응답을 확인했다. T-027은 한 달 전 날짜부터 오늘까지(양 끝 포함)에 걸친 계약 연월의 조회 결과를 합쳐 실제 거래일로 거른다. 취소되지 않은 거래를 현재 위치 직선거리 10km 이내로 제한한다. 거래 원본과 좌표 변환 결과는 화면·순위 계산에 사용하며 좌표를 영구 저장하지 않는다. 동탄역 주변처럼 시군구 경계가 바뀌면 해당 코드의 거래를 추가 조회한다.


## T-031 현재 구 판별

확인일: 2026-11-14. Vworld [데이터 API 2.0 공식 요청 명세](https://www.vworld.kr/dev/v4dv_2ddataguide2_s002.do?svcIde=cadastral)의 공간 필터 POINT(x y)를 사용하고, 기존 LT_C_ADSIGG_INFO 레이어에서 현재 좌표가 속한 시군구를 확인한다. EPSG:4326의 x는 경도, y는 위도다. 후보가 한 개로 확정되지 않으면 임의로 고르지 않는다. 확정된 구의 최근 1개월 거래를 받아 실제 주소 좌표가 3km 이내인지 판정한다. 기존 BOX 교차 시군구 조회는 T-027의 이전 방식이다.

지역 판별 요청에는 현재 좌표가 Vworld로 전송된다. 좌표를 기기 DB에 저장하지 않고 메모리에서만 다룬다. 앱이 지역 코드·거래 주소만 외부에 보낸다는 이전 설명은 이 지역 판별 흐름에 해당하지 않는다.

주소 변환의 공식 status=NOT_FOUND는 검색 결과 없음으로 처리해 해당 주소만 건너뛰고, ERROR는 제공처 오류로 유지한다. [공식 주소→좌표 응답 명세](https://www.vworld.kr/dev/v4dv_geocoderguide2_s001.do)를 확인했다(2026-11-14).
