# 실제 Gleo 음성 E2E 사전 확인 — 2026-11-15

## 판정

사전 확인 일부 완료. 실제 발화 → Gleo 함수 선택 → Nudge 대상 저장까지는 미검증이며 통과로 처리하지 않는다. 앱 경계 계측 E2E 통과 기록과 구분한다.

## 직접 확인한 상태

- 기존 emulator-5554는 조회 중 연결이 종료됐다. 별도 read-only headless Pleos_Connect_v2.1.0 인스턴스 emulator-5556을 기동했다.
- 최신 debug APK를 `adb install -r`로 설치했다. 앱 데이터 초기화는 수행하지 않았다.
- 실제 기본 음성 비서는 `ai.umos.ambientai/.service.AiAssistantService`다. Gleo 설정 화면에서 Gleo Ai App 4.2.0.15, STT SDK 3.3.1, TTS SDK 3.3.1을 확인했다.
- 현재 Android user는 10이며 ASSISTANT 역할도 ai.umos.ambientai다. `cmd voiceinteraction show` 명령과 설정 화면 진입을 확인했다. 이 사실은 음성 인식이나 LLM 정상 응답의 증거가 아니다.
- 설치 앱의 SCRAP_APARTMENT action은 GleoActionReceiver로 resolve된다. 배포한 debug schema 함수는 GET_AREA_PRICE_SUMMARY / SCRAP_APARTMENT / GET_REAL_ESTATE_BRIEFING이다.
- 스키마의 Gleo 승인·DB 등록·실제 함수 인식은 확인되지 않았다. 앱 설치와 receiver resolve만으로 승인됐다고 판단하지 않는다.
- 앱 화면에는 ‘실거래를 불러오지 못했어요’, ‘오늘 일치 0건’, ‘스크랩 0’이 표시됐다. 따라서 실제 관심 매물 Nudge를 표시하는 선행 조건을 확보하지 못했다. 원인을 API 키 문제로 단정하지 않으며 키/local.properties는 열지 않았다.
- 실제 마이크 발화는 수행하지 않았다. 마이크 발화 가능 여부를 사용자에게 요청했다. host microphone forwarding은 활성화하지 않았고 voiceinteraction session은 hide했다.

## 이전 환경 기록의 정정

패키지 이름에서 gleo/voice/assistant만 찾으면 실제 Gleo인 ai.umos.ambientai를 놓친다. ‘Gleo로 식별 가능한 패키지가 없었다’는 이전 검색 결과로 Gleo 부재를 판단하지 않는다. 이후에는 현재 user의 assistant 설정, ASSISTANT role, voice interaction component 및 설정 화면을 기준으로 확인한다.

## 이어서 실행할 검증

1. 실제 데이터와 유효 위치·관심 조건을 준비해 관심 매물 배너를 띄운다. Nudge 없이 ‘스크랩해 줘’를 성공 처리하지 않는다.
2. Gleo 스키마 검토/활성화 상태를 공식 경로에서 확인한다. vendor의 private DB·권한을 임의 수정하지 않는다.
3. 발화 가능한 환경에서 host microphone 입력을 연결한 뒤 Gleo를 호출하고 ‘임과 함께에서 이 단지 스크랩해 줘’를 말한다.
4. STT 결과, SCRAP_APARTMENT 선택, 앱 수신, LOCAL/persisted=true callback, 배너 ‘스크랩함’, 주차 후 목록을 확인한다.
5. 배너 만료·P 전환·앱 background·중복 발화·탭과 음성 경합을 확인한다. 테스트 종료 후 마이크 전달을 해제한다.

안전한 read-only 확인 명령 예:

```bash
adb -s emulator-5556 shell am get-current-user
adb -s emulator-5556 shell settings --user 10 get secure voice_interaction_service
adb -s emulator-5556 shell cmd role get-role-holders --user 10 android.app.role.ASSISTANT
adb -s emulator-5556 shell cmd package query-receivers --brief -a SCRAP_APARTMENT -p com.potatoes.book5.realestate
```

공식 근거(2026-11-15 확인): [Gleo Interface](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/core-concepts), [schema 전달·검토](https://document.pleos.ai/docs/pleos-only/app-integration-guide/guide/deliver-schema). 승인·활성화는 앱 파일 배포와 구분한다.
