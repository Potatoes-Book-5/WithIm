# ADR-006 국토부 실거래가 HTTP 연동

## 배경
사용자가 Retrofit으로 국토부 실거래가 API를 우선 연결하도록 요청했다.
기존 UI는 만원 단위와 단지별 모델을 사용하지만 API는 지역·계약월별 거래 원본을 반환한다.

## 선택지
기존 단지 모델에 거래 원본을 억지로 채우거나 조회 전용 모델과 포트를 제공한다.

## 결정
Retrofit 2.11.0, OkHttp 4.12.0을 카탈로그에 추가한다. XML은 플랫폼 XmlPullParser로 스트리밍 파싱한다.
SDK, Kotlin, AGP 기준은 유지한다.
거래 원본 모델은 만원 및 전용면적 ㎡를 보존한다. 조회 Repository와 UseCase를 AppContainer에서 조립한다.
UI 및 대표 시세 계산은 별도 단계이며 샘플 순위를 실제 데이터라고 표시하지 않는다.
페이지는 요청자가 명시적으로 넘긴다. 무제한 전체 월·전국 수집이나 자동 폴링을 하지 않는다.
예상 가능한 오류는 기존 Outcome으로 반환한다. 키·URL·서버 원문·Throwable을 오류에 노출하지 않는다.
요청은 전체 20초, 연결 10초, 읽기 15초 제한을 사용하고 일시적 I/O 실패를 한 번 재시도한다.
인증/API 거절이나 HTTP 오류는 자동 재시도하지 않는다. 코루틴 취소를 보존한다.

## 결과와 영향
현재 ViewModel을 추가하지 않아도 앱의 UseCase로 호출할 수 있다.
세대수·단지 좌표·대표 시세·평수와 누락값 정책을 정한 뒤 기존 ApartmentRepository/RankingRepository에 매핑한다.
HTTP 캐시와 DB 거래 캐시는 이번 단계에 포함하지 않는다.
키는 환경변수 또는 사용자 Gradle 속성으로 주입한다. BuildConfig 키는 APK에서 추출 가능하다.
운영 배포 시 키 제한 및 서버 중계 필요성은 별도 결정한다.

## 출처
확인일: 2026-11-14.

- 해제 플래그의 값별 해석은 첨부문서에 없어 원문만 보존한다.
