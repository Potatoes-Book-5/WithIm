# ADR-002 Pleos SDK 경계 격리

## 배경

핵심 로직을 에뮬레이터 없이 검증해야 하고, 차량 모델마다 SDK 지원 범위가 다릅니다(CP-001, CP-004).

## 선택지

1. 화면과 로직에서 SDK를 직접 호출한다.
2. `vehicle/` 패키지에 SDK 호출을 모으고 `domain` 인터페이스로 노출한다.
3. SDK 연동을 별도 Gradle 모듈로 분리한다.

## 결정

2번을 제안합니다. 현재 규모에서 3번은 과하며, 필요해지면 `vehicle/`을 모듈로 분리할 수 있습니다.

## 결과와 영향

- `domain`은 JVM 단위 테스트로 검증할 수 있습니다.
- SDK 미지원 처리가 한 곳에 모입니다.
- 인터페이스 정의 비용이 추가됩니다.
