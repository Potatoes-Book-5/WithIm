# T-037 지도 탭 상위 5개 단지

## 목표

지도 탭의 기존 순위 행과 실제 좌표 마커를 최대 5위까지 표시한다. 순위 탭·홈·주행 기록은 상위 3개, 대장 판정은 1위로 유지한다.

## 범위 밖

지도 배율·조회 반경·카드 디자인·알림 빈도·SDK 변경. 가격을 임의로 채우거나 3km 밖 단지를 추가하지 않는다.

- [x] 기존 화면 모델과 지도·행 렌더링 구조 확인
- [x] 같은 가격·거래일 순서로 5위까지 좌표 검증
- [x] 지도용 순위만 분리해 기존 행과 마커로 표시
- [x] 빌드·문서 검사·독립 리뷰
- [x] 죽전역 도로 시나리오에서 5개 행과 순위 탭 3개 확인

## 검증 방법

사용자 요청대로 새 테스트 코드·단위 테스트 실행은 생략한다. 실제 API·에뮬레이터 화면, 빌드·lint·문서 검사로 확인한다. 4·5위가 관심 매물 우선 조회에 의해 빠지지 않는지 리뷰한다.
