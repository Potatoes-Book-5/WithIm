# T-048 추천 알림 매물을 주행 지도 별 핀으로 표시

## 목표

추천 알림이 노출된 단지의 실제 좌표를 주행 지도에 별 모양 강조 핀으로 표시하고, 다음 순위 갱신 뒤에도 현재 주행 화면에서 유지한다.

## 범위 밖

- 추천 점수, 후보 수집 및 알림 억제 정책 변경
- 앱 재시작 이후 지도 마커 복원
- 지도 핀 선택·상세 화면 진입

## 작업 체크리스트

- [x] 알림으로 전달된 추천 단지를 주행 화면 상태의 마커 목록에 누적한다.
- [x] 조건 일치 매물과 추천 알림 매물을 중복 없이 같은 별 핀으로 지도에 표시한다.
- [x] 별 핀의 강조색과 원형 배지를 대장 왕관 마커 스타일에 맞춘다.
- [x] 상태 reducer와 지도 마커 입력의 회귀 테스트를 추가한다.
- [x] SCR-009 명세와 작업 상태를 갱신한다.

## 검증 방법

- `./harness/verify.sh`로 문서/레지스트리 검사, assembleDebug, 단위 테스트, lint를 실행한다.

## 결정 로그

- 추천 알림 이벤트의 단지 좌표를 사용한다. 좌표를 다시 조회하거나 추가 API를 호출하지 않는다.
- 알림된 추천 마커는 같은 주행 화면 상태에 보관한다. 앱 재시작 간 보존은 범위에 넣지 않는다.
- 알림된 단지가 순위 마커에도 있으면 기존 순위 핀이 우선하며 별 핀은 중복 표시하지 않는다.

- 2026-11-15: 알림 후보 좌표를 상태에 누적하고 순위 핀에는 별 배지를, 그 밖의 알림 후보에는 별 핀을 표시했다. 문서 검사·assembleDebug·단위 테스트·lintDebug 통과.
