# T-020 국토부 실거래가 조회

## 목표
국토부 아파트 매매 실거래가 상세 API를 Retrofit으로 호출하고 앱 컨테이너의 UseCase로 제공한다.

## 범위
- 거래 원본 모델, Repository 포트, 조회 UseCase, Retrofit 서비스, XML 파서와 오류 처리
- 키를 환경 변수 또는 Gradle 속성으로 주입하고 저장소에 남기지 않는다.
- 현재 UI의 샘플 순위와 실거래 원본을 혼동하지 않는다. 지도·주소 좌표 변환·대표 시세 계산은 후속 작업이다.

## 진행
- [x] T-020 및 ADR-006 등록
- [x] 최신 UI 기준 독립 브랜치에 조회 코드를 적용
- [x] 빌드와 문서 검증
- [ ] 독립 리뷰와 PR 작성

## 확인
원래 개발 브랜치에서 에뮬레이터 앱을 통해 실제 국토부 API 응답(2026년 9월 영통구 거래 3건)을 확인했다. 이 PR은 조회 계층만 포함하므로 화면의 실거래 표시나 순위 데이터 교체는 후속 PR에서 다룬다. 별도 테스트 코드는 추가하지 않았다.
