# T-030 주행 실거래 화면 와이어프레임 복원

## 목표
T-023에서 와이어프레임과 다르게 바뀐 주행 화면을 SCR-004·SCR-009 Landscape 와이어프레임 배치로 되돌린다. 실거래 데이터, 조회 기준, 기간, 로딩·오류·빈 상태 표시는 유지한다.

## 범위 밖
Portrait 배치, 지도 SDK 표현, 알림 배너와 오버레이, 데이터 조회 로직.

## 결정 로그
- T-027부터 표와 카드가 같은 `snapshot.top`을 보여 주어 표는 중복이었다. 표를 없애고 와이어프레임 배치를 따른다.
- 조회 기준과 기간은 SCR-004 규칙상 표시해야 하므로 와이어프레임에 없는 상단 캡션 한 줄로 둔다.
- 여백은 와이어프레임대로 SCR-004는 좌우·아래 48px·위 36px, SCR-009는 32px·위 28px로 보기마다 다르게 둔다.
- 관심 매물 카드의 `앞·뒤`는 진행 방향을 알 때만 쓰도록 `MapPointUi`에 `directionKnown`을 추가한다.
