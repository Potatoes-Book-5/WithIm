# T-021 영통구 거래·좌표 연결

## 목표
수원시 영통구의 국토부 실거래를 조회하고 Vworld로 거래 주소를 좌표로 변환한다. 차량 좌표가 연결되기 전까지 삼성전자 수원 본사 주소를 임시 기준점으로 사용한다.

## 범위 밖
실제 차량 좌표, 내비게이션 주행거리, 단지별 대표 시세·순위, TTS, 좌표 영구 저장.

## 작업 체크리스트
- [x] T-021과 ADR-007 등록, 공식 출처 확인
- [x] 영통구 거래 조회와 Vworld 주소 좌표 변환 연결
- [x] 임시 기준점 및 거리 계산 연결
- [x] 빌드·문서 검사, 기존 개발 브랜치에서의 실제 호출 확인
- [x] 독립 리뷰
- [ ] PR 작성

## 검증 방법
기존 개발 브랜치에서 두 API의 실제 응답과 에뮬레이터 앱의 국토부 호출을 확인했다. 이번 PR 브랜치는 앱 빌드·문서 검사·독립 리뷰를 통과했으며, 이 브랜치에서 실제 API 호출을 다시 실행하지는 않았다. 키와 전체 요청 URL은 출력하거나 저장하지 않는다. 별도 테스트 코드는 추가하지 않는다.

## 결정 로그
- 사용자의 요청에 따라 강남구 대신 영통구를 고정 조회 지역으로 사용한다.
- 차량 좌표 대신 삼성전자 수원 본사 주소를 임시 기준점으로 사용한다.
- 거래 주소의 좌표는 Vworld에서 실시간 조회하고 영구 저장하지 않는다.
