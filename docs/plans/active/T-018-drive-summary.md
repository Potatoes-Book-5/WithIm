# T-018 주행 요약

## 목표

주행 세션을 기록하고, 주행이 끝나면 지난 주행 요약(SCR-008)을 보여 준다. 요약에서 지나친 관심 매물을 바로 스크랩한다(S-009).

## 범위 밖

- 실제 주행 상태(DI-001), 차량 위치와 주행 거리. 위치 SDK가 연결될 때까지 거리는 기록하지 않고 화면에서 뺀다(미결)
- 요약 공유, 음성 안내(S-009 음성 문구 없음)

## 설계

### 세션 기록(F-009 규칙 1, 2, 5)

- Drive로 바뀌면 세션을 연다. 열린 세션이 있으면 이어 쓴다.
- 주행 중 순위 스냅샷마다 저장한다. 앱이 중간에 종료돼도 저장된 지점까지 요약한다(SM-009).
  - 최종 Top 3는 마지막 스냅샷으로 덮어쓴다.
  - 대장이 바뀌면 시각과 새 대장을 기록한다. 알림 간격(5분)과 알림 동의와 관계없이 모두 기록한다.
  - 관심 매물은 처음 본 것부터 모아 두고, 가장 가까웠던 거리를 남긴다.
- Parking으로 바뀌고 3분(제안값)이 지나면 세션을 닫는다. 그 안에 다시 Drive가 되면 같은 세션을 이어 간다. 종료 시각은 주차한 시각이다.
- 앱을 다시 시작할 때 열린 세션은 마지막 기록 시각으로 닫는다.
- 순위 기록이 없는 세션은 요약을 만들지 않고 지운다.
- 요약은 최근 10건(제안값)만 남긴다.

### 저장(Room v3, 자동 마이그레이션)

| 테이블 | 내용 |
|---|---|
| `drive_sessions` | 시작·종료·마지막 기록 시각, 반경, 거리(현재 null), 확인 여부 |
| `drive_ranks` | 세션별 최종 Top 3 |
| `drive_leader_changes` | 세션별 대장 교체 시각과 단지 |
| `drive_passed_interests` | 세션별 지나친 관심 매물, 가장 가까운 거리, 가격 |

세션을 지우면 하위 행도 함께 지운다(외래 키 CASCADE).

### 화면(SCR-008)

- 세션이 닫히고 확인하지 않은 요약이 있으면 주차 중 화면 위에 요약을 띄운다. 앱이 꺼져 있었다면 다음 실행 때 띄운다.
- 요약을 열면 확인한 것으로 기록한다.
- 홈의 `지난 주행 요약` 타일은 가장 최근 요약을 연다. 없으면 빈 상태를 보여 준다.
- 단지를 누르면 상세(SCR-002), 스크랩 버튼은 바로 스크랩(탭 1회), `스크랩 목록 보기`는 SCR-007, 닫기는 이전 화면.
- 개발 빌드에는 3분을 기다리지 않고 세션을 닫는 `주행 종료` 버튼을 둔다.
