# T-027 앱 전체 실거래 데이터 전환

## 목표
홈·지도·주행 순위·상세·관심 동네·스크랩·주행 기록에서 런타임 샘플 부동산을 제거하고 하나의 실제 국토부/Vworld 데이터 흐름을 사용한다.

## 범위
최근 1개월의 실제 거래에서 단지별 최고 거래 총액 순위, 외부에서 전달받은 차량 위치 기준 직선거리 10km, 실제 주소 좌표, 실거래 상세·실제 월별 이력, 사용자 Room 스크랩·주행 기록.
위치 획득과 Pleos SDK 콜백은 친구가 연결한다. 이 작업은 `VehicleLocationInput` 입력 포트의 위치·정확도·시각·출처를 검증하고 시세 처리에 사용한다. 앱은 GPS 센서를 직접 읽거나 위치 권한을 요청하지 않는다. 개발 빌드의 에뮬레이터 경로만 별도 입력으로 사용한다. 수동 주행 전환은 개발용이다. 현재 API에 없는 세대수 등은 `정보 없음`으로 표시한다. Vworld 공식 시군구 경계 데이터에서 현재 위치 반경과 교차하는 시군구 코드를 조회해 해당 코드의 국토부 거래를 받는다. 전국 데이터를 한꺼번에 받는 방식은 아니다.

## 검증 방법
사용자 요청에 따라 새 테스트 사례와 테스트 실행을 생략한다. 빌드와 앱 실제 API 호출 후 홈/지도/상세/스크랩/주행 요약을 확인한다.

## 결정 로그
- 모든 화면에서 단지 ID를 공유한다. 순위는 최근 한 달의 단지별 최고 거래 총액이며 미제공 정보를 합성하지 않는다.
- 전달받은 모든 유효 위치 갱신에서 현재 위치와 지도 표시를 갱신한다. 시세 순위 재계산은 유의미한 500m 이동 또는 10km 경계 통과에서 수행하고, 같은 조회기간의 국토부 월별 원본은 재사용한다. 동의 없음·정확도 100m 초과·30초 지난 위치는 사용하지 않는다.
- 현재 위치와 진행 방향은 별개다. 방향을 모르면 지도는 북쪽을 위로 두고 앞·뒤를 표시하지 않는다.
- API 실패 시 기존 실제 결과를 보존하고 오류·조회 시각을 알린다. Vworld 좌표는 DB에 저장하지 않는다.
- 사용자 에뮬레이터 화면 검토를 마쳤고 네 PR 작성을 승인받았다. 머지는 별도 지시 전까지 진행하지 않는다.
- 에뮬레이터 이동 검토용 경로는 [동탄역(경기 화성시 동탄역로 151)](https://www.srail.or.kr/cms/archive.do?pageId=KR0406020000) → [삼성전자 수원 본사](https://www.samsung.com/sec/ir/reports-disclosures/public-disclosure/4005/)다. 공식 주소를 좌표로 바꾼 결과는 DB에 저장하지 않는다.
- 친구가 Pleos 위치 콜백을 연결할 수 있도록 `docs/platform/location-input.md`에 입력 계약과 개발용 경로 주입을 기록한다.
- 2026-11-14 사용자 요청: 차량 위치가 없는 첫 실행은 ADR-007의 삼성전자 수원 본사 기준으로 조회하고 실제 지도를 보여 준다. 실제 차량 위치로 오인하지 않도록 임시 기준을 표시하고 차량 마커와 위치 기반 알림을 막는다.
- 2026-11-14 Pleos Connect 에뮬레이터에서 삼성전자 기준 네이버 지도 타일, 반경 원, 순위 핀 3개와 차량 마커 부재를 확인했다. `:app:assembleDebug`와 문서 검사를 통과했다.
