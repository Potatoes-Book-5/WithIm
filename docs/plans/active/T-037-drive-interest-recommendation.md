# T-037 주행 관심 매물 실시간 추천

## 목표

저장된 관심 조건으로 주행 중 실제 차량 반경 10km의 단지 후보를 누적·평가하고, 기어 P로 주행이 끝날 때 요약 데이터에 최대 3개의 `지나친 관심 매물 3` 추천을 제공한다. 조건을 충족한 새 단지는 기존 근접 알림 경로(F-005/F-006)에 전달한다.

## 범위 밖

- UI와 연결되지 않은 별도 탐색 화면/경로
- 추천 결과 서버 업로드, 계정 동기화, 이동 좌표·경로 저장
- 투자 자문, 미래 가격 예측, 신규 외부 데이터 제공자 도입
- Pleos SDK·기어·위치 어댑터 변경

## 설계 개요

1. `RankingSnapshot`의 UI용 Top 3/지도 핀과 추천 후보를 분리한다. Vworld가 제공하는 반경 10km 경계 상자 교차 시군구 목록으로 최근 1개월 거래를 조회하고 거래 좌표로 실제 10km를 확인한다. 신규 주소 지오코딩은 시장 갱신당 기존 예산 18개이며 전체 단지 전수성을 보장하지 않는다.
2. 도메인 순수 정책이 선택된 조건 축별 0~5 점수를 산출하고 알려진 축 평균을 종합 점수로 만든다. 최고 축 코드를 `main_reco_key`로 저장하며 축 동점은 PRICE, AREA, NEIGHBORHOOD, HOUSEHOLDS, NEWNESS 순으로 고정한다. 단지 점수 동점은 거리, 안정 ID로 정렬한다.
3. 주행 세션별 후보를 기기에 영속화한다. 동일 안정 ID는 하나로 합치고 최소 관측 거리, 최신 평가/거래 기준일, 점수와 평가 근거를 갱신한다. Room 하위 레코드는 `drive_sessions` FK 및 세션 trim/delete CASCADE를 따른다.
4. 추천 상위 3개는 저장된 세션 후보에서 결정적으로 산출한다. 실제 알림으로 노출한 단지는 `drive_passed_interests`에도 기록해 상위 3개 순위가 바뀌어도 종료 요약에서 보존한다. 화면에서는 두 목록을 단지 ID로 중복 제거한다.
5. 신규 추천 알림은 새 임의 알림 스케줄러 대신 F-005 후보·억제 정책과 F-006 오디오/간소 알림 처리에 연결한다. 동일 위치 갱신에서 최대 1건, 한 단지 반복 억제를 적용한다.
6. 시장 후보 생성은 유효 차량 위치와 현재 시장 갱신 이벤트에만 반응한다. 임시 기준 위치를 쓰지 않고 네트워크 실패는 기존 후보를 보존한다.
