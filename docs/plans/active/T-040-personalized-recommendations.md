# T-040 스크랩·행동 피드백 기반 개인화 추천

## 목표

기존 관심 조건 기반 추천을 유지하면서, 사용자가 저장한 단지와 추천 카드에서 상세를 연 행동을 로컬 선호 프로필에 반영한다. 같은 후보와 프로필 입력에서는 점수가 결정적으로 재현되어야 한다.

## 범위 밖

- 서버 전송, 계정 간 동기화, 광고·마케팅 사용
- 외부 ML 런타임 또는 원격 AI 모델
- 추천 노출만으로 선호/비선호를 추정
- 운전자 위치나 이동 경로를 프로필 신호로 저장

## 작업 체크리스트

- [x] F-010과 S-011에 로컬 스크랩 프로필·추천 상세 열기 반응을 명세한다.
- [x] 기존 추천 정책에 행동 프로필 점수와 조건 점수를 결합하는 결정적 정책을 추가한다.
- [x] 스크랩 속성으로 현재 선호 프로필을 만들고, 추천 상세 열기 횟수는 단지별 제한된 집계값으로 보관한다.
- [x] 요약/모아보기의 추천 상세 진입만 반응을 기록하고 일반 상세 진입은 기록하지 않는다.
- [x] 사용자 데이터 삭제가 추천 반응 데이터까지 지우도록 연결한다.
- [x] Room v6→v7 자동 마이그레이션, 단위 테스트와 저장 계약 테스트를 추가한다.
- [x] 계획·기능 문서와 데이터 삭제 명세를 갱신한다.

## 검증 방법

- `./harness/verify.sh`로 문서/레지스트리 검사, assembleDebug, testDebugUnitTest, lintDebug 실행
- 로컬 기기(Room) 테스트를 실행할 수 있으면 `./harness/verify.sh --device`로 v6→v7 및 반응 집계를 확인
- 활성 에뮬레이터가 없으면 계측 검증은 미실행으로 기록

## 결정 로그

- 입력은 현재 활성 스크랩과 SCR-008/SCR-011 추천에서 상세를 연 단지로 한정한다.
- 상세 열기는 약한 긍정 신호이며 단지당 최대 10회로 집계한다. 활성 스크랩은 제거 전까지 별도 강한 신호로 사용한다.
- 노출만 되고 탭하지 않은 추천을 부정 신호로 취급하지 않는다.
- 반응은 단지별 최신 추천 속성과 상세 열기 횟수만 Room에 저장한다. 좌표, 주행 세션 ID, 원시 탭 시각은 저장하지 않는다.
- 암묵 신호의 종합 비중은 유효 신호 0개에서 0%, 유효 선호 예시 5개에서 최대 70%로 점진 증가한다. 기존 조건 점수는 계속 결합한다.
- 가격/면적/세대수/연식의 유사도 허용 폭은 순서대로 50,000만원, 15평, 1,500세대, 25년으로 둔다. 제품 수치가 아닌 추천 정책 상수이며 테스트로 고정한다.
