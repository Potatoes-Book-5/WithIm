# T-031 현재 구 3km 순위와 지역별 대장 라운드

## 목표
지도는 차량 주변 근거리 배율(최소 줌 18.5)로 고정하고 순위는 확정된 현재 시군구 안의 직선거리 3km로 제한한다. 새 시군구에서 유효한 위치가 30초 유지되면 새 라운드를 시작한다. 최근 1개월 거래 기준은 유지한다.

## 범위 밖
Pleos 위치 획득·SDK·권한 연결은 친구 담당이다. 기존 UI 배치와 스타일, 인증 설정, SDK 환경은 변경하지 않는다. 사용자가 main 대상 PR 게시를 승인했다. 검증 후 커밋·푸시·PR 게시까지 수행하고 머지는 하지 않는다.

## 작업 체크리스트
- [x] 현재 구 판별과 30초 경계 안정화, 3km 후보 필터 구현
- [x] 지도 근거리 배율 고정과 기존 표시 문구 연결
- [x] 지역 대장 발견과 같은 지역 대장 교체 구분
- [x] 지역 라운드 기록 보존과 주행 전체 최고가 요약 연결
- [x] 빌드·문서 검사·실제 앱/API 확인 및 독립 리뷰

## 검증 방법
사용자 지시에 따라 새 테스트 코드 작성과 단위 테스트 실행은 생략한다. :app:assembleDebug, 문서 검사, 실행 중인 에뮬레이터의 개발용 좌표 입력으로 실제 API 응답·지역 전환·경계 유지·지도 축척을 확인한다. DB 변경 시 기존 기록 보존을 함께 확인한다.

## 결정 로그
- 사용자 승인: 지도 근거리 배율(최소 줌 18.5), 현재 구 안 3km 순위, 새 구에서 30초 유지 후 새 라운드.
- 구가 없는 지역은 공식 시군구 코드를 단위로 사용한다. 가장 가까운 아파트나 주소 문자열로 차량 소재 구를 추정하지 않는다.
- 첫 유효 지역과 새 지역의 첫 대장은 발견, 동일 라운드의 1위 변경은 교체다.
- 거래가 없으면 빈 상태를 표시한다. 기간과 반경을 임의 확장하지 않는다.
- 지역 기록은 앱 로컬 주행 기록에만 저장하고 원좌표는 저장하지 않는다.
- 기존 작업 폴더의 T-028 인증 설정 및 임시 삼성전자 기준 위치 수정은 보존한다.
- 원격 친구 브랜치의 T-029 위치 연결 ID를 보존하고 이번 작업은 T-031으로 등록한다.

## 진행 기록
- 2026-11-14: 사용자 승인 후 등록·구조 조사 및 구현 시작.

- 공식 Vworld Data API 2.0 요청 명세에서 POINT(x y) 공간 필터를 확인했다. 지역 전환은 최대 5초 간격 공식 조회의 유효 관측에 기반하며 샘플 사이의 경계 통과까지 수학적으로 보장하지 않는다.
- 독립 리뷰에서 취소된 이전 요청의 loading 변경, GPS 복구의 발견 중복, 이전 위치 출처의 응답 간섭, 지역 기록 직후 종료 시각 역전을 찾아 수정했다.
- 앱 빌드·Pleos 에뮬레이터 설치 통과, 문서 검사 통과. 실제 기동한 Room v4에서 기존 스크랩 1개와 주행 요약 9개가 유지됨을 확인했다.

- 재현 중 강남구 주소 한 건의 NOT_FOUND 응답이 전체 실패로 처리되는 기존 파서 문제를 발견해 공식 명세대로 검색 결과 없음과 ERROR를 구분했다. 수정 후 강남구 실제 Top 3(51억, 50억, 46억 7,500만 원)와 영통구 실제 Top 3(16억 3,000만 원, 15억 3,000만 원, 14억 2,500만 원)를 확인했다.
- 18초만 다른 구로 이동한 뒤 복귀할 때는 라운드가 늘지 않았다. 30초 이상 유지 후 전환과 동일 구 재방문의 새 라운드를 실제 에뮬레이터 입력으로 확인했다.
- 기존 v3 스키마 및 보존 데이터 복사본에 실제 생성된 v3→v4 SQL을 적용해 스크랩 1개·주행 9개·순위 27개의 행 수 유지와 외래키 오류 0건을 확인했다. 단위 테스트는 실행하지 않았다.

- 사용자 친구들과 함께 보는 재현 요청에 따라 강남구→영통구를 다시 실행했다. 실제 화면에서 선경1차 51억→광교더샵 16억 3,000만 원 전환을 확인했다. 주행 기록의 지역별 최고가와 전체 최고가가 분리돼, 현재 영통구 순위로 바뀐 뒤에도 전체 최고가 Top 3는 강남구의 51억·50억·46억 7,500만 원으로 유지됐다.
- 사용자 화면 검토 중이라 지도 화면과 개발용 위치 입력을 잠시 유지한다. 에뮬레이터의 원래 location_consented=false 설정은 검토 종료 후 설정 화면에서 복원해야 한다. 현재 테스트 입력용으로만 true이며 실제 GPS SDK는 연결하지 않았다.
- 커밋·추가 PR 게시·머지는 수행하지 않았다.


- 추가 사용자 의견 반영: 지도 축척을 1km에서 근거리 배율(최소 줌 18.5)로 확대했다. 3km 검색과 순위표는 유지하며 대장 마커는 실제 좌표에 둔다. 차량 이동으로 지도 범위에 들어올 때 자연스럽게 보이고, 대장을 따라 카메라를 이동하거나 확대 범위를 늘리지 않는다.
