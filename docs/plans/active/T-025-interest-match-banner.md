# T-025 주행 중 관심 매물 상단 배너 알림

## 목표

주행 중 관심 조건에 맞는 단지에 가까워지면 주행 화면(SCR-004, SCR-009) 위에 상단 배너(SCR-005 A안)를 8초 동안 띄운다. 주차 후에는 주행 요약(SCR-008)의 `지나친 관심 매물`에서 모아 본다(E안의 모아보기, 이미 구현됨).

## 범위 밖

- TTS 재생(F-006, TextToSpeech SDK). 배너에는 기존 대장 교체 알림처럼 `음성 안내 중` 표시만 둔다.
- 음성 스크랩(STT)
- 재알림 억제 기록의 영구 저장. 앱 프로세스가 살아 있는 동안만 기억한다.
- 경로 진행 방향을 고려한 판정(F-005 미결)
- 실제 위치(F-001)와 실거래 단지 좌표(T-005)

## 설계

- 도메인 `ObserveInterestMatchAlertsUseCase`(F-005 규칙 2~4, F-006 규칙 5·7)
  - 순위 스냅샷의 `interestMatches` 중 알림 거리(제안값 2km) 안에 있는 단지만 후보로 삼는다.
  - 스크랩한 단지는 제외한다(변동 알림 F-008 대상).
  - 같은 단지는 알린 뒤 억제 기간(제안값 24시간) 동안 다시 알리지 않는다.
  - 관심 매물 알림이 꺼져 있으면 알리지 않는다.
  - 한 스냅샷에서 후보가 여럿이면 가장 가까운 1건만 알린다. 나머지는 주행 요약에 남는다(F-009 기록).
- 화면 알림은 한 칸(`DrivingAlertUi`)을 대장 교체와 함께 쓰고, 최신 1건만 보여 준다(F-006 규칙 5).
- 배너(SCR-005 A안): 앱 영역 상단, 어두운 카드, 별 아이콘, `관심 조건에 맞는 매물 · 앞 1.2km`, 단지명, 가격·평수, `음성 안내 중`, 스크랩 버튼 1개, 남은 시간 막대. 화면을 어둡게 덮지 않는다.
- 스크랩 버튼은 한 번 탭으로 스크랩한다(F-008 주행 중 한 번 탭, 허용 여부는 T-001 미확정). 누르면 `스크랩함`으로 바뀌고 다시 누를 수 없다.
