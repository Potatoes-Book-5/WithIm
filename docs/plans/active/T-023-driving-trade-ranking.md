# T-023 주행 실거래 랭킹

## 목표
주행 화면 오른쪽 표에 오늘 기준 최근 1개월 영통구 실제 거래 총액 상위 3건을 표시한다. 삼성전자 수원 임시 기준점 반경 10km 안의 거래만 사용한다.

## 범위 밖
실제 차량 위치, 내비게이션 SDK, 단지 대표 시세, 홈·주행 요약 데이터 교체.

## 작업 체크리스트
- [x] T-023 등록과 관련 화면·기능 명세 확인
- [x] 실제 거래 총액 순위와 반경 필터 구현
- [x] 주행 MVI 상태와 오른쪽 표 연결, 로딩·실패·빈 결과 표시
- [x] 빌드, 에뮬레이터 앱 실제 호출과 주행 화면 확인
- [x] 독립 리뷰와 문서 갱신

## 검증 방법
새 테스트 코드는 추가하지 않는다. 앱 빌드와 실제 에뮬레이터 호출로 조회 결과·정렬·거리·화면을 확인한다. 문서 검사를 실행한다.

## 결정 로그
- 거래 총액 내림차순, 동률이면 거래일 내림차순. 개별 거래 순위로 표시한다.
- 기간은 오늘의 날짜에서 한 달을 뺀 날짜부터 오늘까지 양끝 포함. 걸치는 계약 연월 API를 조회하고 거래일로 필터한다.
- 취소 관련 정보가 있는 거래는 후보에서 제외한다.
- 차량 위치가 연결되기 전이므로 삼성전자 수원 기준이라고 명시한다.
- 주행 화면 진입 시 한 번 조회하며 recomposition이나 보기 전환으로 재호출하지 않는다. 주차 시 진행 중 조회를 취소하고 다음 주행에서 기간과 데이터를 갱신한다.
- 기존 샘플 순위/지도 흐름과 실거래 표의 출처를 구분한다.

## 진행 기록
- 2026-11-14: 작업 등록, 구현 시작.
- 앱 빌드·설치와 문서 검사 통과. 1699×1140 에뮬레이터에서 순위·지도 보기의 표와 금액 표시를 확인했다.
- 실제 API 조회 기간 2026-10-14~2026-11-14: 광교e편한세상 38억(4.2km), 광교중흥에스클래스 25억 5,000만원(3.5km), 자연앤자이2단지 24억 1,000만원(3.6km).
- 독립 리뷰에서 확인한 창 너비·높이 문제를 비율 너비와 압축 행으로 수정했다. 새 테스트 사례와 테스트 실행은 사용자 요청에 따라 생략했다.
