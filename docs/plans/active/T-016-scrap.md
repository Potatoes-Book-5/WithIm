# T-016 스크랩 기능

## 목표

스크랩 목록(SCR-007)과 아파트 상세(SCR-002)를 구현하고, 스크랩 정보를 Room에 저장한다. 시세는 샘플 저장소로 대신하고 실거래가 API(T-005)는 이후 연결한다.

## 범위 밖

- 실거래가 API 연결, 순위 변동(`RANK_CHANGE`) 판단
- 주행 중 스크랩(알림, 주행 요약에서의 스크랩)
- 부부 간 스크랩 공유, 스크랩 개수 상한

## 작업 체크리스트

- [x] 저장 데이터 설계(F-008), ADR-005
- [x] Room, KSP 의존성과 `scraps` 테이블, DAO, 스키마 내보내기
- [x] domain: 스크랩, 단지 상세 모델, 변동 판단 규칙, UseCase
- [x] 화면 이동을 스택으로 바꿔 홈 → 상세, 홈 → 스크랩 목록 → 상세 지원
- [x] SCR-007 스크랩 목록(전체·변동 있음 필터)
- [x] SCR-002 아파트 상세(스크랩 토글, 추이 차트, 최근 거래)
