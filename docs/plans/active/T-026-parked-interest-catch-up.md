# T-026 주차 후 관심 매물 모아보기

## 목표

주행이 끝나면 지금처럼 주행 요약(SCR-008)을 띄우고, SCR-008의 `관심 매물 모아보기` 버튼으로 이번 주행에서 만난 관심 매물 화면(SCR-011, 시안 E안)을 연다. 두 화면의 와이어프레임 SVG를 만든다.

## 범위 밖

- 시안의 `지도에서 보기`(주차 중 지도 화면 없음)
- 단지를 지난 시각 표시(주행 기록에 시각 없음)
- 내비게이션 라이브러리 도입

## 설계

- `Screen.InterestCatchUp(sessionId)`를 추가한다.
- 자동 진입은 바꾸지 않는다. 확인하지 않은 요약이 생기면 SCR-008을 쌓는다.
- SCR-008 오른쪽 열 아래에 `관심 매물 모아보기 ›` 버튼(지나친 관심 매물이 있을 때만)을 두고, `OpenInterestCatchUp` Intent로 같은 주행의 SCR-011을 연다.
- SCR-011은 SCR-008과 같은 `DriveSummaryViewModel`(요약, 스크랩)을 쓴다. 앱 바는 SCR-007처럼 뒤로 버튼과 제목이다.
