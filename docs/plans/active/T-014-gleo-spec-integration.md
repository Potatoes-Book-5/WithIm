## 결정 로그

- 사용자가 지정한 `geonu/gleo-spec` 이름을 사용한다. 일반 브랜치 명명 규칙의 예시보다 명시 요청을 우선한다.
- 등록 변경은 별도 커밋으로 분리하되 사용자가 요청한 한 브랜치에서 함께 검토한다. 등록 ID는 main 머지 전까지 브랜치 초안이며, main에 합쳐진 뒤에만 팀의 유효 ID가 된다. main 머지나 등록 PR 자동 머지는 하지 않는다.
- 기능·규칙 원본을 중복 보관하는 단일 SPEC.md를 추가하지 않는다. 기존 기능은 보강하고, 새로운 도메인은 새 기능 문서로 분리한다.
- 테스트 상세의 원본은 CSV 한 곳이다. Markdown은 실행 가이드와 요구사항/기능 추적 색인이다.
- 기존 시안 C 오각형 결정은 유지한다. 임장 추천 점수는 별도 제안이며 기존 화면 점수를 대체하지 않는다.
- 플랫폼 지원과 제품 기본값은 구분한다. 사람의 승인이 필요한 항목은 미결로 남기며 승인되었다고 기록하지 않는다.
