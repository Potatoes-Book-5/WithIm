# T-017 마이 페이지

## 목표

마이 페이지(SCR-010, 시안 C)를 구현한다. 내 관심 조건을 오각형으로 보여 주고, 스크랩 단지를 조건과 비교해 일치율 상위 3곳을 보여 준다. 오각형 다섯 축(가격대, 평수, 동네, 세대수, 신축)을 채우기 위해 관심 조건에 세대수와 준공 연차를 추가한다.

## 범위 밖

- 실거래가 API(T-005) 연결. 세대수·준공연도는 샘플 단지 데이터를 쓴다
- 부부 각자 조건(시안 B), Portrait 2분할 프레임
- 홈 `설정`(SCR-006 재진입), 주행 요약(SCR-008)

## 결정(2026-11-14, 사용자)

- 세대수와 신축 축은 관심 조건 화면(SCR-003)에 칩 그룹을 추가해 사용자가 고른다. 각각 하나만 고르며 고르지 않아도 된다.
- 축별 만족도는 거리 기준으로 계산한다(제안값).

## 오각형 계산(제안값)

| 축 | 조건 범위 안 | 벗어났을 때 |
|---|---|---|
| 가격대 | 5 | 가장 가까운 구간 경계에서 10% 벗어날 때마다 −1 |
| 평수 | 5 | 가장 가까운 구간 경계에서 3평 벗어날 때마다 −1 |
| 동네 | 5 | 0 |
| 세대수 | 5 | 기준보다 100세대 적을 때마다 −1 |
| 신축 | 5 | 기준 연차보다 2년 오래될 때마다 −1 |

- 0~5로 자르고 소수 값을 그대로 그린다.
- 조건을 고르지 않은 축은 5로 본다.
- 단지 정보를 모르는 축(세대수, 준공연도가 없음)은 0으로 그리고 일치율 평균에서 뺀다.
- 일치율은 축 값 평균 × 20을 반올림한 백분율이다.
