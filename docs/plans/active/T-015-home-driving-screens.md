# T-015 홈·주행 화면 구현

## 목표

홈(SCR-001)과 주행 중 화면인 순위(SCR-004), 지도 모드(SCR-009), 대장 교체 알림(SCR-005)을 Landscape 기준으로 구현한다. 와이어프레임 `SCR-001_landscape_parked`, `SCR-004_landscape_driving`, `SCR-009_landscape_driving`, `SCR-005_landscape_driving`을 따른다.

## 범위 밖

- 실거래가 API(T-005), 지도 SDK(T-013): 포트와 샘플 구현만 두고 이후 저장소 구현을 교체한다.
- 실제 주행 규제 연동(CarUxRestrictions, DI-001): 개발 빌드 전용 시뮬레이션으로 대신한다.
- TTS 재생(F-006): 화면의 "음성 안내 중" 표시만 둔다.
- 상세, 스크랩, 마이 페이지, 주행 요약, 설정 화면: 버튼은 두고 "준비 중" 안내를 표시한다.
- Portrait 프레임
