# T-013 지도 SDK 연결(네이버 지도)

## 목표

주행 중 지도 모드(SCR-009)의 간이 지도(`SchematicMap`)를 네이버 지도 Android SDK로 바꾼다. 차량 위치를 중심으로 1·2·3위 순위 마커, 관심 매물, 그 밖의 단지, 거리 원(2km, 5km)을 표시한다.

## 범위 밖

- 홈(SCR-001) 지도. 지도는 주행 지도 모드에만 둔다(2026-11-14 사용자 확인).
- 실제 차량 위치(FusedLocation SDK, F-001)와 실거래 단지 좌표(T-005). 샘플 차량 위치와 샘플 좌표를 쓴다.
- 주행 중 지도 허용 여부(T-001), 다크 테마 지도 스타일, 오프라인 지도 캐시
- NaviHelper SDK로 내비 안내 요청

## 설계

- 도메인에 `GeoPoint`, `VehiclePose`(위치, 진행 방향)를 추가한다. `Apartment.location`, `RankingSnapshot.vehicle`은 null을 허용해 데이터 출처가 없으면 간이 지도를 쓴다.
- 샘플 순위 저장소는 차량 위치와 진행 방향에서 거리·상대 방위로 단지 좌표를 계산해 두 값이 서로 맞게 한다.
- `NaverDrivingMap`은 `AndroidView`로 `MapView`를 감싼다. Compose 래퍼는 추가 의존성이라 쓰지 않는다.
  - 진행 방향이 위, 차량은 아래쪽 약 3/4 지점(콘텐츠 패딩)에 둔다.
  - 확대, 이동, 회전, 기울기 제스처와 지도 컨트롤을 모두 끈다(SCR-009 공통).
  - 카메라는 애니메이션 없이 바꾼다(DD-005).
  - 마커: 1위 강조색 원 + 왕관, 2·3위 번호 원, 관심 매물 별, 그 밖의 단지 회색 점. Landscape라 라벨은 달지 않는다(SCR-009 시안 D).
- 클라이언트 ID가 비어 있거나 차량 위치가 없으면 `SchematicMap`으로 대체한다.
- 키는 `local.properties`의 `naver.map.clientId`(또는 콘솔 헤더 이름 `X-NCP-APIGW-API-KEY-ID`)에서 읽어 매니페스트 meta-data `com.naver.maps.map.NCP_KEY_ID`와 `BuildConfig.NAVER_MAP_CLIENT_ID`로 전달한다. Client Secret은 지도 표시에 필요 없어 앱에 넣지 않는다.

- 에뮬레이터: 주행 시작 → 지도 보기 → 네이버 지도와 Top 3·관심 매물 마커, 거리 원 확인 → 지역 이동 시 카메라와 마커 갱신 → 대장 교체 알림이 지도 위에 표시

## 결정 로그

- 2026-11-14: Pleos Connect에는 앱 안에 지도를 그리는 SDK가 없다(NaviHelper는 내장 내비 제어만 제공). 네이버 지도 SDK를 쓴다(사용자 결정, ADR-004).
- 2026-11-14: 지도는 홈이 아니라 주행 지도 모드(SCR-009)에 넣는다(사용자 확인).
- 2026-11-14: `Application`에서 `setClient()`로 설정하면 인증 오류 800(Client 미지정)이 나서, SDK 문서의 매니페스트 meta-data 방식으로 바꿨다.
- 2026-11-14: 줌은 SDK의 `Projection.getMetersPerDp(위도, 0)`로 계산한다. 256dp 타일을 가정한 계산은 실제보다 한 단계 확대됐다.
