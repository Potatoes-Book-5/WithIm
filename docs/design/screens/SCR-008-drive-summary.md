# SCR-008 주행 요약

## 목적

주행이 끝난 뒤 이번 주행의 순위 기록과 관심 매물을 정리해 보여 준다.

## 진입·이탈 경로

- 진입: 주행 종료(S-009, 기어 P 즉시, T-034) 후 자동, 다음 실행 시 자동(확인하지 않은 요약), 홈의 `지난 주행 요약` 타일(가장 최근 요약)
- 이탈: 닫기 후 이전 화면, 관심 매물 모아보기(SCR-011), 스크랩 목록, 단지 상세

## 정보 우선순위

1. 주행 거리와 시간
2. 최종 Top 3
3. 대장 교체 이력
4. `지나친 관심 매물 3` 추천 최대 3개
5. 기존 지나친 관심 매물과 스크랩 버튼

## 레이아웃

- 상단: 요약 제목, 거리, 시간
- 왼쪽: 최종 Top 3와 대장 교체 타임라인
- 오른쪽: `지나친 관심 매물 3` 추천 영역, 기존 지나친 관심 매물 목록과 스크랩 버튼, 그 아래 `관심 매물 모아보기 ›` 버튼(지나친 관심 매물이 있을 때만, T-026)
- 하단: 닫기

## 인터랙션과 음성

- 스크랩 토글
- 단지를 누르면 상세
- 추천 카드는 이름 아래 추천 키워드와 가격을 표시한다. 최근접 거리는 표시하지 않는다.
- `관심 매물 모아보기`를 누르면 같은 주행의 SCR-011

## T-031 표시값

지역 라운드 기록이 있는 요약은 기존 왼쪽 순위 카드 영역에 '이번 주행 최고가 TOP 3'를 표시한다. 대장 타임라인은 같은 위치에서 지역 이름·단지 이름을 표시하며 발견과 교체를 데이터에서 구분한다. 화면 배치와 관심 매물·스크랩·모아보기 동선은 유지한다. 이전 요약은 기존 최종 순위를 그대로 표시한다.
