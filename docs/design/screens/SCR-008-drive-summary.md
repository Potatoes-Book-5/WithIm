# SCR-008 주행 요약

## 목적

주행이 끝난 뒤 이번 주행의 순위 기록과 관심 매물을 정리해 보여 준다.

## 진입·이탈 경로

- 진입: 주행 종료(S-009), 다음 실행 시
- 이탈: 닫기 후 홈, 스크랩 목록

## 정보 우선순위

1. 주행 거리와 시간
2. 최종 Top 3
3. 대장 교체 이력
4. 지나친 관심 매물과 스크랩 버튼

## 레이아웃

- 상단: 요약 제목, 거리, 시간
- 왼쪽: 최종 Top 3와 대장 교체 타임라인
- 오른쪽: 지나친 관심 매물 목록과 스크랩 버튼
- 하단: 닫기
