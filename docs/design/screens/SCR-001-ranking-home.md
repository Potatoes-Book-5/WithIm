# SCR-001 홈

## 목적

주차 중 반경 10km 대장 아파트와 Top 3, 스크랩 변동을 한눈에 보여 준다.

## 진입·이탈 경로

- 진입: 앱 실행, 조건 설정 완료, 주행 요약 닫기
- 이탈: 상세(SCR-002), 스크랩(SCR-007), 마이 페이지(SCR-010), 설정(SCR-006), 주행 전환 시 SCR-004

## 정보 우선순위

1. 대장 아파트(1위) 단지명과 가격
2. 2·3위
3. 스크랩 변동 건수
4. 데이터 기준 시각

T-027부터 홈 순위는 최근 1개월 실제 거래의 단지별 최고 총액 기준이다. Vworld 시군구 경계 데이터로 기준 위치 주변의 시군구 코드를 정하고 국토부 거래를 조회한 뒤, 기준 위치에서 직선거리 10km 이내인 거래만 포함한다. 기존 화면 배치는 유지하고 부제 한 줄에 계약일 범위·조회 기준·API 조회 시각·상태를 간결하게 표시한다. 차량 위치가 없으면 삼성전자 수원 본사 기준 결과임을 명시한다.

## 레이아웃

- 왼쪽 2/3: 대장 카드와 2·3위 목록
- 오른쪽 1/3: 스크랩 변동, 오늘의 관심 매물, 바로가기
- 상단: 앱 이름, 현재 동네, 반경 표시

## 인터랙션과 음성

- 순위 행을 누르면 상세로 이동
- 조회 오류에는 마지막 실제 거래 결과를 유지하며 재조회 버튼을 제공한다. 결과가 없을 때는 로딩·빈 결과·오류를 구분한다.
- 상단 `마이 페이지` 버튼과 오른쪽 `관심 조건` 카드를 누르면 마이 페이지(SCR-010)로 이동, 조건 수정은 마이 페이지에서 한다
- 변동 카드를 누르면 스크랩 목록 '변동 있음' 필터
- 주행 전환 시 SCR-004로 자동 전환
