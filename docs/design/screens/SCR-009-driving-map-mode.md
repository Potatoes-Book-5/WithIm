# SCR-009 주행 중 지도 모드

## 목적

주행 중 차량 위치를 기준으로 주변 아파트(순위 단지, 관심 매물)의 상대 위치를 한눈에 보여 준다. 주행 중 순위 화면(SCR-004)의 두 번째 보기다.

## 결정

2026-11-13 팀 결정으로 **Portrait는 2D 지도(시안 A), Landscape는 2D 지도와 순위 목록(시안 D)**을 사용한다.

| 시안 | 결과 | 이유 |
|---|---|---|
| A. 2D 지도 (Portrait) | 채택 | 반경 10km를 한 화면에 담고 실제 길과 위치가 맞음 |
| D. 2D 지도 + 순위 목록 (Landscape) | 채택 | A와 같은 지도 스타일로 위치와 순위를 동시에 확인 |
| C. 레이더 | 대체안 | 지도 SDK를 쓸 수 없거나 주행 중 지도가 허용되지 않을 때 검토 |
| B. 3D 원근 뷰 | 제외 | 원근 때문에 먼 단지가 지평선에 몰리고, 렌더링과 움직임이 주행 중 규칙(PF-002, DD-005)에 부담 |

## 진입·이탈 경로

- 진입: SCR-004 상단의 `순위 | 지도` 전환
- 이탈: 같은 전환으로 SCR-004, 주차 전환 후 홈 또는 주행 요약
- 마지막으로 고른 보기를 기억해 다음 주행에도 사용한다(제안값).

## 정보 우선순위

1. 내 차량 위치와 진행 방향
2. 1위(대장) 단지의 방향과 거리
3. 관심 매물의 방향과 거리
4. 2·3위 단지
5. 알림 거리(2km) 범위

## 레이아웃

### Portrait (시안 A)

- 상단: `순위 | 지도` 전환, 반경 표시, 주행 중 배지
- 지도: 진행 방향이 위인 2D 지도이고, 차량은 아래쪽 약 3/4 지점에 고정한다.
- 거리 원: 2km(알림 거리, 점선)와 5km
- 핀: 1위는 왕관과 강조색, 2·3위는 번호, 관심 매물은 별, 그 밖의 단지는 작은 회색 점
- 라벨: 1·2위와 관심 매물에만 단지명과 가격 또는 거리 한 줄
- 화면 밖 단지: 가장자리 표시(예: 3위 뒤쪽 6.8km)
- 하단: Top 3 요약 줄

### Landscape (시안 D)

- 왼쪽: 시안 A와 같은 2D 지도, 라벨 없이 핀만 표시
- 오른쪽: Top 3 목록(가격, 앞뒤 방향과 거리)과 관심 매물 카드

T-023에서는 오른쪽에 한 달 전 날짜부터 오늘까지(양 끝 포함) 영통구 **개별 실거래 상위 3건 표**를 추가한다. 기간이 두 달력 월에 걸치면 두 월의 API를 조회하고 실제 거래일로 거른다. 삼성전자 수원 본사 임시 기준점에서 직선거리 10km 이내만 표시하고 거래금액 총액 내림차순·거래일 최신순으로 정렬한다. 해제된 거래는 제외한다. 표에 실제 날짜 범위를 표시한다. 지도 핀과 기존 순위 카드는 여전히 샘플이며 실제 거래 표와 연결된 것으로 표시하지 않는다. 표에는 로딩·오류·빈 결과 상태를 제공한다.

### 공통

- 지도는 진행 방향이 바뀌어도 부드러운 회전 대신 단계적으로 갱신한다(DD-005, 제안값).
- 주행 중 지도 조작(확대, 이동, 핀 선택)은 제공하지 않는다.
