# SCR-009 주행 중 지도 모드

## 목적

주행 중 차량 위치를 기준으로 주변 아파트(순위 단지, 관심 매물)의 상대 위치를 한눈에 보여 준다. 주행 중 순위 화면(SCR-004)의 두 번째 보기다.

## 결정

2026-11-13 팀 결정으로 **Portrait는 2D 지도(시안 A), Landscape는 2D 지도와 순위 목록(시안 D)**을 사용한다.

| 시안 | 결과 | 이유 |
|---|---|---|
| A. 2D 지도 (Portrait) | 채택 | 반경 3km를 한 화면에 담고 실제 길과 위치가 맞음 |
| D. 2D 지도 + 순위 목록 (Landscape) | 채택 | A와 같은 지도 스타일로 위치와 순위를 동시에 확인 |
| C. 레이더 | 대체안 | 지도 SDK를 쓸 수 없거나 주행 중 지도가 허용되지 않을 때 검토 |
| B. 3D 원근 뷰 | 제외 | 원근 때문에 먼 단지가 지평선에 몰리고, 렌더링과 움직임이 주행 중 규칙(PF-002, DD-005)에 부담 |

## 진입·이탈 경로

- 진입: SCR-004 상단의 `순위 | 지도` 전환
- 이탈: 같은 전환으로 SCR-004, 주차 전환 후 홈 또는 주행 요약
- 마지막으로 고른 보기를 기억해 다음 주행에도 사용한다(제안값).

## 정보 우선순위

1. 내 차량 위치와 진행 방향
2. 1위(대장) 단지의 방향과 거리
3. 관심 매물의 방향과 거리
4. 2·3위 단지
5. 알림 거리(2km) 범위

## 레이아웃

### Portrait (시안 A)

- 상단: `순위 | 지도` 전환, 반경 표시, 주행 중 배지
- 지도: 진행 방향이 위인 2D 지도이고, 차량은 아래쪽 약 3/4 지점에 고정한다.
- 거리 원: 50m와 100m
- 핀: 1위는 왕관과 강조색, 2·3위는 번호, 관심 매물은 별, 그 밖의 단지는 작은 회색 점
- 라벨: 1·2위와 관심 매물에만 단지명과 가격 또는 거리 한 줄
- 화면 밖 단지: 가장자리 표시(예: 3위 뒤쪽 6.8km)
- 하단: Top 3 요약 줄

### Landscape (시안 D)

- 왼쪽: 시안 A와 같은 2D 지도, 라벨 없이 핀만 표시
- 오른쪽: Top 5 목록(가격, 앞뒤 방향과 거리)과 관심 매물 카드(T-037)

T-027부터 지도 중심, 실거래 단지 마커와 오른쪽 순위 목록은 같은 기준 위치와 최근 3개월 실제 거래를 공유한다. T-030부터 T-023의 별도 실거래 표를 없애고 시안 D대로 오른쪽 520px 열에 `반경 3km 순위` 제목, Top 3 행(176px), 관심 매물 카드를 둔다. 조회 기준과 계약일 범위는 상단 `반경 3km` 오른쪽 한 줄에 표시하고, 순위가 비어 있으면 목록 자리에 조회 중·오류·빈 결과를 표시한다. 관심 매물 카드는 진행 방향을 모르면 `앞·뒤` 없이 거리만 쓴다. 차량 위치가 없으면 삼성전자 수원 본사를 임시 지도 중심으로 쓰고, 실제 차량 위치가 들어오면 자동으로 전환한다. Vworld 경계 데이터로 기준 위치의 3km 경계 상자와 교차하는 시군구를 고르고, 실제 거래 좌표가 3km 이내인 거래만 표시한다. 해제 거래는 제외한다. 유효 위치를 받을 때마다 지도 중심을 갱신하고 500m 이상 이동하거나 반경 경계를 넘을 때 순위를 다시 평가한다.

### 공통

T-037에서는 지도 탭의 순위 행과 순위 마커를 최대 5개로 늘린다. 기존 행 높이(최대 176px)·열 너비·지도 배율·3km 반경은 유지하며 단지가 부족하면 받은 단지만 표시한다. 관심 매물 카드가 함께 표시되거나 화면이 낮으면 남는 높이를 다섯 행에 나눠 하단 카드가 잘리지 않게 한다. 순위 탭·홈·주행 기록의 Top 3 및 1위 대장 판정·같은 지역 5분 알림 제한은 변경하지 않는다. 4·5위도 가격·거래일 순으로 좌표를 확인하며, 관심 매물 우선 조회 결과에서 임의로 골라 채우지 않는다.

- 지도는 네이버 지도 SDK로 그린다(ADR-004). 위치 콜백이 없거나 권한·SDK 미지원 상태이면 삼성전자 수원 본사 기준으로 실제 지도를 그리되 차량 마커는 그리지 않고 임시 기준을 명시한다. 지도 클라이언트 ID가 없으면 사유를 알리는 상태 화면을 보인다. 가상의 도로는 그리지 않는다.
- 진행 방향이 확인되면 그 방향을 위로, 확인되지 않으면 북쪽을 위로 표시한다. 방향을 모를 때 차량 마커는 점으로 그리고 앞·뒤 표현을 생략한다.
- 차량 위치는 FusedLocation SDK가 보내 위치 입력 포트가 사용 가능(AVAILABLE)으로 판정한 위치다(T-029). SDK `heading`은 단위가 문서에 없어 진행 방향은 미확인(null)으로 넘기며, 지도의 차량 마커·거리 원·순위 핀은 실거래 저장소(`LiveMarketRepository`) 스냅샷을 따른다.
- 거리 원은 SDK가 점선을 지원하지 않아 50m는 강조색 실선, 100m는 회색 실선으로 그린다.
- 지도는 진행 방향이 바뀌어도 부드러운 회전 대신 단계적으로 갱신한다(DD-005, 제안값).
- 주행 중 지도 조작(확대, 이동, 핀 선택)은 제공하지 않는다.

## T-031 지도 축척

지도는 위치 주변 근거리 배율(최소 줌 18.5)를 담는 고정 축척을 사용한다. 거리 원은 50m와 100m다. 순위 조회 반경 3km와 카메라 축척은 독립적이며, 지도 밖의 상위 단지를 모두 담기 위한 자동 축소를 하지 않는다. 기존 배치·카드 비율·버튼·차량 위치는 유지한다. 오른쪽 표는 확정된 지역 이름과 3km 기준을 기존 텍스트 위치에 표시한다.


대장 마커는 실제 단지 좌표에 둔다. 현재 화면 밖이면 숨겨지고 차량이 가까이 이동해 화면에 들어오면 보인다. 화면 가장자리의 가짜 위치로 옮기거나 대장 위치로 카메라를 이동하지 않는다.
