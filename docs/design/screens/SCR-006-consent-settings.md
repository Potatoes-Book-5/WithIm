# SCR-006 동의와 설정

## 목적

첫 실행 시 위치 사용 이유를 설명하고 동의를 받는다. 이후 알림과 데이터 설정을 제공한다.

## 진입·이탈 경로

- 진입: 앱 첫 실행, 홈의 `설정`(수정 모드)
- 이탈: 동의 후 SCR-003, 설정은 저장 또는 취소 후 홈

## 정보 우선순위

1. 앱 소개 한 줄
2. 위치 사용 이유
3. 알림 설정
4. 동의 버튼

## 레이아웃

- 왼쪽: 앱 이름과 소개
- 오른쪽: 사용 이유 3개 항목과 알림 토글
- 하단: 동의하고 시작

## 문구

| 위치 | 문구 |
|---|---|
| 제목 | 임과 함께, 임장을 더 즐겁게 |

| 설정 제목 | 설정 · 주차 중에만 바꿀 수 있어요. 저장을 눌러야 반영돼요 |
| 설정 토글 | 차량 위치 사용, 관심 매물 알림, 대장 교체 알림 |

| 삭제 확인 | 저장된 데이터를 모두 삭제할까요? 관심 조건, 스크랩, 주행 기록이 이 차량에서 지워지고 되돌릴 수 없어요. (취소 / 삭제) |

## 설정 수정 모드(T-019)

- 저장된 동의와 알림 값을 불러와 토글을 바꾸고 `저장`을 눌러야 반영한다. `취소`는 바꾸지 않고 닫는다.
- `모두 삭제`는 확인 대화상자를 거쳐 관심 조건, 스크랩, 주행 기록을 지운다. 동의와 알림 설정은 남긴다(F-007 규칙 3).
- TTS 사용 여부 토글(F-007 규칙 2)은 TTS 기능(T-001, T-003)이 정해질 때 추가한다.
- 불러오는 동안 설정 영역은 비워 둔다.

## S-011 동의·프로필 제안

위치 기반 조회·관심 지역 저장·선택적 자동 알림을 구분해 설명한다. 목소리로 개인을 식별한다고 안내하지 않는다. 지역/문맥/예약 알림/브리핑 이력 삭제의 범위와 실제 보관기간은 [F-007](../../product/features/F-007-consent-settings.md)의 검토 초안이며 승인 전 미결로 표시한다. 카메라/녹화 기능은 MVP 설정에서 활성화할 수 없다.
