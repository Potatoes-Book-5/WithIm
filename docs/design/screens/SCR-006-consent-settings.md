# SCR-006 동의와 설정

## 목적

첫 실행 시 위치 사용 이유를 설명하고 동의를 받는다. 이후 알림과 데이터 설정을 제공한다.

## 진입·이탈 경로

- 진입: 앱 첫 실행, 홈의 설정
- 이탈: 동의 후 SCR-003, 설정 닫기 후 홈

## 정보 우선순위

1. 앱 소개 한 줄
2. 위치 사용 이유
3. 알림 설정
4. 동의 버튼

## 레이아웃

- 오른쪽: 사용 이유 3개 항목과 알림 토글

## S-011 동의·프로필 제안

위치 기반 조회·관심 지역 저장·선택적 자동 알림을 구분해 설명한다. 목소리로 개인을 식별한다고 안내하지 않는다. 지역/문맥/예약 알림/브리핑 이력 삭제의 범위와 실제 보관기간은 [F-007](../../product/features/F-007-consent-settings.md)의 검토 초안이며 승인 전 미결로 표시한다. 카메라/녹화 기능은 MVP 설정에서 활성화할 수 없다.
