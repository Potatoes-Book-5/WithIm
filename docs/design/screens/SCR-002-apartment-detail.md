# SCR-002 아파트 상세

## 목적

선택한 단지의 실거래 정보와 변동을 보여 주고 스크랩하게 한다.

## 진입·이탈 경로

- 진입: 홈, 스크랩 목록, 주행 요약
- 이탈: 뒤로 가기

## 정보 우선순위

1. 단지명과 최근 실거래가
2. 스크랩 버튼
3. 변동 내용(있을 때)
4. 단지 기본 정보
5. 최근 거래 내역

## 레이아웃

- 상단: 뒤로, 단지명, 스크랩 버튼
- 왼쪽: 최근 실거래가, 변동 배지, 가격 추이
- 오른쪽: 기본 정보와 최근 거래 3건
