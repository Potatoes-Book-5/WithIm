# SCR-002 아파트 상세

## 목적

선택한 단지의 실거래 정보와 변동을 보여 주고 스크랩하게 한다.

## 진입·이탈 경로

- 진입: 홈, 스크랩 목록, 주행 요약, 관심 지역(SCR-011)의 추천 단지
- 이탈: 뒤로 가기

## 정보 우선순위

1. 단지명과 최근 실거래가
2. 스크랩 버튼
3. 변동 내용(있을 때)
4. 단지 기본 정보
5. 최근 거래 내역

## 레이아웃

- 상단: 뒤로, 단지명, 스크랩 버튼
- 왼쪽: 최근 실거래가, 변동 배지, 가격 추이
- 오른쪽: 기본 정보와 최근 거래 3건

## R-04 — 주차 심층 분석 확장

- 상세 허용은 [상태 매트릭스](../../product/feature-state-matrix.md)를 따른다. 신호 대기는 상세 허용 상태가 아니다.
- 가로 창은 왼쪽 추천 1~3위, 오른쪽 지역 추이/선택 단지 거래/입지 요약을 배치한다. 좁은 창은 목록→상세 순차 탐색으로 전환한다.
- 가격 순위와 맞춤 추천을 제목·단위로 분리하고, 출처/기준일·표본·면적·축을 표시한다. 계산 규칙은 F-002/F-004에서만 정의한다.
- 후보 없음·부분 오류·과거 캐시 상태를 구분한다. 선택 단지 응답 역전으로 이전 그래프가 덮어쓰지 않게 한다.
- 주행 전환 시 상세/입력을 제거하고 선택 단지만 보존한다. 다시 주차해도 자동으로 상세를 띄우지 않는다.
- 출입구 주소와 `경로 안내` 동작을 추가한다. 교체 확인·접수/실제 안내 구분은 [F-012](../../product/features/F-012-apartment-navigation.md)을 따른다.
- light를 기본으로 하고 플랫폼 주야간 규칙에 대응한다. 새 상태의 와이어프레임/Figma는 아직 작성하지 않았다.
- 기능: F-010, F-011, F-012. 여정: S-011. 검증: [테스트](../../testing/gleo-tour/README.md).
