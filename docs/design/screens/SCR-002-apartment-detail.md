# SCR-002 아파트 상세

## 목적

선택한 단지의 실거래 정보와 변동을 보여 주고 스크랩하게 한다.

## 진입·이탈 경로

- 진입: 홈, 스크랩 목록, 주행 요약
- 이탈: 뒤로 가기

## 정보 우선순위

1. 단지명과 최근 실거래가
2. 스크랩 버튼
3. 변동 내용(있을 때)
4. 단지 기본 정보
5. 최근 거래 내역

T-027에서는 국토부에서 받은 단지의 실제 거래만 표시한다. 세대수처럼 응답에 없는 항목은 `정보 없음`, 준공연도가 누락된 경우도 `정보 없음`으로 표시한다. 평형은 전용면적(㎡) 환산값이므로 `전용환산평`으로 표기한다. 가격 차트는 조회기간에 실제로 받은 월별 거래값만 연결하며 두 점 미만이면 추이 부족을 알린다. 연도별 값을 임의로 채우지 않는다. 거리는 외부에서 전달받은 현재 차량 위치 기준 직선거리다.

## 레이아웃

T-033에서 세대수는 [공동주택 API](../../platform/kapt-api.md)로 보충한다. 단지명·주소가 검증된 값만 표시하고 미확인·조회 실패 시 기존 `정보 없음`을 유지한다. 스크랩에도 기존 저장·보충 흐름으로 반영한다. 화면 배치는 변경하지 않는다.

- 상단: 뒤로, 단지명, 스크랩 버튼
- 왼쪽: 최근 실거래가, 변동 배지, 가격 추이
- 오른쪽: 기본 정보와 최근 거래 3건
