# SCR-012 데일리 브리핑

## 목적

관심 지역의 신규 공개 거래·청약·선택 뉴스와 조회 상태를 전달한다.

## 진입·이탈 경로

- 진입: 홈(SCR-001), 관심 지역(SCR-011), 허용된 요청형 Gleo 경로
- 이탈: 해당 지역/단지, 뒤로

## 정보 우선순위

1. 대상 프로필/지역
2. 최대 3개 요약 카드
3. 원천·게시/거래일·수집 시각
4. 부분 실패/과거 자료 상태

## 레이아웃

- 카드형 목록. 뉴스 플래시는 정적 카드이며 자동 스크롤/점멸 없음
- 가로·세로·분할 창에서 출처/기준일이 잘리지 않음
- 기본/새 소식 없음/오프라인/부분 실패/프로필 미확정 상태. 새 Figma·와이어프레임은 미작성

## 컴포넌트

지역/브리핑 카드, 출처·기준일, 빈/오류 안내, 주차 중 명시 동작을 사용한다. 새 디자인 토큰/실제 Figma 프레임은 이 문서에서 확정하지 않는다.

## 상태 변형

위 레이아웃의 상태는 문서 명세만 존재한다. light 기본과 플랫폼 주야간 규칙을 적용한다. 와이어프레임 미작성은 플랫폼 사용 승인과 별도다.

## 인터랙션과 음성

- 요청형 기본. 시동/자동 발화 API 검증 전 자동으로 화면을 열지 않음
- 주행 중 상세 클릭 차단. 승인된 간소 카드/음성만 조건부 제공
- 실제 카드 열람/검증된 완료 이벤트와 체크포인트 규칙은 F-013 참조

## 문구

관심 지역 새 소식 · 새로 공개된 거래 · 청약 소식을 확인하지 못했습니다
