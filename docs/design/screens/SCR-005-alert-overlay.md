# SCR-005 알림 표시

## 목적

관심 매물 발견과 대장 교체를 TTS와 함께 짧게 표시한다.

## 진입·이탈 경로

- 진입: F-006 알림 이벤트
- 이탈: 8초 후 자동 닫힘

## 정보 우선순위

1. 알림 종류
2. 단지명
3. 거리 또는 가격
4. TTS 재생 표시

## 레이아웃

- 주행 화면 위 카드 형태로 표시하고 Driving View를 가리지 않는다(SM-001).
- 버튼은 최대 1개(스크랩)이며 허용 여부 미확정

## 컴포넌트

| 영역 | 컴포넌트 | 비고 |
|---|---|---|
| 카드 | 알림 카드 | Shadow Level 3 후보 |
| 버튼 | Basic Button | 주행 중 허용 미확정 |

## 인터랙션과 음성

- 자동 닫힘 8초(제안값)
- 스크랩 한 번 탭 또는 음성 '스크랩해 줘'
