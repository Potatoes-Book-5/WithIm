# SCR-005 알림 표시

## 목적

관심 매물 발견과 대장 교체를 TTS와 함께 짧게 표시한다.

## 진입·이탈 경로

- 진입: F-006 알림 이벤트
- 이탈: 8초 후 자동 닫힘

## 정보 우선순위

1. 알림 종류
2. 단지명
3. 거리 또는 가격
4. TTS 재생 표시

## 레이아웃

- 주행 화면 위 카드 형태로 표시하고 Driving View를 가리지 않는다(SM-001).
- 버튼은 최대 1개(스크랩)이며 허용 여부 미확정
- 관심 매물 발견은 앱 영역 상단 배너로 띄운다(A안, 2026-11-14 사용자 결정, T-025). 화면을 어둡게 덮지 않고 아래 순위·지도가 그대로 보인다.
  - 왼쪽: 별 아이콘(지도의 관심 매물 마커와 같은 기호)
  - 가운데: 알림 종류와 방향·거리, 단지명, 가격·평수
  - 오른쪽: `음성 안내 중`, 스크랩 버튼
  - 아래: 남은 시간 막대
- 대장 교체는 지금처럼 화면 전체 위 카드로 띄운다. 두 알림이 겹치면 최신 1건만 보인다(F-006 규칙 5).
- 주차 후 다시 보기는 주행 요약(SCR-008)의 `지나친 관심 매물`이 맡는다(E안의 모아보기).

## 인터랙션과 음성

- 자동 닫힘 8초(제안값)
- 스크랩 한 번 탭 또는 음성 '스크랩해 줘'(음성은 STT 연결 후)
- 스크랩하면 버튼이 `스크랩함`으로 바뀌고 다시 누를 수 없다. 해제는 주차 후 스크랩 목록에서 한다.
