# SCR-005 알림 표시

## 목적

추천 매물 발견과 대장 교체를 TTS와 함께 짧게 표시한다.

## 진입·이탈 경로

- 진입: F-006 알림 이벤트
- 이탈: 대장 교체는 10초, 관심 매물은 15초 후 자동 닫힘(T-041 후속: TTS 질문과 응답 시간)

## 정보 우선순위

1. 알림 종류
2. 단지명
3. 거리 또는 가격
4. TTS 재생 표시

## 레이아웃

- 주행 화면 위 카드 형태로 표시하고 Driving View를 가리지 않는다(SM-001).
- 버튼은 최대 1개(스크랩)이며 허용 여부 미확정
- 관심 매물 발견은 앱 영역 상단 배너로 띄운다(A안, 2026-11-14 사용자 결정, T-025). 화면을 어둡게 덮지 않고 아래 순위·지도가 그대로 보인다.
  - 왼쪽: 별 아이콘(지도의 관심 매물 마커와 같은 기호)
  - 가운데: 알림 종류와 방향·거리, 단지명, 가격·평수
  - 오른쪽: 음성 스크랩 안내(마이크, `“스크랩해 줘” 라고 말하면 저장돼요`), 스크랩 버튼. 대장 교체 알림의 `음성 안내 중` 자리를 음성 스크랩 안내로 바꾼다(2026-11-14 사용자 요청, DD-011).
  - 아래: 남은 시간 막대
- 대장 교체는 지금처럼 화면 전체 위 카드로 띄운다. 추천 알림의 음성 응답 시간에는 안내 중인 단지를 고정한다. 이때 새 추천·대장 이벤트가 와도 덮어쓰거나 질문을 다시 읽지 않으며 발견 기록은 주행 요약에 남긴다.
- 주차 후 다시 보기는 주행 요약(SCR-008)의 `지나친 관심 매물`이 맡는다(E안의 모아보기).

## 인터랙션과 음성

- 자동 닫힘: 대장 교체 10초(2026-11-14 사용자 결정), 관심 매물 15초(T-041 후속)
- 스크랩 한 번 탭 또는 음성 '스크랩해 줘'(음성은 debug Gleo action 연결 후)
- 관심 매물 배너가 떠 있는 동안 '스크랩해 줘'를 들으면 탭 없이 바로 스크랩한다. TTS 안내가 끝난 뒤부터 배너가 닫힐 때까지 듣는다(제안값).
- T-041의 SCRAP_APARTMENT로 스크랩하면 안내 자리가 `스크랩했어요 · 주차 후 스크랩 목록에서 확인`으로, 버튼이 `스크랩함`으로 바뀌고, 배너는 남은 시간 뒤 닫힌다.
- 스크랩하면 버튼이 `스크랩함`으로 바뀌고 다시 누를 수 없다. 해제는 주차 후 스크랩 목록에서 한다.

## T-031 지역 대장 발견

새 라운드 첫 1위는 기존 대장 알림 영역에서 '새 지역의 대장을 발견했어요'와 지역·단지 이름으로 표시한다. 같은 라운드의 이후 교체는 기존 화살표 비교를 유지한다. 배치·스타일·닫힘 시간은 유지한다.

## T-041 구현

음성 스크랩은 자체 STT 대신 Gleo Intent 경로로 연결한다. 배너 key·단지 ID·만료 시각을 domain context 포트에 발행하고 닫힘/대체·Driving 화면 숨김·앱 background에서 무효화한다. 배너 탭과 음성은 같은 멱등 저장을 호출하고, DB 관찰을 통해 ‘스크랩함’을 표시한다. 기존에 저장된 단지의 배너도 처음부터 저장 상태로 보인다. 공개 debug 명령은 현재 보이는 알림만 실행하며 상세 화면·직전 알림으로 대체하지 않는다. Gleo가 실제로 청취 중인지 앱이 알 수 있는 API는 확인되지 않아 자체 마이크 시작·TTS 완료 후 자동 청취는 구현하지 않는다. 실제 음성·주행 심사 Gate는 여전히 별도 검증한다.

2026-11-15 T-041 후속: 추천 알림이 보이면 ‘{단지명}, 스크랩할까요?’를 ON_DEVICE TTS로 읽는다. 긴 질문이 실제로 8.2초 걸려 사용자 후속 요청에 따라 줄였다. 관심 알림 설정·위치 동의·foreground를 확인하고 오디오 포커스 거절·상실, 알림 만료, 화면 종료 시 폐기한다. 포커스를 되찾아도 다시 읽지 않는다.
