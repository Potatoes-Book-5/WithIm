# SCR-011 주차 후 추천 매물 모아보기

## 목적

주행 세션의 전체 추천 후보와 지나친 관심 매물을 다시 확인하고 스크랩한다. 추천으로 저장된 단지는 한 번만 표시한다. 추천이 저장되지 않은 과거 요약은 기존 지나친 관심 매물 목록을 사용한다.

## 진입·이탈 경로

- 진입: SCR-008의 `관심 매물 모아보기`(추천 또는 지나친 관심 매물이 있을 때만 보인다). 주행이 끝나면 SCR-008이 먼저 뜬다(2026-11-14 사용자 결정).
- 이탈: 뒤로 → SCR-008, 단지 → 단지 상세(SCR-002), `스크랩 목록 보기` → SCR-007

## 정보 우선순위

1. 추천 매물 수
2. 단지명과 가격
3. 가장 가까웠던 거리
4. 스크랩 상태

## 레이아웃

- 상단: 뒤로 버튼, 제목, 오른쪽에 `개수 · 주행 날짜`(SCR-007 앱 바와 같은 형태)
- 가운데: 전체 추천 후보와 추천 목록에 없는 지나친 관심 매물 목록(별 아이콘, 단지명, 가장 가까웠던 거리, 가격, 스크랩 토글). 중복은 한 번만 표시하고, 앱 창 너비 전체를 쓴다.
- 하단 오른쪽: `스크랩 목록 보기 ›`

## 컴포넌트

| 영역 | 컴포넌트 | 비고 |
|---|---|---|
| 목록 | 목록 항목, 스크랩 토글 | SCR-008의 지나친 관심 매물 항목과 같은 동작 |
| 앱 바 | 뒤로 버튼 | SCR-007과 같음 |
| 하단 | 텍스트 링크 | 스크랩 목록 보기 |

해당 없는 상태는 위 표에서 제외했습니다. 추천과 지나친 관심 매물이 모두 없으면 SCR-008에 진입 버튼을 두지 않습니다. 모든 프레임은 light, dark 테마를 각각 만듭니다.

## 인터랙션과 음성

- 스크랩 토글
- 추천 카드를 눌러 상세를 열면 다음 주행의 개인화에 쓸 로컬 상세 반응을 기록한다. 일반 지나친 관심 항목은 반응으로 기록하지 않는다.
