# SCR-010 마이 페이지

## 목적

첫 실행 때 설정한 관심 부동산 조건을 한눈에 보여 주고, 스크랩한 단지가 그 조건을 얼마나 만족하는지 비교해 스크랩 목록(SCR-007)으로 이동하게 한다.

## 결정

2026-11-13 팀 결정으로 **시안 C(스크랩 비교 오각형)**를 사용한다. 동료 아이디어인 육각형·오각형 비교 차트에서 출발했다.

| 시안 | 결과 | 이유 |
|---|---|---|
| C. 스크랩 비교 오각형 | 채택 | 사용자 입력을 늘리지 않고 데이터로 계산하며, 스크랩 이동이라는 화면 목적과 바로 연결 |
| B. 부부 비교 육각형 | 보류 | 부부 각자 조건을 갖기로 하면 다시 검토 |
| A. 조건 육각형 | 제외 | 조건별 중요도 입력이 추가로 필요 |
| D. 카드형 | 제외 | 조건 간 비교가 잘 드러나지 않음 |

## 진입·이탈 경로

- 진입: 홈(SCR-001)의 상단 `마이 페이지` 버튼과 `관심 조건` 카드
- 이탈: 스크랩 목록(SCR-007), 조건 수정(SCR-003), 단지 상세(SCR-002), 뒤로 가기
- 주차 중에만 진입한다. 주행이 시작되면 SCR-004로 전환한다.

## 정보 우선순위

1. 내 관심 조건(오각형과 조건 값)
2. 스크랩 단지별 조건 일치율 상위 3곳
3. 스크랩 전체 수와 변동 건수, 스크랩 목록으로 가는 버튼
4. 조건 수정 버튼

## 레이아웃

- 상단: 뒤로 가기, `마이 페이지` 제목, 설명 한 줄
- 왼쪽 패널: `내 조건` 오각형, 조건 값 두 줄, `조건 수정` 버튼
- 오른쪽 위: 스크랩 상위 3곳 카드. 각 카드는 작은 오각형(점선: 내 조건, 채움: 단지), 단지명, 조건 일치율, 변동 배지
- 오른쪽 아래: `스크랩 전체 보기` 버튼과 변동 건수

## 오각형 규칙

- 축 순서는 가격대, 평수, 동네, 세대수, 신축이며 모든 오각형에서 같게 한다.
- 내 조건 오각형은 모든 축이 최대값인 기준 모양이다.
- 단지 오각형의 각 축은 그 조건을 얼마나 만족하는지(0~5)를 나타낸다. 조건 범위 안이면 5이고, 벗어난 정도에 따라 줄어든다(2026-11-14 결정, 제안값).

| 축 | 벗어났을 때 |
|---|---|
| 가격대 | 가장 가까운 구간 경계에서 10% 벗어날 때마다 −1 |
| 평수 | 가장 가까운 구간 경계에서 3평마다 −1 |
| 동네 | 0 |
| 세대수 | 기준보다 100세대 적을 때마다 −1 |
| 신축 | 기준 연차보다 2년 오래될 때마다 −1 |

- 조건을 고르지 않은 축은 5로 본다. 단지 정보를 모르는 축은 0으로 그리고 일치율 평균에서 뺀다.
- 조건 일치율은 축 값 평균 × 20을 반올림한 백분율이다(제안값). 같으면 최근에 스크랩한 단지가 먼저다.
- 구현: `domain/policy/ConditionMatchPolicy.kt`
- 작은 오각형에는 축 이름을 표시하지 않고, 왼쪽 큰 오각형으로 축 순서를 알려 준다.
