# SCR-003 관심 조건 설정

## 목적

동네, 가격대, 평수를 칩 선택으로 한 화면에서 설정한다.

## 진입·이탈 경로

- 진입: 첫 실행(동의 후), 마이 페이지(SCR-010)의 `조건 수정`
- 이탈: 첫 실행이면 저장 또는 건너뛰기 후 홈, 수정이면 저장 또는 취소 후 연 화면으로

## 정보 우선순위

1. 동네 선택
2. 가격대 선택
3. 평수 선택
4. 세대수, 준공 선택(T-017)
5. 저장 버튼

## 레이아웃

- 한 화면에 다섯 그룹(동네, 가격대, 평수, 세대수, 준공)을 세로로 배치하고 스크롤한다. 다단계 이동은 없다(DD-009).
- 동네 그룹: 주변 추천 칩, 음성 검색 버튼
- 하단: 건너뛰기, 저장

## 컴포넌트

| 영역 | 컴포넌트 | 비고 |
|---|---|---|
| 조건 그룹 | 선택 칩 | 동네·가격대·평수는 다중 선택, 세대수·준공은 하나만(다시 누르면 해제) |
| 동네 | 음성 검색 버튼 | STT |
| 하단 | Basic Button |  |

## 인터랙션과 음성

- 칩은 눌러서 선택/해제
- 음성 검색 결과는 칩으로 추가
- 주행 중 진입 불가

## 문구

| 위치 | 문구 |
|---|---|
| 제목 | 어떤 집을 함께 찾고 있나요? |
| 저장 | 이 조건으로 시작 |
| 건너뛰기 | 나중에 할게요 (수정 중에는 `취소`, 저장된 조건과 알림을 바꾸지 않음) |
| 세대수 칩 | 300세대 이상 · 500세대 이상 · 1,000세대 이상 |
| 준공 칩 | 5년 이내 · 10년 이내 · 15년 이내 |
