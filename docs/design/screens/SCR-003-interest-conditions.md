# SCR-003 관심 조건 설정

## 목적

동네, 가격대, 평수를 칩 선택으로 한 화면에서 설정한다.

## 진입·이탈 경로

- 진입: 첫 실행(동의 후), 홈의 조건 수정
- 이탈: 저장 또는 건너뛰기 후 홈

## 정보 우선순위

1. 동네 선택
2. 가격대 선택
3. 평수 선택
4. 저장 버튼

## 레이아웃

- 한 화면에 세 그룹을 세로로 배치해 다단계 이동을 없앤다(DD-009).
- 동네 그룹: 주변 추천 칩, 음성 검색 버튼
- 하단: 건너뛰기, 저장

## 컴포넌트

| 영역 | 컴포넌트 | 비고 |
|---|---|---|
| 조건 그룹 | 선택 칩 | 다중 선택 |
| 동네 | 음성 검색 버튼 | STT |
| 하단 | Basic Button |  |

## 인터랙션과 음성

- 칩은 눌러서 선택/해제
- 음성 검색 결과는 칩으로 추가
- 주행 중 진입 불가

| 건너뛰기 | 나중에 할게요 |
