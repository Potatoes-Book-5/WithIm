# SCR-004 주행 중 순위 경쟁

## 목적

주행 중 반경 10km Top 3를 1~2초 안에 읽을 수 있게 보여 준다.

## 진입·이탈 경로

- 진입: 주행 전환(S-005)
- 이탈: 주차 전환 후 홈 또는 주행 요약

## 정보 우선순위

1. 1위 대장 아파트 단지명과 가격
2. 2·3위
3. 주행 중 표시

## 현재 실거래 표시 범위 (T-027, T-030)

- 순위 카드는 **한 달 전 날짜부터 오늘까지(양 끝 포함)의 아파트 매매 실거래** 중 현재 차량 위치(없으면 삼성전자 수원 본사 임시 기준)에서 직선거리 10km 이내인 거래로 만든 Top 3다. 기준 위치의 경계 상자와 교차하는 시군구의 월별 국토부 API를 조회한 뒤 실제 거래일과 직선거리로 거른다. 해제된 거래는 제외한다.
- T-030부터 T-023의 오른쪽 실거래 표를 없애고 와이어프레임대로 카드 3장이 앱 창 너비를 채운다. 표와 카드가 같은 거래를 두 번 보여 주었기 때문이다.
- 와이어프레임에는 없지만 상단 `반경 10km` 오른쪽에 조회 기준과 계약일 범위를 한 줄로 표시한다(예: `현재 차량 위치 · 반경 10km 실거래 · 10.14~11.14 계약`).
- 순위가 비어 있으면 카드 자리에 조회 중, API 오류, 조건에 맞는 거래 없음 중 하나를 표시한다. 임의의 거래값으로 대체하지 않는다.
- 위치나 지도를 사용할 수 없으면 원인을 표시하고 가상 좌표를 만들지 않는다.

## 레이아웃

- Portrait 기본: 내비 앱 옆 창에서 사용
- Top 3를 큰 카드로 세로 배치, 스크롤 없음
- 버튼 없음, 입력은 음성만
