# SCR-004 주행 중 순위 경쟁

## 목적

주행 중 반경 10km Top 3를 1~2초 안에 읽을 수 있게 보여 준다.

## 진입·이탈 경로

- 진입: 주행 전환(S-005)
- 이탈: 주차 전환 후 홈 또는 주행 요약

## 정보 우선순위

1. 1위 대장 아파트 단지명과 가격
2. 2·3위
3. 주행 중 표시

## 현재 실거래 표시 범위 (T-023)

- 주행 화면 오른쪽 표에는 **한 달 전 날짜부터 오늘까지(양 끝 포함)의 수원시 영통구 개별 아파트 매매 실거래** 중 삼성전자 수원 본사 임시 기준점에서 직선거리 10km 이내인 거래를 최대 3건 표시한다. 달력 월이 두 개에 걸치면 각 월의 국토부 API를 조회한 뒤 실제 거래일로 기간을 거른다.
- 거래금액 총액(만원) 내림차순, 같으면 거래일 최신순으로 정렬한다. 같은 단지의 여러 거래가 각각 표시될 수 있다. 해제된 거래는 제외한다.
- 표의 제목과 설명에 `실거래`, 실제 날짜 범위, `삼성전자 기준`을 표시한다. 차량 현재 위치 기반 순위나 단지별 대표 시세로 표현하지 않는다.
- 조회 중에는 로딩 상태를, API 오류에는 오류 상태를, 조건에 맞는 거래가 없으면 빈 상태를 표시한다. 임의의 거래값으로 대체하지 않는다.
- 네이버 지도 SDK의 지도 바탕은 실제 지도다. 지도 위 단지 마커와 순위 카드는 샘플 데이터이므로 `샘플`임을 명확히 표시한다. 실제 거래 표의 순위와 샘플 카드·마커의 순위를 결합하지 않는다.
