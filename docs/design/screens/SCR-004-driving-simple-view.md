# SCR-004 주행 중 순위 경쟁

## 목적

주행 중 반경 10km Top 3를 1~2초 안에 읽을 수 있게 보여 준다.

## 진입·이탈 경로

- 진입: 주행 전환(S-005)
- 이탈: 주차 전환 후 홈 또는 주행 요약

## 정보 우선순위

1. 1위 대장 아파트 단지명과 가격
2. 2·3위
3. 주행 중 표시

## 레이아웃

- Portrait 기본: 내비 앱 옆 창에서 사용
- Top 3를 큰 카드로 세로 배치, 스크롤 없음
- 버튼 없음, 입력은 음성만

## 컴포넌트

| 영역 | 컴포넌트 | 비고 |
|---|---|---|
| 순위 | 대형 순위 카드 | 앱 전용 후보 |
| 상단 | 주행 중 배지 |  |

## 인터랙션과 음성

- 상단 `순위 | 지도` 전환으로 지도 모드(SCR-009)로 바꾼다. 전환은 이 화면의 유일한 터치 동작이며 주행 중 허용 여부는 미확정이다.
- 순위 변경 시 애니메이션 없이 즉시 갱신(DD-005, ANM-002)
