# 디자인 원칙

> 확인일: 2026-11-08 · 상태: 초안. 페이지 요약을 바탕으로 작성했으며 T-006에서 원문과 대조합니다.
> 공식 문서를 복제하지 않고 요약합니다. 판단이 필요하면 원문을 우선합니다.

## 원문

- [UI Design Guide 소개](https://document.pleos.ai/docs/connect/guide/docs-design/Introduction/intro)

## 요약

기본 원칙은 사용성과 안전성(Easy & Safe), 일관성(Consistency), 즉시성(Glanceability)입니다.

## 규칙

강도(MUST/SHOULD)는 원문 표현을 바탕으로 팀이 해석한 값입니다.

| ID | 강도 | 규칙 |
|---|---|---|
| DG-001 | MUST | 영상이나 자동 스크롤로 시선을 빼앗지 않는다. |
| DG-002 | MUST | 한 손으로 조작할 수 있는 단순한 동작만 요구한다. |
| DG-003 | SHOULD | 아이콘, 용어, 상호작용 패턴을 Pleos Connect 기본 UI와 맞춘다. |
| DG-004 | MUST | 핵심 정보는 1~2초 안에 파악할 수 있어야 한다. |
| DG-005 | MUST | 입력 후 시스템 응답은 0.25초를 넘지 않게 하고, 지연되면 응답 중임을 표시한다. |
| DG-006 | MUST | 아이콘, 텍스트, 이미지의 대비율은 4.5:1 이상이다. |
| DG-007 | SHOULD | 한 줄은 영문 기준 80자 이하, 문단은 3줄 이하로 제한한다. |
| DG-008 | MUST | 중요 정보의 기본 텍스트 높이는 5mm 이상, 보조 텍스트는 3mm 이상이다. |
| DG-009 | SHOULD | 통용되는 아이콘에 텍스트 라벨을 함께 제공하고 터치 시 진동이나 음성 피드백을 준다. |
| DG-010 | MUST | 알림은 필요한 경우에만 간결하게 표시하며 광고 목적으로 사용하지 않는다. |
| DG-011 | SHOULD | 야간·주간 모드와 음성 인터랙션을 지원한다. |
| DG-012 | SHOULD | 다양한 해상도와 화면 비율, 다국어에 대응한다. |

## 이 앱에 적용

- SCR 문서에 핵심 정보를 3개 이내로 우선순위화합니다(팀 제안값).

## 원문에 없는 항목

- 구체적인 해상도 수치(Display Layout 페이지 확인 필요)
