# Typography

> 확인일: 2026-11-08 · 상태: 초안. 페이지 요약을 바탕으로 작성했으며 T-006에서 원문과 대조합니다.
> 공식 문서를 복제하지 않고 요약합니다. 판단이 필요하면 원문을 우선합니다.

## 원문

- [Typography](https://document.pleos.ai/docs/connect/guide/docs-design/foundations/typography)

## 요약

System UI 글꼴은 Asta Sans이며 한국어와 영어를 지원합니다.

## 규칙

강도(MUST/SHOULD)는 원문 표현을 바탕으로 팀이 해석한 값입니다.

| ID | 강도 | 규칙 |
|---|---|---|
| TYP-001 | SHOULD | System UI 글꼴인 Asta Sans를 사용한다. |
| TYP-002 | MUST | 12sp 이상을 사용하고 실제 픽셀 기준 최소 높이는 18px 이상으로 한다. |
| TYP-003 | SHOULD | 정보 위계에 따라 컴포넌트 간 일관된 크기를 적용한다. |
| TYP-004 | SHOULD | 캐릭터가 강조된 글꼴은 피한다. |

## 타입 위계

Headline, Title, Body, Label. 이름, 크기, 굵기, 행간은 이미지로 제공되므로 공식 `.fig`에서 추출합니다(T-002).

## 이 앱에 적용

- 가격처럼 비교가 필요한 숫자의 위계는 SCR 문서에서 지정합니다.

## 원문에 없는 항목

- 토큰 이름과 값(이미지로만 제공)
- Feature 위계 본문
